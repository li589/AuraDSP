## 一、背景与目标

### 1. 空间混响（Spatial Reverb）热修复
* **现象描述**：
  用户反馈：启动应用后，稍加拖动空间混响的干湿比（Wet/Dry Mix）滑块，空间混响卡片与状态立刻自动关闭（总开关熄灭、折叠并停止发声）；在用户手动再次开启或点击预设后，之后恢复正常。
* **根因定位（Root Cause）**：
  1. `state.dart` 中的混响开启判定逻辑为：`bool get isSpatialReverbOn => reverbPreset >= 0 || fvOn;`。
  2. 应用冷启动时，`replaySessionToEngine()` 仅恢复了 `reverbPreset`，此时内存中 `fvOn == false`。
  3. 当用户拖动干湿比滑块时，触发了 `setReverbCustomParam('wet', v)`。该方法内部直接执行了 `reverbPreset = -2`（标记为自定义模式），但**遗漏了调用 `setFreeverbEnabled(true)` 或将 `fvOn` 置为 `true`**。
  4. 导致判定表达式计算为 `(-2 >= 0) || false == false`，整个空间混响被误判定为已关闭（`isSpatialReverbOn == false`），引发界面自动折叠、总开关关闭、底层 Freeverb 引擎关断。
  5. 后续用户点击预设时，由于 `selectReverbPreset()` 内部显式调用了 `setFreeverbEnabled(true)`，因此之后恢复正常。
* **修复目标**：
  - 在 `setReverbCustomParam()` 中补齐 `setFreeverbEnabled(true)` 与 `fvOn = true`。
  - 在 `replaySessionToEngine()` 中，若处于混响开启状态，无条件同步下发 `ParamId.fvEnable` 与全部 `freeverb.*` 参数。

### 2. 串扰消除（Crossfeed / 交叉馈送）独立卡片设计
* **声学定位**：
  专为耳机佩戴者设计，用于消除耳机由于绝对左右隔离导致的“头中效应”（In-the-Head Localization）。通过模拟真实音箱在听音室中的微秒级延迟与人头声学阴影（ITD/ILD），显著缓解长时间耳机听觉疲劳。
* **范围界定**：
  - **不包含 HRTF 3D 环绕模式**：HRTF 脉冲与 3D 虚拟空间算法留待后续独立的“空间音效 / 虚拟声场”卡片统一承载。
  - **精选 EasyEffects 与 JamesDSP 核心预设（剔除重复项）**：
    1. **默认标准 (Default / BS2B Standard)**：$700\text{ Hz}, 4.5\text{ dB}$（轻度互馈，声底自然，日常流行/人声首选）
    2. **经典耳放 (Chu Moy)**：$700\text{ Hz}, 6.0\text{ dB}$（经典耳放互馈方案，温润平衡）
    3. **增强互馈 (Jan Meier)**：$650\text{ Hz}, 9.5\text{ dB}$（知名耳放设计师 Meier 方案，深度消除早期硬立体声压迫感）
    4. **自定义 (Custom)**：允许在高级面板自由调节截止频率与衰减分贝。
* **UI 交互规范**：
  - 严格采用已统一的 `SectionCard` 标准卡片规范，序号对齐信号链顺序；
  - 顶部显示模式选择 Chip（Default / Chu Moy / Jan Meier / 自定义）；
  - 核心展示区提供“互馈强度”直观量化反馈与说明；
  - 高级面板统一采用 `AdvancedSection`：内置 **截止频率 (Cutoff: 300 ~ 2000 Hz)** 与 **互馈电平 (Feed: 1.0 ~ 15.0 dB)** 两大物理参数滑块；选择预设时自动回填相应物理值，拖动自定义滑块时自动联动选中“自定义”Chip。

## 二、架构与参数映射表

### 1. C++ 引擎参数扩展 (`auradsp_engine.cpp`)

| 参数 ID | 类型 | 取值范围 | 默认值 | 作用与说明 |
| :--- | :--- | :--- | :--- | :--- |
| `crossfeed.enable` | `int32_t` | `0` 或 `1` | `0` | 全局开启/旁路控制 |
| `crossfeed.mode` | `int32_t` | `0..3` | `0` | `0`: Default, `1`: Chu Moy, `2`: Jan Meier, `3`: Custom |
| `crossfeed.fcut` | `float` | `300.0 ~ 2000.0` | `700.0` | 串扰滤波低通截止频率 (Hz) |
| `crossfeed.feed` | `float` | `1.0 ~ 15.0` | `4.5` | 低频串扰互馈衰减量 (dB) |

### 2. 底层 DSP 算法调用关系 (`libjamesdsp`)
* `crossfeed.mode == 0`（Default）：调用 `BS2BInit(&jdsp->advXF.bs2b[0], fs, BS2B_DEFAULT_CLEVEL)`，模式切至 0；
* `crossfeed.mode == 1`（Chu Moy）：调用 `BS2BInit(&jdsp->advXF.bs2b[0], fs, BS2B_CMOY_CLEVEL)`，模式切至 0；
* `crossfeed.mode == 2`（Jan Meier）：调用 `BS2BInit(&jdsp->advXF.bs2b[1], fs, BS2B_JMEIER_CLEVEL)`，模式切至 1；
* `crossfeed.mode == 3`（Custom）：调用 `BS2BCalculateflevel((uint32_t)fcut, (uint32_t)(feed * 10.0f))` 计算 `flevel`，初始化 `bs2b[0]` 并切至模式 0。
