# 调试体系与控件实测（2026-11-01）

> 目标：所有调试打印受统一总线约束；用户每一次点击/拖动同时留下
> **前端 UI 事件** 与 **DSP 回执**；整套调试实例可由命令行启动。
> 工具入口：[`tools/debug/README.md`](../../tools/debug/README.md)。

## 1. 事件链

```text
用户操作
  → ui.control / ui.tap / ui.pointer      （主 isolate，含控件 id/标签/值）
  → param.send / command.send             （主 isolate → 音频 isolate）
  → engine.ack                            （音频 isolate → 主 isolate，rc/耗时）
  → JSONL + 实时 HUD + 命令行 tail
```

- `ui.control`：`ParamSlider` / `ParamSwitch` / `ParamChoiceChips` /
  `ParamAutoGainRow` / 通用 `ValueSlider` 等，带 `ParamSpec.id`。
- `ui.tap`：无参数语义的按钮——`chip` / `segment` / `dropdown` /
  `nav`（左栏页面）/ `rail`（左栏收起展开）/ `icon`（顶栏图标动作）。
- `param.send`：`AppModel.send` 对所有 `setParam` / `setParamStr` 统一记录；
  长脚本只记长度，不写源码。
- `engine.ack`：`state_events` 的 `paramResult` 落一条 `rc/tookMs/msg`；
  `rc=0` 表示 DSP 层已接收。
- `ui.pointer`：根级指针兜底，覆盖没有语义标签的自定义按钮。

## 2. 启动

```powershell
cd app\auradsp_app
flutter build windows --release --no-tree-shake-icons
powershell -File ..\..\tools\debug\run_debug.ps1 -Tail
```

`--debug` 打开总线；`--debug-log=<path>` 指定 JSONL；`--debug-console`
同时写 stdout。默认 `%TEMP%\auradsp_debug_trace.jsonl`。

## 3. HUD 与“所有控件”确认

调试实例右下角出现 `DEBUG TRACE` 面板：

```text
DEBUG TRACE · UI <已见控件>/<ParamRegistry 非派生总数> · ACK <成功回执数>
#n [ui] control eq.enable = true
#n [param] send eq.enable = 1
#n [engine] ack eq.enable = 0
```

逐页操作每个滑块/开关/chip 后：

1. `UI` 计数应覆盖该页参数（`control.register` 首次出现即 +1）；
2. 每次操作应看到成对的 `ui.control` → `param.send` → `engine.ack`；
3. 只有 `ui/param` 没有 `engine.ack` → 音频 isolate 未回执或引擎拒绝，
   查 `engine.ack` 的 `rc/msg`；
4. 无 `ui.control` 但有点击 → 看 `ui.tap`（chip/segment/dropdown/nav/rail/icon）
   或 `ui.pointer`（自定义控件），再按坐标定位。

## 4. 打印规范

| 场景 | 唯一出口 |
|---|---|
| 业务代码普通日志/错误 | `dbgLog`（`engine/debug_log.dart`，写 `%TEMP%\auradsp_debug.log`） |
| 调试事件/控件/参数/回执 | `DebugTrace`（`core/debug/debug_trace.dart`） |
| 引擎宿主控制线程 | `AURADSP_DBG*` / `AURADSP_WARN*`（编译期 `AURADSP_DBG_LOG` + 运行期 `AURADSP_LOG`） |
| 引擎音频 RT 线程 | **禁止任何日志**（零分配/零锁/零系统调用） |

- 业务代码禁止直接 `print(` / `debugPrint(`；门禁
  `tools/bin/debug_log_scan.py` + `test/smoke/smoke_debug_policy.py`。
- 调试事件不记录音频内容、完整 EEL 脚本或密钥；字符串统一截断 240 字符。
- 调试总线默认关闭；未传 `--debug` 时不创建文件、不建定时器、不格式化字符串。

## 5. 验收

| 项 | 标准 |
|---|---|
| 调试启动 | `run_debug.ps1` 能启动 Release 并生成 JSONL |
| UI→DSP 链 | 每个参数控件至少一组 `ui.control/param.send/engine.ack` |
| 非参数按钮 | 至少 `ui.tap` 或 `ui.pointer` + `command.send` |
| 覆盖率 | HUD `UI` 计数随页面操作增长，未知控件可在 JSONL 反查 |
| 打印门禁 | `debug_log_scan.py` 0 违规；`smoke_debug_policy.py` 全绿 |
| 回归 | `flutter analyze` 0；`flutter test test/debug_trace_test.dart` 3/3 |

## 6. 已知边界

- `ParamRegistry` 的派生参数（如 `bass.gain`）不单独占控件，HUD 总数
  只统计非派生 spec；
- 音频 isolate 内部的高频 `setParam` 日志仍按原 `ThrottledLog` 采样，
  但每次 **主 isolate 发令** 与 **引擎回执** 不受采样影响；
- `--debug-console` 依赖父进程控制台；GUI 双击启动时请用 JSONL / HUD。
