### 1.2 勘误项（报告有误或已过时，**须先修报告再按报告办事**）

#### E1（中）字符串总量已漂移：2333→2322、错误串 134→133
- **现象**：重跑总数 2322（host 413 而非 424）、错误/诊断串 133 而非 134。
- **根因（推断，证据链闭合）**：报告扫描时工作区存在**未提交的 `[TEMP-DIAG]` 临时诊断代码**；报告生成后 4 分钟（host_instances.cpp mtime 13:27 vs 报告 13:23）该代码被移除还原至 HEAD。`git log -S 'TEMP-DIAG'` 为空证实从未提交；当前全树 `TEMP-DIAG` 命中 0。
- **影响**：报告 A2 示例中的 `[TEMP-DIAG close] step B1...` 已不存在；引用报告数字做门禁会差 1~11。
- **处置**：报告头部加"快照状态"注记，数字以本计划复跑值为准；**扫描类报告生成时必须先 `git status` 标注工作区洁净度**（入 §6 规范）。

#### E2（高）"纯调试型约 8 个"严重低估——实际 86 处，低报 10 倍
- **现象**：报告 A2 称 `[DBG]/[TEMP-DIAG]` 约 8 个。实测当前树 `[DBG` 共 **86 处**，全部为**无条件 `std::cout`**：
  - `engine/host/host_instances.cpp`：70 处
  - `engine/host/host_slots.cpp`：11 处
  - `engine/plugin_host_util.h`：5 处
- **根因**：报告的 134 个"错误/诊断串"只是全树字符串中匹配 `ERROR_RE` 关键词（failed/null/closed/invalid…）的**子集**；86 处 DBG 中仅 **7** 处含错误关键词，其余 79 处（step 1/enter/exit/complete 等）**完全不在报告视野内**。分类口径把"错误串统计"误当"调试输出统计"。
- **加重情节**：全部 86 处**无任何编译开关**（文件内 4 处 `#if _MSC_VER` 均为 SEH 块，与日志无关）；输出通道为 `std::cout`——Flutter GUI 进程内 DLL 的 stdout 通常无效，**用户机器上看不到、附控制台时又全量刷出**，属于"该看时看不到、不该看时会泄露"的双输。
- **处置**：升级为本计划 **D1（P0）**，见 §3。

#### E3（低）A3"版本两处不一致"系误报，但真问题在别处
- **误报**：`auradsp_engine.h` 的 `1.0.0` 仅是注释示例（L150 `/* 引擎 ABI 版本，如 "1.0.0" */`），不是版本锚点；真实版本单一 = `AURADSP_VERSION "1.1.0"`（`engine_internal.h` L17），`auradsp_version()` 返回它。
- **真问题（报告反而漏掉）**：`host_instances.cpp` L1130 `m_host.version = "1.0.0";`（VST3/CLAP host 自报版本）与 `AURADSP_VERSION 1.1.0` **硬编码不同步**——插件侧看到的宿主版本与引擎真实版本不一致。
- **处置**：并入 §6 S1-1 版本单源化。

#### E4（低）扫描工具链违反项目工具分流规范
- `engine/scan_engine_strings.py`、`engine/gen_report.py`、`engine/_scan_cache.json` 均为 untracked（?? 状态）却放在引擎源码树内；`gen_report.py` L6 写死绝对路径 `D:/temp_desktop/Proj/JamesDSP`；`_scan_cache.json` 未入 `.gitignore`，污染 `git status`。
- **处置**：并入 §6 S1-3 工具归位。

## 3. D1 · 调试信息控制（P0，发布阻断级）

### 3.1 统一调试日志宏（新增 `engine/debug_log.h`）

```cpp
// 编译期一级开关：CMake option AURADSP_DBG_LOG（默认：Release=OFF / Debug=OFF，显式开启）
// 关闭时宏展开为空 —— 字符串字面量不进二进制（省体积 + 彻底零开销 + strings 扫描不可见）
#ifdef AURADSP_DBG_LOG
  #define AURADSP_DBG(msg) ::jamesdsp::dbg::emit(__FILE__, __LINE__, msg)
#else
  #define AURADSP_DBG(msg) ((void)0)
#endif
```

- **输出通道**：`OutputDebugStringA`（DebugView/VS 可见）替代 `std::cout`——GUI 进程内无控制台也可靠，且不会劫持 stdout；格式 `"[AuraDSP][host_instances.cpp:434] ..."`。
- **运行期二级控制**（Debug 构建内）：环境变量 `AURADSP_LOG=0|1|2`（0 静默 / 1 警告 / 2 全量），启动时读一次存 `std::atomic<int>`——满足"偶发问题现场抓日志"而不必重编译。
- **明确不做**：文件日志、日志滚动（宿主生命周期短，无需求）；RT 路径日志（铁律禁止）。

### 3.2 86 处逐条分诊改造（三分类）

| 分类 | 判定标准 | 处置 | 预估 |
|---|---|---|---|
| **T1 过程追踪** | step 1 / enter / exit / complete / quiesced 等中性步骤 | 改 `AURADSP_DBG`，保留 | ~65 处 |
| **T2 真实故障** | failed / NULL / timeout / crashed / unresponsive / WARNING | 双轨：改 `AURADSP_DBG` + **能返回错误码的补 `set_error`/返回码**（宿主 API 已有 rc 通道的只改宏） | ~18 处 |
| **T3 冗余无信息量** | 与相邻行重复、纯占位 | 删除 | ~3 处 |

- 逐文件落地顺序：`plugin_host_util.h`（5）→ `host_slots.cpp`（11）→ `host_instances.cpp`（70，按 CLAP/VST3/unload/showEditor 分组小步提交）。
- **同步清退**：`#include <iostream>` 若因此不再需要则移除；[TEMP-DIAG 类临时标记**永久禁入**（§5 门禁）。

## 4. D2 · 错误字符串治理（P1）

### 4.1 结构化错误格式（引擎侧，保持英文）

- 统一格式：`"<param-id>: <reason-token>"`（现状已接近：`ddc.load: engine closed`、`eq.curve: invalid length`）。归一 reason-token 白名单（约 12 个）：`engine closed` / `invalid length` / `buffer too small` / `invalid encoding` / `invalid path` / `out of range` / `parse failed` / `io failed` / `file too large` / `unsupported` / `internal` …
- 不新增 ABI 返回码；`AURADSP_E_*` 五码语义不变（分类已够 UI 分流：拒绝原因展示与否）。

### 4.2 Dart 侧映射 + i18n + 脱敏（三语 arb）

- 新增 `lib/core/engine_error_map.dart`：`reason-token → l10n 词条`（`app_zh/en/ja.arb` 各补 ~12 条），未知 token **兜底显示原文**（永不空白）。
- 接入点：`state.dart` L1710 `_admitEngineEvent('error|$msg')` 前做一次 map 转译；`paramResult.msg`（isolate→UI 事件）同点复用。
- **脱敏规则**：含内部配置名的文案（`gate.maxFileMb`、`gate.maxIrSeconds`、内部路径）在**用户可见层**替换为友好描述，完整原文只进 `dbgLog`。示例：`file too large (exceeds configured gate.maxFileMb)` → zh「音频文件大小超出限制」。
- UI 现有通知去重（`_admitEngineEvent` 5s 窗口）不受影响——只改 msg 渲染内容，不改 key 结构。

### 4.3 验收

- 契约测试补断言：扫描 `engine_param_table.h` + 链路 set_error 串，**全部匹配 reason-token 白名单格式**（新增 token 未登记 → 测试红，倒逼登记）。
- UI 测试：模拟 `paramResult rc!=0` 断言横幅显示 zh 词条而非英文原文。
