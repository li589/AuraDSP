- **依据规划**：[`docs/20-执行/ASIO双线开发规划-2026-10-15.md`](file:///d:/temp_desktop/Proj/JamesDSP/docs/20-执行/ASIO双线开发规划-2026-10-15.md) 第 3 节（P3 出口门禁）与 [`docs/adr/ADR-008-asio-driver-identity-and-architecture.md`](file:///d:/temp_desktop/Proj/JamesDSP/docs/adr/ADR-008-asio-driver-identity-and-architecture.md)。
- **P3 核心目标**：
  - **Zero-DSP 彻底解耦动态加载**：实现 [`AuraAsioEngineLoader.h`](file:///d:/temp_desktop/Proj/JamesDSP/core/desktop/windows-drivers/04_asio_driver/AuraAsioEngineLoader.h)，驱动 DLL 内部严禁编译或静态链接 DSP 算法，必须通过 `LoadLibraryW`/`GetProcAddress` 动态绑定 `auradsp_engine.dll`；
  - **实时音频链路打通（DAW -> DSP -> WASAPI/Loopback）**：在 MMCSS "Pro Audio" 调度线程中，将 DAW 写入的非交织浮点双缓冲提取、高效交织送入 `auradsp_process`、解耦输出至物理渲染汇（`AuraAsioWasapiSink`）以及输入回录通道（ASIO Loopback）；
  - **实时线程安全（Real-Time Safety）**：中间缓冲与交织区全量在 `createBuffers` 预分配，流式泵循环中实现**零堆分配、零阻塞锁**；旁路与统计指标全部采用 `std::atomic`；
  - **外部参数控制与波形 A/B 门禁**：通过 `IASIO::future` 扩展私有选择子（`kAuraAsioFutureIsDspLoaded`, `kAuraAsioFutureSetBypass`, `kAuraAsioFutureGetBypass`, `kAuraAsioFutureSetParam`, `kAuraAsioFutureGetParam`, `kAuraAsioFutureApplyParamsString`, `kAuraAsioFutureGetDspProcessedFrames`, `kAuraAsioFutureCopyLastOutputBlock`）；
  - **P3 出口门禁**：达成 A/B 实测：`bypass=1` 输出等于干声，开 `post.gain = +6.0dB` 幅值精确翻倍（2.0x ±2%），重置恢复 1.0x，所有测试 100% 自动化闭环。

## 1. P3 核心技术实现

### 1.1 动态引擎装载器（[`AuraAsioEngineLoader.h`](file:///d:/temp_desktop/Proj/JamesDSP/core/desktop/windows-drivers/04_asio_driver/AuraAsioEngineLoader.h)）
位于 [`core/desktop/windows-drivers/04_asio_driver/`](file:///d:/temp_desktop/Proj/JamesDSP/core/desktop/windows-drivers/04_asio_driver/)：
- **符号绑定**：
  - `auradsp_create(float sampleRate, int maxBlockFrames)`
  - `auradsp_destroy(void* handle)`
  - `auradsp_process(void* handle, const float* in, float* out, int frames)`
  - `auradsp_set_param(void* handle, const char* id, const void* value, unsigned int bytes)`
  - `auradsp_get_param(void* handle, const char* id, void* outValue, unsigned int bytes)`
- **多级稳健探测路径**：
  1. 环境变量 `AURADSP_ENGINE_DLL`；
  2. 驱动模块自身目录及相对路径（`windows-drivers/out/Release/` -> `windows/out/Release/auradsp_engine.dll`）；
  3. 宿主进程 EXE 目录及相对路径；
  4. 系统安装目录 `C:\Program Files\AuraDSP\auradsp_engine.dll`；
  5. 系统默认动态库查找。
- **参数批处理注入**：内置 `ApplyParamsString`，支持 `"bass.enable=1;bass.gain=10.0"` 格式在控制线程直接下发。

### 1.2 驱动音频管线升级（[`AuraAsioDriver.cpp`](file:///d:/temp_desktop/Proj/JamesDSP/core/desktop/windows-drivers/04_asio_driver/AuraAsioDriver.cpp)）
- **RT 中间缓冲管理**：
  - 在 `createBuffers` 中使用 `_aligned_malloc(..., 64)` 分配 `m_interleavedIn`、`m_interleavedOut`、`m_dspOutL`、`m_dspOutR`；
  - 在 `disposeBuffers` 中 `_aligned_free` 清理，确保流式循环中绝不调用 `malloc/free/new/delete`。
- **双缓冲时序与 DSP 注入**：
  ```cpp
  // 1. 获取 DAW 上一个周期填充完毕的对立半区
  const long playIndex = 1 - currentToggle;
  const float* playL = (m_outputActive[0] && m_outBuffers[0][playIndex]) ? m_outBuffers[0][playIndex] : nullptr;
  const float* playR = (m_outputActive[1] && m_outBuffers[1][playIndex]) ? m_outBuffers[1][playIndex] : nullptr;

  if (m_dspOutL && m_dspOutR) {
      if (m_engine && !m_bypass.load(std::memory_order_relaxed) && m_interleavedIn && m_interleavedOut) {
          // 交织送入 auradsp_process 处理
          for (long i = 0; i < m_bufferSize; ++i) {
              m_interleavedIn[i * 2 + 0] = playL ? playL[i] : 0.0f;
              m_interleavedIn[i * 2 + 1] = playR ? playR[i] : 0.0f;
          }
          m_engineLoader.Process(m_engine, m_interleavedIn, m_interleavedOut, (int)m_bufferSize);
          for (long i = 0; i < m_bufferSize; ++i) {
              m_dspOutL[i] = m_interleavedOut[i * 2 + 0];
              m_dspOutR[i] = m_interleavedOut[i * 2 + 1];
          }
          m_dspProcessedFrames.fetch_add((uint64_t)m_bufferSize, std::memory_order_relaxed);
      } else {
          // 旁路直通
          if (playL) memcpy(m_dspOutL, playL, (size_t)m_bufferSize * sizeof(float));
          else memset(m_dspOutL, 0, (size_t)m_bufferSize * sizeof(float));
          if (playR) memcpy(m_dspOutR, playR, (size_t)m_bufferSize * sizeof(float));
          else memset(m_dspOutR, 0, (size_t)m_bufferSize * sizeof(float));
      }

      // 物理输出与 Loopback 录音回灌
      m_wasapiSink.PushSamples(m_dspOutL, m_dspOutR, m_bufferSize, m_sampleRate);
      if (m_inputActive[0] && m_inBuffers[0][currentToggle]) {
          memcpy(m_inBuffers[0][currentToggle], m_dspOutL, (size_t)m_bufferSize * sizeof(float));
      }
      if (m_inputActive[1] && m_inBuffers[1][currentToggle]) {
          memcpy(m_inBuffers[1][currentToggle], m_dspOutR, (size_t)m_bufferSize * sizeof(float));
      }
  }
  ```

### 1.3 诊断与扩展 Future 体系（[`AuraAsioDriverGuid.h`](file:///d:/temp_desktop/Proj/JamesDSP/core/desktop/windows-drivers/04_asio_driver/AuraAsioDriverGuid.h)）
- `kAuraAsioFutureIsDspLoaded` (`0x41555210`)：查询 DSP 引擎 DLL 是否成功动态装载；
- `kAuraAsioFutureSetBypass` (`0x41555211`)：控制驱动无缝切换 DSP 旁路态 / 处理态；
- `kAuraAsioFutureGetBypass` (`0x41555212`)：读取当前旁路状态；
- `kAuraAsioFutureSetParam` (`0x41555213`)：通过 `AuraAsioParamIo` 下发参数（如 `post.gain`, `bass.enable`）；
- `kAuraAsioFutureGetParam` (`0x41555214`)：回读引擎参数；
- `kAuraAsioFutureApplyParamsString` (`0x41555215`)：分号分隔批量参数注入；
- `kAuraAsioFutureGetDspProcessedFrames` (`0x41555216`)：读取 DSP 实际处理的总采样数；
- `kAuraAsioFutureCopyLastOutputBlock` (`0x41555217`)：无侵入复制最近一帧物理输出波形供自动化验证。
