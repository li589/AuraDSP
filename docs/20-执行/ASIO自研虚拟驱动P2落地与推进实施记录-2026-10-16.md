# ASIO 自研虚拟驱动（Driver 线 P2）落地与推进实施记录（2026-10-16）

## 0. 概要与定位

- **依据规划**：`docs/20-执行/ASIO双线开发规划-2026-10-15.md` 第 3 节（P2 出口门禁）与 `docs/adr/ADR-008-asio-driver-identity-and-architecture.md`。
- **P2 核心目标**：
  - 实现 DAW 输出缓冲到默认物理音频端点（WASAPI Shared Mode）的高保真直通渲染汇（`AuraAsioWasapiSink`）；
  - 实现采样率自适应线性插值重采样（支持 44.1kHz、48kHz、96kHz 等无缝对接物理声卡混音格式）；
  - 实现单线程无锁环形解耦缓冲（16,384 采样容量），杜绝爆音、断流与死锁；
  - 达成 P2 出口门禁：在无 DSP 介入的纯净直通状态下，外部写入的 440Hz 音频流稳定通过物理端点渲染发声。

## 1. P2 核心技术实现

### 1.1 WASAPI 直通渲染汇（`AuraAsioWasapiSink`）
位于 [`core/desktop/windows-drivers/04_asio_driver/`](file:///d:/temp_desktop/Proj/JamesDSP/core/desktop/windows-drivers/04_asio_driver/)：
- [`AuraAsioWasapiSink.h`](file:///d:/temp_desktop/Proj/JamesDSP/core/desktop/windows-drivers/04_asio_driver/AuraAsioWasapiSink.h) & [`AuraAsioWasapiSink.cpp`](file:///d:/temp_desktop/Proj/JamesDSP/core/desktop/windows-drivers/04_asio_driver/AuraAsioWasapiSink.cpp)：
  - **端点激活与格式自适应**：通过 `IMMDeviceEnumerator` 取得 `eRender, eMultimedia` 默认渲染设备，自动探测系统混音格式（IEEE Float 32 位 或 PCM 16 位，支持任意物理通道扩展填充）。
  - **解耦缓冲**：设置 20ms 底层缓冲并预填静音，防止驱动冷启动突发底噪；维护 16,384 采样立体声 FIFO。
  - **重采样引擎**：高精度相位累加器与线性插值算法，无惧 DAW 与硬件采样率差异（如 DAW 44.1kHz <-> 硬件 48kHz）。
  - **环境韧性与静默回退**：若无物理音频端点（如无音频虚拟化机或无输出设备），优雅跳过渲染，确保 ASIO 时钟泵与宿主通信绝对不卡死、不崩溃。

### 1.2 驱动时钟泵与双缓冲直通接合
- [`AuraAsioDriver.cpp`](file:///d:/temp_desktop/Proj/JamesDSP/core/desktop/windows-drivers/04_asio_driver/AuraAsioDriver.cpp)：
  - **RT 线程 COM 套间管理**：在 `AudioPumpThreadProc` 入口初始化 `CoInitializeEx(nullptr, COINIT_MULTITHREADED)`，退出时调用 `CoUninitialize()`，确保 WASAPI 接口合规调用。
  - **双缓冲搬运时序**：在 MMCSS "Pro Audio" 调度线程中，每当触发 `bufferSwitch(currentToggle)`，立即将上一周期 DAW 已填充完毕的对立半区数据 `1 - currentToggle` 投递给 `m_wasapiSink.PushSamples(...)`，完美符合 ASIO 经典双缓冲时序规范。
  - **生命周期管控**：`PumpLoop` 启动时打开汇、退出时关闭；`disposeBuffers` 强保障资源清空。

### 1.3 诊断与扩展 Future 选择子
在 [`AuraAsioDriverGuid.h`](file:///d:/temp_desktop/Proj/JamesDSP/core/desktop/windows-drivers/04_asio_driver/AuraAsioDriverGuid.h) 与 `AuraAsioDriver::future` 中扩展 Steinberg 规范的私有诊断选择子：
- `kAuraAsioFutureIsWasapiOpen` (`0x41555203`，查询 WASAPI 端点是否就绪)；
- `kAuraAsioFutureGetWasapiTargetRate` (`0x41555202`，查询物理混音采样率)；
- `kAuraAsioFutureGetWasapiRenderedFrames` (`0x41555201`，查询累计渲染物理帧数)；
- 严格遵循 Steinberg 规范，成功返回 `ASE_SUCCESS` (`0x3f4847a0`)。
