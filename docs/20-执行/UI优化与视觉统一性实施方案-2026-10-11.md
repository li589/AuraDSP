## 1. 现状基线（盘点摘要）

| 维度 | 现状 | 问题 |
|------|------|------|
| **设计令牌** | `AuraSpace` 8pt 网格、`AuraRadius` 四级、`AuraDur` 六档、`AuraCurve` 三条 | 个别硬编码（`14.0`、`AuraSpace.xxs+1`）破坏网格 |
| **排版体系** | eyebrow(12.5) / section(15) / label(14) / caption(12) / mono(11-12) | 标题层级偶尔混用、中文回退字体未统一走 `kBodyCjkFallback` |
| **核心组件** | `SectionCard`、`ValueSlider`、`AuraSwitch`、`AuraChip`、`AuraSegmented`、`AdvancedSection` | `_ChoiceChip` 私有未复用；`ValueSlider.overridden` 字段利用率极低 |
| **提示机制** | `LatencyBadge` 用 `Tooltip(350ms)`；`InteractiveEQ` 画布自绘 `_drawTooltipBadge` | **缺通用「问号徽标 → hover 气泡」组件**；Android 长按/暂留无对应 |
| **页面结构** | `EffectsPage` 9 张卡片 + `PresetCard`；`SettingsPage` 6 个 Section | 文案冗余（标题+hint 语义重叠）、卡片内边距不一致（`hero` vs 普通） |
| **响应式** | `contentMaxW=1080`、`pageX=32` 居中 | **无断点**；窄屏下卡片被挤压、水平溢出（SignalFlowBar、EQ 顶栏） |
| **主题** | 3 套 `AuraPalette`（Dark/Light/Aurora） | `auraLight` 强调色 `(230,59,46)` 与绿 `(212,255,63)` 语义未区分 |

## 2. 目标与非目标

### ✅ 目标（本轮范围）
1. **文案去重**：标题+hint 合一，冗余说明下沉或删除
2. **间距/尺寸归网**：清除硬编码，统一走 `AuraSpace`/`AuraRadius`/`AuraDur`
3. **复用组件化**：`_ChoiceChip` → `AuraChoiceChip` 公开；`ValueSlider` 精简字段
4. **帮助徽标系统**：`InfoBadge`（问号圆圈）→ hover/长按显示 `Tooltip`/气泡；Android 兼容
5. **响应式断点**：`contentMaxW` 下增加 `mobile(<600)`/`tablet(600-900)`/`desktop(>900)` 三档，卡片/顶栏自适应
6. **视觉统一**：
   - 卡片内边距统一 `cardPad`（取消 `hero` 差异）
   - 标题行 `SectionTitle` 间距、`AdvancedSection` 展开动画统一
   - `AuraChip`/`AuraSegmented` 选中态色值走 `palette.accent` 统一

### ❌ 非目标（后续迭代）
- 全新设计语言/品牌重塑
- 国际化文案重写（现有 l10n 保留）
- 引擎参数 schema 变更
- 性能优化（除非显性瓶颈）

## 4. 关键设计决策（已确认：6 项全按方案 A，2026-10-11；双击复位不需要）

| 决策点 | 方案 A（推荐） | 方案 B | 备选 |
|--------|---------------|--------|------|
| **InfoBadge 触发** | Desktop: hover 300ms → Tooltip<br>Android: 长按 500ms → 气泡（`showMenu`/`OverlayEntry`） | 统一点击弹 `Dialog` | 双击？ |
| **气泡样式** | Material `Tooltip` 变体（圆角 6、背景 `palette.panelRaised`、箭头指向徽标） | 自定义 `OverlayEntry` 气泡（更灵活） | `flutter_tooltip` 包 |
| **响应式断点** | `<600` mobile / `600-900` tablet / `>900` desktop | 仅 mobile/desktop 两档 | 跟随 Material `Breakpoints` |
| **SignalFlowBar 窄屏** | 横向滚动（现状）+ 指示器 | 折叠为下拉菜单 | 简化为图标-only |
| **EQ 顶栏 (7/10/15/31段 + 预设 + 动作)** | Wrap 自动换行（现状） | Tablet+ 横排、Mobile 竖排堆叠 | 折叠面板 |
| **文案去重策略** | hint 为空时不渲染；标题自包含语义 | 统一用 `InfoBadge` 承载次要说明 | 保留 hint 但缩短 50% |

> 决策已确认，P0 按此落地；唯气泡箭头见下方 P0 落地注记。

> **P0 落地注记（v1.1）**：箭头未做——Flutter `Tooltip` 无箭头支持，自定义 Overlay 在无真机视觉验证手段下风险高。当前为无箭头 Tooltip 变体（圆角 6 / `panelRaised` / hover 时描边+图标转 accent / 触屏命中 24px / 抬指保留 2.5s）。如坚持要箭头，P2 另做 `OverlayEntry`（需真机截图验收），请明确指示。

## 6. Android/小屏适配细则

| 场景 | 行为 |
|------|------|
| **InfoBadge** | 长按 500ms → `OverlayEntry` 气泡（上方/下方自动翻转）；点击空白/再次长按关闭；滚动时若手指未离开超 800ms 保持显示 |

## 12. InfoBadge 组件草案（`lib/core/ui_helpers.dart`）

```dart
class InfoBadge extends StatefulWidget {
  final String message;      // 气泡内容（支持换行）
  final double size;         // 徽标直径，默认 16
  final EdgeInsets? padding; // 徽标外边距
  const InfoBadge({
    super.key,
    required this.message,
    this.size = 16,
    this.padding,
  });

  @override
  State<InfoBadge> createState() => _InfoBadgeState();
}

class _InfoBadgeState extends State<InfoBadge> {
  OverlayEntry? _overlay;
  bool _hover = false;
  Timer? _longPressTimer;

  void _show() { /* OverlayEntry 气泡 */ }
  void _hide() { _overlay?.remove(); _overlay = null; }

  @override
  Widget build(BuildContext context) {
    final p = paletteOf(context);
    final badge = MouseRegion(
      onEnter: (_) => setState(() => _hover = true),
      onExit: (_) => setState(() => _hover = false),
      child: GestureDetector(
        onLongPressStart: (_) => _longPressTimer = Timer(500.ms, _show),
        onLongPressEnd: (_) { _longPressTimer?.cancel(); },
        onTap: () { if (!kIsWeb && Platform.isAndroid) _show(); },
        child: Container(
          width: widget.size,
          height: widget.size,
          decoration: BoxDecoration(
            shape: BoxShape.circle,
            border: Border.all(color: _hover ? p.accent : p.hairline, width: 1.5),
          ),
          child: Center(
            child: Icon(Icons.help_outline_rounded,
                size: widget.size * 0.7,
                color: _hover ? p.accent : p.textDim),
          ),
        ),
      ),
    );
    return widget.padding == null ? badge : Padding(padding: widget.padding!, child: badge);
  }
}
```

> Android 长按阈值 500ms、滚动保持 800ms、气泡箭头自动翻转、点击空白关闭。
