# ASIO 自研虚拟驱动（Driver 线 P1）落地与推进实施记录（2026-10-16）

## 0. 概要与定位

- **依据规划**：`docs/20-执行/ASIO双线开发规划-2026-10-15.md` 与 `docs/adr/ADR-008-asio-driver-identity-and-architecture.md`
- **模式边界**：
  - **Client 线**（已落地）：`04_asio_client/` + `bridge/asio_bridge/`，作为宿主打开第三方声卡驱动。
  - **Driver 线**（本次推进）：`04_asio_driver/`，自身作为虚拟 ASIO 驱动（`AuraDSP Driver`），对外暴露 COM In-Proc Server，供外部 DAW（FL Studio 2025、Reaper、Cubase、Ableton Live）打开并将音频推入 AuraDSP。
  - **Zero-DSP 分离原则**：驱动目录严格只做音频缓冲搬运与时钟驱动，严禁耦合算法。

## 1. P1 阶段落地清单

### 1.1 驱动标识与商标合规
- **驱动对外名称**：`AuraDSP Driver`（严格遵守 Steinberg ASIO Usage Guidelines，杜绝侵权前缀/后缀）。
- **注册表宿主键**：`HKLM\SOFTWARE\ASIO\AuraDSP Driver`
- **固定 CLSID**：`{4B617572-6144-5350-4153-494F44727631}`（ASCII 语义：`AuraDSPASIODrv1`）。

### 1.2 源码体系（Clean-Room 现代 C++20 COM）
位于 `core/desktop/windows-drivers/04_asio_driver/`：
- [`AuraAsioDriverGuid.h`](file:///d:/temp_desktop/Proj/JamesDSP/core/desktop/windows-drivers/04_asio_driver/AuraAsioDriverGuid.h)：定义 CLSID 与驱动标识常量。
- [`AuraAsioDriver.h`](file:///d:/temp_desktop/Proj/JamesDSP/core/desktop/windows-drivers/04_asio_driver/AuraAsioDriver.h) & [`AuraAsioDriver.cpp`](file:///d:/temp_desktop/Proj/JamesDSP/core/desktop/windows-drivers/04_asio_driver/AuraAsioDriver.cpp)：直接派生 Steinberg `IASIO` 接口，完整实现 21 个标准虚函数：
  - 能力协商：`init`, `getDriverName`, `getDriverVersion`, `getChannels` (2 In / 2 Out), `getBufferSize` (64~2048, pref 256), `canSampleRate` (44.1k/48k/88.2k/96k/176.4k/192k), `getSampleRate`, `setSampleRate`, `getLatencies`, `getChannelInfo` (`Float32LSB` 零转换损耗)。
  - 实时时钟泵：`start`, `stop`, `createBuffers`, `disposeBuffers`。
  - 调度器：集成 `AvSetMmThreadCharacteristicsW(L"Pro Audio")` + `timeBeginPeriod(1)` + QPC 亚毫秒自旋微调，确保 `bufferSwitch` / `bufferSwitchTimeInfo` 精确至微秒。
- [`AuraAsioClassFactory.h`](file:///d:/temp_desktop/Proj/JamesDSP/core/desktop/windows-drivers/04_asio_driver/AuraAsioClassFactory.h) & [`AuraAsioClassFactory.cpp`](file:///d:/temp_desktop/Proj/JamesDSP/core/desktop/windows-drivers/04_asio_driver/AuraAsioClassFactory.cpp)：标准 COM `IClassFactory` 现代 C++ 实现。
- [`AuraAsioDriverMain.cpp`](file:///d:/temp_desktop/Proj/JamesDSP/core/desktop/windows-drivers/04_asio_driver/AuraAsioDriverMain.cpp)：`DllMain`, `DllGetClassObject`, `DllCanUnloadNow`, `DllRegisterServer`, `DllUnregisterServer`（双向支持 64 位注册表视图与 HKCU 开发者回退）。
- [`AuraAsioDriver.def`](file:///d:/temp_desktop/Proj/JamesDSP/core/desktop/windows-drivers/04_asio_driver/AuraAsioDriver.def)：导出 COM 4 个标准符号。
- [`register_driver.ps1`](file:///d:/temp_desktop/Proj/JamesDSP/core/desktop/windows-drivers/04_asio_driver/register_driver.ps1)：提供一键体检 (`-Action status`)、提权注册 (`-Action register`) 与反注册 (`-Action unregister`) 运维脚本。
