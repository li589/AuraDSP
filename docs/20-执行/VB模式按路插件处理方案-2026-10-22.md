# VB 模式按路插件处理方案 v2（2026-10-22 修订，覆盖 v1）

> v1（同日早版）已完成引擎链开关/桥掩码/设置页复选框并验证。本版按用户实测反馈修订：
> 插件页逐路显示区撤除，改在「打开界面」上做总线下拉；预设功能整体移除（保留加载状态记录）。

## 修订背景

**实测反馈**：① "似乎还是只处理 A1"；② 插件页 A1–B3 逐路显示区多此一举——用户的心智模型是
"插件处理多路 = 每路都配了插件，调某一路的插件就打开那一路的插件界面"；③ 预设按钮鸡肋
（深度做需逐插件适配），取消；④ 设置页 VB 复选框界面 OK，保留。

**"只处理 A1"归因（非代码缺陷，属部署问题）**：
- `dist/AuraDSP-Windows-x64/auradsp_engine.dll` 仍是 **10-17 23:59** 旧二进制（早于 433963a
  全组扇出与链开关 ABI）；App 按「exe 同目录优先」加载。桥侧 smoke 已证 8 组扇出 + 掩码跨
  重建存活（见 `docs/30-审查/VB按路插件处理-实施验证报告-2026-10-22.md`）。
- **处置**：执行后用最新引擎/桥 DLL 更新 exe 同目录（build/windows/x64/runner/Release 与
  dist 包），由用户在 Voicemeeter 实机复核。

## 语义定案（v1 保留部分）

- **引擎链级开关（per-handle）**：`auradsp_plugin_chain_set_enabled/get_enabled`，关闭时
  `processInterleavedN` 早退，该 handle 全部插件（含 PDC）不进路径；挂载状态保留。**不变**。
- **桥内掩码**：`vb_plugin_group_enable(mask)`（bit g = 组 g 总线吃插件链，默认 0xFF），
  跨 CHANGE 重建重放。**不变**。
- **Dart 持久化**：`vbPluginGroupMask`（config v6）。**不变**。
- **设置页 VB 总线行复选框 + Tooltip**：**不变**（用户确认 OK）。

## v2 改动一：插件页逐路显示区撤除

- 删除 `plugins_page.dart` L297-300 的 `_VbPluginBuses` 挂载与 `plugins/plugins_slots.dart`
  L160-262 的 `_VbPluginBuses` 类。设置页复选框 + 本方案的总线下拉已覆盖全部交互。

## v2 改动二：「打开界面」按路打开（核心）

### 现状根因
`VmBridge.cpp` 的 `PluginEngine()` 恒返回 `eng[0]`（L79-81），`vb_plugin_slot_show_editor`
只开 A1 组实例的 GUI——即"编辑器单实例（eng[0]）"限制。`PluginEngineAt(g)` 已存在可直接用。

### 新链路（group 维度贯穿）
```
UI 下拉选组 g → manager.showEditor(slot, group: g, title)
  → isolate 'pluginSlotShowEditor' {slot, group, title}
  → bridge.showEditor(slot, group, title)
  → vb_plugin_slot_show_editor_g(slot, group, title)   [新]
  → PluginEngineAt(g)->showEditor(slot, title)         [该路引擎实例的 GUI]
```
- 新增 `vb_plugin_slot_show_editor_g/_close_editor_g/_is_editor_open_g`（带 group）；旧三函数
  保留（inproc/非 VB 路径与兼容）。PluginBridge.h Fns 可选解析同链开关模式（旧桥 DLL 不炸）。
- close/isOpen 同步带 group：Dart 侧记住"当前编辑器路"（= 下拉选中项），关闭走同一路。
- 编辑器标题带路名：`'<插件名> - <路名> - AuraDSP Host'`（沿用 C1 多槽区分思路）。
- 语义：每路引擎各持一份插件实例（433963a 已扇出加载），改某一路 GUI 参数只作用于该路实例——
  正是"调某一路的插件就打开那一路的界面"。

## v2 改动三：总线下拉选框（仅 VB 模式）

- **位置**：插件页 Hero 卡 trailing，原「预设」按钮位（「打开界面」右侧）。
- **显示条件**：`audioMode == 'vbcallback'` 且 `vbInfo.groups > 0`。其它模式
  （VAIO/ASIO/WASAPI/sysapo）**不显示**，「打开界面」行为与现在完全一致。
- **选项**：`vbPluginGroupMask` 勾选的路，名字取 `vbBusNames(edition)`（Potato → A1…A5,B1…B3）。
- **掩码为 0（设置页全不选）**：下拉禁用（onChanged null）+ 显示"旁路"；「打开界面」同步禁用，
  Tooltip 说明"所有总线均已旁路插件处理"。
- **选中态回落**：设置页取消勾选导致当前选中路失效时，回落到最低勾选路；全不选时保持原位（禁用态）。
- **状态**：`vbPluginEditorGroup`（AppModel 字段，会话级，不持久化；切换 notifyListeners）。
- **主题**：下拉用仓库既有 Dropdown 主题模式（paletteOf + labelOf/captionOf + 紧凑密度），
  不引第三方组件，边框/圆角/hover 与设置页下拉一致。

## v2 改动四：预设功能整体移除（保留加载状态记录）

**移除**（按钮和逻辑）：
- UI：`plugins_hero.dart` 预设 OutlinedButton；`plugins_page.dart` `_showPresetDialog` 全方法
  + `_ActivePluginHero.onShowPresets` 形参及调用链；头注第 3 条更新。
- Manager（plugin_manager.dart）：`_getPresetsDir`/`savePreset`/`loadPreset`/`listPresets`。
- Isolate（audio_isolate.dart）：`pluginSlotSavePreset`/`pluginSlotLoadPreset` case 及
  `pluginSlotPresetSaved`/`pluginSlotPresetLoaded` 事件。
- FFI（bridge_plugin_ffi.dart 等）：savePreset/loadPreset 绑定（含 Wrap）。
- l10n：`dlgPreset`/`plugPresetTitle`/`plugPresetSaveLabel`/`plugPresetNameHint`/
  `plugPresetList`/`plugPresetEmpty` 三语 arb + gen 删除；`dlgSave`/`dlgLoad` 仅当无其他
  引用时才删（先查引用）。

**保留**（用户明确要求）：
- `pluginMirror[slot]`（loaded/path/id/bypass/stage）及其会话持久化链路——即"每个插件当时
  加载的状态"记录，原样不动。
- 扫描缓存、editor journal、隔离名单机制不动。
- 用户磁盘上既有 `.aurapreset` 文件**不清除**（无副作用；避免破坏性操作）。
