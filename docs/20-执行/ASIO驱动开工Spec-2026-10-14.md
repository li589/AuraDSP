# ASIO 驱动开工 Spec（2026-10-14）

> 目标：落地 Win 四种底层音频模式的最后一块——**ASIO 专业模式**（`audio_modes.dart` 四模式中的 `asio`），
> 使 AuraDSP 能以 **ASIO 宿主（host）** 身份直接驱动专业音频接口/虚拟 ASIO 驱动，
> 把 `engine/` 的 RT-Safe DSP 链插入 ASIO 缓冲区切换回调，获得低于 WASAPI 的延迟与多声道能力。
> 前置阻塞已清除：Steinberg ASIO SDK 2.3.4 实体位于本机 `C:\FreeRulesPrograms\BasicToolkits\SteinbergDev\ASIOSDK`，
> 且本机已装 7 个可实测的 ASIO 驱动（含 Voicemeeter 虚拟 ASIO 家族）。
> 铁律沿用：本目录只做传输与格式搬运，**不承载任何具体音效算法**（算法全在 `engine/`）。

|---|---|---|

| **`asio`** | **`04_asio_engine/`（本 Spec）** | 🔵 **本次开工** |

### 0.2 范围边界（先划清）

- **做**：ASIO **宿主**——枚举/加载第三方 ASIO 驱动（COM `IASIO`）、查询能力、创建缓冲区、
  在 `bufferSwitch` 回调内调用 `auradsp_process` 完成 DSP、可视化帧透出、参数即时下发。
- **不做**：不写 ASIO **驱动**（那需要 WDK + 音频设备，属 `01_vaio_driver/` 范畴）；
  不碰 DSD（ASIO 2.1 DSD 支持，`DSDTranscoder` 在位，v1 仅 float32 PCM，DSD 列风险登记）；
  不改 `engine/` 任何算法；不改 ADR-001 进程内主力结论（ASIO 与 sysapo/vbcallback 并列为用户可选后端）。

## 2. 架构设计

### 2.1 目录布局（`core/desktop/windows-drivers/04_asio_engine/`，新建）

```text
04_asio_engine/
├── README.md            # SDK 登记 + 许可路线 + 构建前提（本 Spec §1 的落地版）
├── AsioHost.h/.cpp      # IASIO RAII 封装：枚举→init→能力查询→createBuffers→start/stop
├── asio_probe.cpp       # 可执行：枚举 + 能力查询 JSON 输出（无音频，零风险）
├── asio_tone.cpp        # 可执行：选定驱动播放正弦 N 秒（对标 tone_play）
└── AsioBridge.h         # P2 常驻桥 C ABI 声明（镜像 VmBridge.h 契约，先声明后实现）
```

P2 起追加 `AsioBridge.cpp` + `AsioBridge.def` → `auraasio_bridge` SHARED（app isolate FFI 调用）。

### 2.2 宿主时序（标准 ASIO host flow）

```
AsioDrivers::getDriverNames（注册表 HKLM\SOFTWARE\ASIO 枚举）
  → loadDriver(name)（CoCreateInstance → IASIO）
  → IASIO::init(sysHandle)
  → getChannels / getBufferSize / canSampleRate / getSampleRate / getLatencies
  → createBuffers(ASIOBufferInfo[], ASIOCallbacks{bufferSwitch, sampleRateDidChange, asioMessage})
  → start() … bufferSwitch(doubleBufferIndex, directProcess) 循环
  → stop() → disposeBuffers() → ASIOExit()
```

### 2.3 RT 契约（铁律，与 02/05 同款）

- `bufferSwitch` 即 RT 线程（驱动自有线程）：**零分配、零锁、零 syscall、零日志**；
  仅做 ① ASIO 分声道缓冲 → 引擎交织 float32 的搬运（memcpy 级）② `auradsp_process`
  ③ 交织 → 分声道回写 ④ viz 帧写入 SPSC 环（与 `auradsp_viz_read` 同 408B 布局）。
- 控制面（`start/stop/set_param/status`）全在 Dart 线程或桥内辅助线程，与 RT 线程仅经
  `std::atomic` 交接（复用 `engine/` 既有 `Params` 原子表）。
- **MMCSS 注意**（SDK 2.3 pdf p.46）：MMCSS "Pro Audio" 是**每线程**属性，宿主无法替
  驱动的回调线程提优先级——因此 RT 保障靠"回调工作量有界"（仅 memcpy + 引擎 process），
  不得在回调内做重活；VM/FLStudio 等驱动的自有调度由其负责。此点列入风险 R-2。
- 声道策略：ASIO 驱动常为多声道（VM 虚拟 ASIO 8 出）。v1 取**前两个输出通道**作为
  stereo 对（与引擎 2ch 契约匹配），通道对选择列入 P2 参数面。
- 采样率策略：以驱动 `getSampleRate` 为准创建引擎（引擎侧本就支持任意 sr；
  不支持的目标率走 `canSampleRate` 预检并在 UI 明示，不静默重采样）。

### 2.4 与 APP 的集成契约（P3，镜像 VmBridge）

`audio_modes.dart` 的 `asio` 已就位（仅持久化）。P3 接线后：

- isolate 启动时读模式 → `asio` 则加载 `auraasio_bridge.dll`（安装捆绑 + `verify_dll_copies` 扩项）；
- 设置页新增**驱动选择器**（`asio_probe` 的 JSON 枚举驱动 + 缓冲大小档）；
- 状态/可视化复用既有 `state.dart` 监听面（408B VizFrame 解析已有，零新协议）。

## 3. 分期实施计划

### Phase 1 — 探测与发声（本 Spec 批准后执行，无音频风险）

| 文件 | 内容 | 验收 |
|---|---|---|
| `AsioHost.{h,cpp}` | `AsioDrivers` 封装 + IASIO 生命周期 + 能力查询结构体 | 编译零警告（`/W1`） |
| `asio_probe.cpp` | 枚举注册表 → 逐个 `init`/查询 → JSON 输出（驱动名/版本/输入输出声道数/缓冲 min-max-preferred/延迟/采样率） | `smoke_asio_probe.py`：JSON 驱动集合 == 注册表 7 项；每驱动字段非空且合理 |
| `asio_tone.cpp` | 选定驱动 → 创建缓冲 → 正弦 440Hz 播放 N 秒（默认 3s）→ 干净退出 | `smoke_asio_tone.py`：对 `FL Studio ASIO` 跑 3s，退出码 0，无崩溃无爆音断言（峰值域检查） |

- 构建集成（父 `CMakeLists.txt` 追加， SDK 路径缺失即 FATAL 并提示）：

```cmake

    "${ASIODIR}/AsioHost.cpp"
    "${ASIO_SDK_ROOT}/common/asio.cpp" "${ASIO_SDK_ROOT}/common/asiodrvr.cpp"
    "${ASIO_SDK_ROOT}/common/combase.cpp" "${ASIO_SDK_ROOT}/common/register.cpp"
```

## 5. 风险登记

| # | 风险 | 缓解 |
|---|---|---|
| R-1 | 某些 ASIO 驱动 `init` 需窗口句柄/控制面板交互（FL Studio ASIO 弹设置窗） | probe 用 `init(nullptr)` + 超时；驱动控制面板交 `controlPanel()` 由用户在 P3 设置页触发，桥内不碰 |
| R-2 | MMCSS 无法覆盖驱动回调线程（§2.3） | 回调工作量有界；长任务（扫描/文件加载）一律控制线程 |
| R-3 | 驱动 `bufferSwitch` 中掉线/重置回调重入 | `asioMessage` 回调内置状态机；stop 幂等 + 在途等待（同 05 `vb_test_stop` 50ms 模式） |
| R-4 | 多声道驱动缓冲区布局差异（VM 8ch vs FLStudio 2ch） | v1 固定取前两声道；通道对参数化留 P2 |
| R-5 | GPLv3 路线与未来闭源分发冲突 | 现已明文锁定 GPLv3；若商业模式变更先获 Steinberg 书面协议（§1.2） |
| R-6 | DSD 驱动（DSDTranscoder）会话格式非 PCM | v1 显式拒绝非 float32 格式并上报，不猜 |
