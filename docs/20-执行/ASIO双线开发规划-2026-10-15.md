# ASIO 双线开发规划（2026-10-15）

## 0. 一句话决策

- **Client 线**（现状，已落地）：打开第三方 ASIO 驱动，处理其输入→输出。
  对应 `04_asio_engine/`（宿主）+ `bridge/asio_bridge/`（FFI 桥）。
- **Driver 线**（新立项）：自身作为 ASIO 驱动被 DAW 打开（FL Studio 设备列表里
  能选到我们），DAW 音频灌进来 → DSP → 选定后端出去。
- **顺序**：VAIO 先行（WDM 解决"DAW→我们"，不需要 ASIO 协议）；
  Driver 线排 VAIO 之后，是协议补充（低延迟 + 输入通道），不是前置。

## 1. Client 线现状（done，回归全绿）

- 宿主：枚举/load/init/channels/rate/buffer/start/stop（`04_asio_engine/`）。
- 桥：detect/start/stop/status/set_param(+_str)/get_param(+_str)/viz/bypass/test，
  12 导出；字符串通道 + LiveProg 回放已对齐 VB。
- App：驱动选择器 + 缓冲档 + 输出对 + 热切换 + srMismatch 明示。
- Smoke：`smoke_asio_{probe,tone,bridge}.py`（FL Studio ASIO 实测 44.1k/512）。
- 约束：ASIO 驱动独占，一次一家；占用优雅让路（NOTE 不判红）。

## 2. Driver 线设计

### 2.1 身份与注册

- COM 服务器 DLL：`DllGetClassObject` + `DllRegisterServer/Unregister`，
  注册 `HKLM\SOFTWARE\ASIO\<名>`（CLSID + DLL 路径），需管理员安装。
- **名字待 ADR**：04 README 铁律——v1 不使用 ASIO 商标（Usage Guidelines）。
  驱动显示名带 "ASIO" 即踩线，立项前另立 ADR 定名，默认工作名 `AuraDSP ASIO`。
- IASIO 全方法：init/getDriverName/getChannels/get/setSampleRate/getBufferSize/
  createBuffers/start/stop/getLatencies/…；`bufferSwitch` 回调内调
  `auradsp_process`（复用引擎，不碰算法；RT 铁律沿用）。

### 2.2 后端路由（Driver 收到 DAW 音频后的去处）

Driver 本身只是"壳"，后端复用现有模式（App 侧新增"ASIO 驱动后端"选择器）：

| 后端 | 说明 | 状态 |
|---|---|---|
| WASAPI 渲染（默认输出） | 最先可用，无依赖 | ✅ 随 P2 |
| VAIO 虚拟声卡 | VAIO 点亮后首选，系统声闭环 | ⏳ 等 VAIO |
| VB 总线 | 跟随 vbcallback 模式 | ✅ 逻辑已有 |
| ASIO-Client 驱动 | 套娃（抓别的驱动输出），延迟双份 | 可选，不推荐默认 |

### 2.3 谈判与预算

- 采样率/缓冲：DAW 说了算（`setSampleRate/canSampleRate`），引擎按协商值建；
  只认驱动给的值（与 VB"只认有效 STARTING"同款思想）。
- 延迟预算：双份缓冲（DAW 侧 + 后端侧），如实展示，不承诺单份。
- 独占语义：Driver 被 DAW 独占期间，Client 线不得开同一底层设备
  （已有 busy 让路机制，复用）。

## 3. 分期与出口

- **P0**：名字/商标 ADR + VAIO 落地（前置依赖，无之不开工）。
- **P1**：COM 骨架——注册/反注册，DAW 能枚举到；init/getChannels 走通；
  smoke 做注册表对账。门：FL Studio 列表出现且可选中。
- **P2**：bufferSwitch 直通（DAW→后端，无 DSP 也能响）+ 端到端延迟实测。
  门：440Hz 测试音走 Driver 通路可闻。
- **P3**：DSP 接入 + App 后端选择器 + 参数/字符串通道（复用 Client 线契约）。
  门：开 Bass 可闻变化，bypass A/B 成立。
- **P4**：DAW 矩阵（FL/Cubase/Live/Reaper）+ smoke（编译/回读/重建语义按
  Driver 重定）。门：四 DAW 全绿。
- **P5**：安装器/签名/卸载清理（注册表无残留）。

## 4. 目录预留

Driver 线单开 **`06_asio_driver/`**（transport/host 性质，沿用编号制；
**不进 `bridge/`**——桥是 FFI 薄适配，Driver 是 COM 服务器，两码事）。
Client 线文件不动（只改注释，已做）。

## 5. 非目标（首版不做）

DSD、ASIO 2.x 特有扩展、多客户端并发、32 位构建。
