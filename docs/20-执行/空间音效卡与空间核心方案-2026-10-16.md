## 1. 三家在干什么（概念层）

- **Dolby Headphone（DH1/DH2/DH3）**：5.1 声道 → 固定角度 HRTF 摆位（L/C/R/LS/RS）
  → 离散早期反射 → 后期扩散混响 → 双耳。房间感来自"早期反射图案 + 混响尾"，
  个性化=无。这是我们默认风格的模板。
- **DTS Headphone:X**：扬声器位置映射 + 耳机校准 EQ。我们有 DDC/VDC 等价物，
  不必另起数据线。
- **中性派（Bauer/BS2B/Sonic）**：ITD/ILD + 串音处理，不加房间味。对应我们的
  crossfeed（BS2B 已在链）+ haas（延迟）。

## 2. L1 参数化 HRTF（新引擎 stage `spatial`，无数据）

 per-虚拟扬声器（默认 5.0 摆位，deg）：L(-30) C(0) R(+30) LS(-110) RS(+110)：

| cue | 实现 | 公式/范围 |
|---|---|---|
| ITD | 短延迟线/声道 | Woodworth：`dt = r/c·(θ+sinθ)`，r=8.75cm，最大 ~0.65ms |
| ILD | 高频头影衰减 | 对侧声道 2kHz 以上 shelving，按 \|θ\| 0..-6dB |
| pinna | 2 个 peaking/notch（8k/12k 附近，±3dB 内） | 方向感点缀，不做精确耳廓 |
| Width | 摆位张角缩放 0.5..1.5× | 默认 1.0 |

输入：立体声上混（L→L/C/R 按能量分，R 同理；v1 不做真 5.1 分离）。
RT 安全：延迟线预分配 + 整数下标 + biquad 系数控制线程算（沿用 filter 模式）。

## 3. Dolby 房间感 = L1 + 早期反射 + freeverb（无新混响引擎）

- **早期反射**：8 个离散 tap ±配对（时间 5.5/9/14/21/30/42/55/68ms、
  增益 ±{0.25,0.18,0.12,0.07}、偶→L 奇→R），同 |g| 配对保证左右反射能量
  严格相等（7 tap 左4右3 时 mono 下 L/R 差 7%，已修复），
  room 参数整体缩放 tap 时间（复用 roomsize 语义，0.5..2.0×）。
- **后期**：直接复用 freeverb（decay/damp/wet 已接线；roomsize/width 刚接好）。
- 出厂默认（Dolby 房）：room=1.0，早期电平中等，wet 0.35，width 1.0。
- DTS 预设：早期反射关小/关掉 + 提示联动 DDC；中性预设：只要 L1 摆位，
  反射全关、混响 bypass。

## 4. 新参数面（`spatial.*`，6 个）

`spatial.enable` / `spatial.style`（0=Dolby 房，1=DTS 定位，2=中性，整组联动下面三个的默认值）/
`spatial.room`（0..1，早期反射电平 + tap 时间缩放）/
`spatial.width`（0.5..1.5，摆位张角）/
`spatial.center`（0..1，对白/中置聚焦）/
`spatial.outgain|autogain`（沿用 P-010/P-011 门面，与各效果一致）

## 5. ViPER 概念对照（仅接口事实，无实现接触）

- Reverberation：RoomSize/Damp/Dry/Wet/Width —— 与我方 freeverb 参数面
  一一对应，验证了我们的参数选择。
- VHE：左右分区卷积 + EffectLevel 分档——概念可用（IR 分档），无数据不跟进。
- DiffSurround：DelayTime/WetDryMix/Reverse/LPCutoff——与 haas+filter 重叠，
  不新增。
- Cure：crossfeed 预设制——我们 crossfeed.mode 已覆盖。

## 6. "空间音效"卡结构（A：只分组，不动引擎链）

```
空间音效卡（新）
├─ hero：风格三预设（Dolby 房/DTS/中性）+ 虚拟扬声器摆位图 + 房间混响可视化
├─ 空间核心（spatial.*，展开）
├─ 混响（vendor preset + freeverb，折叠搬入）
```

- 链页不动（19 行照旧）；B 组节点（单行"空间"）进 Phase 2。
- 激励器不进卡（音色非空间）。

## 9. 2026-10-18 复核（代码实况）

> 本节是对 2026-10-16 方案的执行后复核；与上文冲突时以本节为准。

1. **已落地**：`spatial` stage、8 个 `spatial.*` 参数、三风格预设（Dolby 房/DTS 定位/中性）、
   5 虚拟扬声器（-30/0/+30/-110/+110°）、Woodworth ITD、简化 ILD/头影低通、
   全局双 biquad pinna、8 tap 对称早期反射、outgain/autogain、2ms 输出增益平滑。
   测试见 `test/smoke/smoke_spatial.py`（左右对称、双耳差异、早期反射、44.1k、fuzz）。
2. **头跟踪（2026-10-18 Phase A 已更新）**：`spatial.headazim` 已被 `dsp_spatial.cpp`
   消费（块级 ~15ms 平滑），`headtrack` 作为 OpenTrack UDP 外部源开关；UI 已增加
   空间化比例/高度/头部跟随/头部朝向控件。`smoke_spatial.py` 已改为断言
   “headazim 改变声像、headtrack 标志本身不改变 DSP”。
3. **多声道（2026-10-18 B1/B2a 已更新）**：新增 `spatial.binaural`，6/8ch（含 4ch Quad）
   按 FL/FR/C/LFE/SL/SR/BL/BR 映射为双耳 stereo，输出写回 FL/FR、其余置零；VAIO 桥
   在物理立体声端点自动取 FL/FR；VM 泵在 `spatial.binaural=1` 时把每组 8ch 送入引擎。
   本地播放已于 2026-10-18（B2b）按文件源声道数投喂引擎多声道（策略见
   `local_channel_policy.dart`）；**ASIO 双线已于 2026-10-19（B2c）升级为 2/4/6/8 档多声道**
   （`asio_start_ex` / 驱动注册表 `Channels`，输出映射 binaural→FL/FR、否则离散 N）。FDN 晚期混响（B3a）、
   双耳全通扩散（B3b）、矩形房间镜像源早期反射（B3c）均已落地。
4. **HRTF 质量边界**：pinna 是 5 路求和后的**全局**滤波，所有方向共用同一组 8k/12.5k
   peaking/notch；没有仰角、没有前后向专属耳廓线索，前/后与上方定位弱。中置分支
   `|deg|<0.5` 直接双耳相加，绕过 ITD/ILD/pinna，容易头中化。
5. **房间模型边界**：`spatial` 自带镜像源早期反射（B3c，shoebox 12 像）与 8 线 FDN
   晚期混响（B3a），freeverb 是另一套房间且只作用前置；仍无距离/空气吸收/逐源镜像与
   频带 RT60。属“能听出空间”的 L1，不是物理房间渲染器。
6. **资产边界**：`assets/` 仅有 `.irs/.vdc`，无 `.sofa/.hrir`；当前为零数据依赖参数模型。
   实测 HRIR/SOFA 在授权审查前不引入；可先支持用户自带 WAV HRIR 对。
