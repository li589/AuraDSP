# 任意响应 EQ（ArbMag / AutoEq）开工 Spec（2026-10-13）

> 目标：补齐 AuraDSP 处理链中最后一块预留效果器——任意响应均衡器（ArbMag）。
> 核心价值：原生支持 AutoEq 与 Equalizer APO 的 `GraphicEQ:` 文本格式，让用户直接导入成千上万款耳机的校准曲线与自定义频响。
> 基准引擎：基于 `libjamesdsp` 内建的 `ArbitraryMagnitude` / `ArbFIRGen` 最小相位 8192 点 FIR 滤波器生成器与 `FFTConvolver2x2` 分块卷积器。

---

## 0. 总体约定与定位

- **Stage ID**：`arbmag`，对外暴露状态变更：`exposed: false` → `exposed: true`。
- **处理链拓扑顺序**（默认顺序，在 `eq` 与 `convolver` 之间）：
  `input → bassmono → tube → comp → bass → eq → exciter → arbmag → convolver → ddc → liveprog → crossfeed → stereo → haas → reverb → output`
  - **声学原理**：在图形均衡（`eq`）与高频激励（`exciter`）完成主观音色调校后，接入 `arbmag` 进行高精度目标曲线校准（如 Harman Target / AutoEq 补偿），之后再送入空间卷积与脉冲混响。
- **参数闭环规范**：
  - `set/get param` 引擎全对称；
  - `state.dart` 与 `presets.dart` 快照与恢复全对称；
  - `chain_page.dart` 节点拖拽、点击跳转、开关联动全畅通；
  - 延迟上报与独立后台探针支持；
  - 高级面板统一集成：自动增益补偿开关（Auto Gain）与输出增益门（Output Gain Gate，-12.0 ~ +6.0 dB）；
  - 中英日全语言本地化；
  - C++ Smoke 测试与 Flutter 测试 100% 通过。
- **RT 铁律**：音频处理线程零锁零动态分配；字符串解析与 8192 点 FIR 计算在非实时线程完成，双缓冲刷新。

## 1. 算法原理与格式规范

### 1.1 DSP 算法核心
1. **频点插值与最小相位重构**：
   - 输入为任意多个对数频率-增益对（Frequency-dB 节点）；
   - 在对数频域栅格上进行单调插值（`gainAtLogGrid`）；
   - 利用离散希尔伯特变换（Hilbert Transform）从幅频响应重构因果最小相位谱（Minimum Phase Spectrum），避免线性相位带来的预振铃（Pre-ringing）；
   - 生成 8192 点 FIR 脉冲响应（`FILTERLEN = 8192`）。
2. **低延迟分块卷积推流**：
   - 采用 `FFTConvolver2x2`，基于分块 FFT 快速卷积处理立体声流；
   - 切换曲线时在后台重新生成脉冲响应，并通过 `FFTConvolver2x2RefreshImpulseResponse` 进行双缓冲平滑过渡，杜绝爆音。

### 1.2 字符串协议格式（GraphicEQ 标准）
完全兼容 AutoEq 与 EqualizerAPO 标准文本：
```text
GraphicEQ: 20 0.0; 25 -0.5; 50 1.2; 100 2.5; 1000 -1.0; 10000 3.0; 20000 0.0
```
- 支持带前缀 `GraphicEQ:` 或纯数值列表；
- 节点分隔符支持分号 `;`、逗号 `,` 或换行符；
- 节点内部格式为 `频率(Hz) 增益(dB)`。

### 2.1 引擎底层参数表

| :--- | :--- | :--- | :--- | :--- |
| `arbmag.enable` | `int32_t` | R/W | `0` | 开关（0=旁路，1=启用） |

## 4. 延迟评估与测量隔离

- **标称延迟**：
  - `arbmag` 采用分块 FFT 卷积，理论标称延迟约为当前音频块尺寸的时间跨度（如 128 采样点 @48kHz 对应约 2.67 ms）；
  - `compute_latency` 中登记该分块感知时延；
- **脉冲响应实测（探针）**：
  - 在 `auradsp_engine.cpp` 的 `probe_isolate` 中注册 `arbmag`；
  - 测量时注入单位冲激脉冲，计算首波通过 FFT 卷积器的到达时间；
  - 未加载有效曲线（或增益恒 0）时报告直通 0 延迟。
- **实时音频流保护**：
  - 测量沿用已重构的后台独立 `Isolate.run` 异步执行机制，实时音频泵 100% 零卡顿。
