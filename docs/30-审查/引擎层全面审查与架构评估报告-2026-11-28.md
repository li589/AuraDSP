## 三、 单开专项可行性深度调研（基于源码实证与 `source/` 借鉴）

### 3.1 【单开专项 A】Legacy 效果器高采样率支持度与“双采样率域”重构评估

### 3.2 【单开专项 B】Convolver 真多声道（5.1 / 7.1 + M→N 矩阵）重构评估

**核心问题**：当前 [convolver1D.c:100-212](file:///d:/temp_desktop/Proj/JamesDSP/engine/legacy/jdsp/Effects/convolver1D.c#L100-L212) 与 [engine_convolver.cpp:198-212](file:///d:/temp_desktop/Proj/JamesDSP/engine/chain/engine_convolver.cpp#L198-L212) 强拒 `3/5/6/7/8` ch IR，MC 链只抽 FL/FR 进卷积，且 `TwoStageFFTConvolver` 每个实例自带 `pthread_t + condvar` 并持 `jdsp_lock` 阻塞重载。

**为何需要单开专项**：若强行把现有 `TwoStageFFTConvolver` 扩成 8 声道，将产生 **8 条独立后台线程与每块锁/条件变量同步**，依然不支持 `M→N`（如 7.1 → 2ch HeSuVi 双耳或 4ch True Stereo）路由，也无法消除 `jdsp_lock`。

**推荐 `source/` 最佳实践组合**（估算工作量约 1–2 周专项）：
1. **核心卷积引擎**：借鉴 **`source/lsp-plugins`**（LGPL-3.0+）[`Convolver.cpp`](file:///d:/temp_desktop/Proj/JamesDSP/source/lsp-plugins/modules/lsp-dsp-units/src/main/util/Convolver.cpp) 与 [`impulse_reverb.cpp`](file:///d:/temp_desktop/Proj/JamesDSP/source/lsp-plugins/modules/lsp-plugins-impulse-reverb/src/main/plug/impulse_reverb.cpp)：
   - **零后台工作线程的非均匀分区卷积**：前 128 样本时域直卷 + 二进制进位掩码递增 FFT 分区阶数 + 长尾块按子块增量均摊计算，**无需任何 RT 互斥锁或线程等待**；
   - **声道相位错峰（`phase` offset）**：错开 8 个声道长尾 FFT 触发帧，防止每逢整数块边界所有声道同时引发 CPU 尖峰；
   - **`M→N` 矩阵泛化**：支持直通每声道（`1/2/6/8ch` + `convolver.channels` 掩码）以及 `fPanIn/fPanOut` 任意矩阵混音。
2. **SIMD 复数乘加与零锁热切换**：借鉴 **`source/equalizerAPO64`** [`libHybridConv_eapo.cpp`](file:///d:/temp_desktop/Proj/JamesDSP/source/equalizerAPO64/libHybridConv-0.1.1/libHybridConv_eapo.cpp) 的平面 `Re[]/Im[]` AVX2/FMA 乘加循环，并直接复用本仓已验证的 **`PoolBank` 双槽影子替换（`eq_pool`/`arbmag_pool` 范式）** 完成 RT 零阻塞热切换。

## 五、 审查结论与下一步执行建议

1. **优先止血**：建议按 **Batch 1 → Batch 2 → Batch 3/4 → Batch 5** 节奏推进；其中 **Batch 1** 的 `<44.1kHz` ASRC 溢出、POSIX 递归死锁、`dyneq` 低采样率极点发散、`dsp_shelf/filter` 原子撕裂以及插件 `setBypassSlot` 10s–60s 阻塞反转均为无前置条件的稳定性隐患，应优先打包落地。
2. **明确降噪**：尊重既定边界——不再修改 `bassmono` C/LFE 可选配对逻辑，也不为超出设计上限的 `384 kHz` 浪费工时。
3. **重型特性单独开轮**：Legacy 高采样率去 ASRC（专项 A）与多声道非均匀分区 Convolver（专项 B）涉及底层算法重构与第三方/开源范式引入，已明确单列为独立专项轮次，避免与当前核心链稳定修复混为一谈。
