# 脚本页面与脚本功能检查升级报告（2026-10-13）

> 范围：脚本编辑页 UI（`liveprog_page.dart` + `eel_editor_support.dart`）、EEL2 引擎后端
> （`liveprogWrapper.c` + `auradsp_engine.cpp`）、Dart 桥接（`state.dart` / `audio_isolate.dart` /
> `auradsp_ffi.dart`）、持久化（`presets.dart` / `session_memory.dart`）。
> 方法：只读检查，未改代码。定位差异化：EasyEffects / Viper4Windows 均无用户脚本层，
> 脚本是 AuraDSP 独有的可编程 DSP 护城河。

## 2. 检查结论（缺什么，按严重度）

### P0：错误不可见
- 编辑页不展示 `lpStatus/lpError`（仅全局 EventBanner 一闪而过），编译失败后编辑器无任何标红。
- NSEEL 错误无行列号（P-003 二期未做），用户不知道错在哪一行。

### P0：状态重启丢失 + 默认值三处打架
- 会话只恢复 `lpCode`，`lpEnabled` 恒 false、`lpParams` 恒 0：重启后脚本静默不生效，滑块归零。
- 默认值四源互斥：`state.dart` 全 0 / `EelSliderParser` 回填 `0<0,1>` / 无 meta 滑块 `-1..4` / 内置模板 `slider1:1.0<0,2>`。
  后果：同一脚本在“解析—显示—引擎”三处初值不一致。

### P1：Linter 太弱，错误全漏到引擎
- 现 Linter 仅括号/引号/块注释配对。`@init/@sample` 缺失、空 `@init`
  （vendor 要求 ≥1 语句，内置模板恰好是空段高危样例）、`slider9+` 越界引用、
  `srate` 只读误写，全部要下发编译才暴露。

### P1：大脚本编译卡音频
- 编译在控制线程持 `jdsp_lock` + 2×strLen malloc；上限 256 KiB 但无防抖/超时/取消。
  快速连击“应用”或加载大脚本时音频泵被饿死。

### P1：脚本入口未进 FileGate
- 外部目录递归加载无大小/magic/编码校验，与 `APP-插件与信号图扩展规划 §5.4` L1/L2 要求违背；
  恶意 `.eel`（超大/非 UTF-8）可直接打到编译器。

### P2：库管理与状态分叉
- 库无重命名/删除，`save()` 静默覆盖无确认。
- `unload` 把 `lpCode` 置 null：编辑器内容与引擎态分叉（编辑器还有字，引擎已空）。

## 3. 升级方案

### 3.1 错误可见（P0）
1. 编辑页绑定 `lpStatus/lpError`：状态胶囊（灰-未加载 / 绿-运行中 / 红-编译失败 + 错误码中文文案）；
   失败时编辑器顶部内联错误条，不依赖 EventBanner。
2. 落地 P-003：`liveprogWrapper.c` 把 NSEEL `checkErrorCode` 的行列透出为
   `liveprog.compile{line,col,msg}` 事件，编辑器段级飘红 + 点击跳行。
3. 修复内置模板空 `@init`（加一条有效语句或删段），消除自带坏样例。

### 3.2 状态持久化 + 默认值统一（P0）
4. 会话补 `lp{enabled,params}` 两字段；预设 v2 加 `liveprog{enabled,params,codeHash}`
   （存 hash 不存全文，全文仍走脚本库引用，避免预设膨胀；逻辑见 3.5）。
5. 单一默认值源：以脚本内 `sliderN:` 声明为准 → 无声明用 Parser 回填 `0<0,1>` →
   UI 无 meta 时改用 `0..1`（删掉 `-1..4`）；模板同步，三处一致。
6. `unload` 不再清 `lpCode`（改清 `lpEnabled=false` + 状态胶囊回“未加载”），编辑器与引擎态一致。

### 3.3 Linter 预检（P1）
7. 在现有 `EelLinter` 加四条零成本规则（复用 `EelSliderParser` 同一正则）：
   `@init/@sample` 段存在性、非空段、`sliderN`（N>8）越界、`srate/num_ch` 写操作警告。
   全部在“应用”前本地拦截，给出行号。

### 3.4 编译防抖与取消（P1）
8. “应用”按钮 500 ms 防抖 + 编译期间禁用按钮 + 状态胶囊转“编译中…”。
9. 控制线程编译加超时守护（>2 s 放弃并报 `lpError=编译超时`），避免持锁饿死音频泵。
   （远期：编译移出 `jdsp_lock`，VM 双缓冲热切——RT 架构改动，单独立项。）

### 3.5 脚本入口 FileGate（P1）
10. 外部目录加载接入 FileGate L1：stat 限 1 MB、UTF-8 嗅探、失败隔离（坏文件跳过并记一条库内警告，不中断整批）。
11. 库加删除/重命名/覆盖确认三件套；保存冲突弹确认框。

### 3.6 资产与一等槽位（P2，增长向）
12. 40 款官方 `.eel` 分级装包（基础/调制/实验）+ 3 个最小示例一键载入（增益/软限幅/展宽）。
13. Liveprog 升为信号图一等槽：多实例、排序、旁路、延迟探针可测化（与 chain_meter 探针联动，
    延续 `.ai/memory` 中“liveprog×2 做强效应探针”的验证范式）。
