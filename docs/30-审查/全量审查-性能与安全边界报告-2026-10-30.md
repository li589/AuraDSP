| E-01 | **中** | `engine/chain/engine_chain.cpp:520-536`（`apply_comp`）→ `engine/legacy/jdsp/Effects/dynamic.c:2054` → `engine/legacy/jdsp/generalDSP/interpolation.c:19-21` | 7 个 `comp.freqN` 各自独立钳制 [20,20000]，**不校验单调递增**。用户把频带滑块拖交叉后：① legacy `pchip` 对无序横坐标持续 `printf`（本次探针实时调参期间触发 **5008 次 / 389 KB 日志**，控制线程同步 IO）；② `upper_bound` 在无序数组上取段错误，压缩增益曲线失真。现有 `smoke_effects_allparams` 只验证单参数边界，未覆盖交叉。 | 在 `apply_comp` 组包时按 `freq` 成对排序（或逐带钳制到相邻带之间）后再 `CompressorCommit`；legacy `printf` 以 `[PATCHED-AuraDSP P-xxx]` 方式移除/降级并登记 `engine/legacy/PATCHES.md`；补一条交叉频带 smoke。 |

## 3. 引擎性能评估

### 3.1 方法

- 48 kHz / 双声道 / 480 帧块（10 ms），ctypes 直调 Release DLL。
- 每点 30 块预热 + 200–300 块采样，报告 **p50**（已观察到 p95 受 Python/系统调度噪声污染，
  p50 在复测间稳定，故作为主口径）；另记 p95/max 观察尖峰。
- Part 1：参数表解析为真相源，逐效果器单独启用，遍历该效果器**全部有界参数**的 min/中点/max。
- Part 2：20 节点全链（`graph.effects` 确认 21 条注册项，ddc 因无 VDC 资源跳过）+
  2048-tap 合成 IR 卷积；控制线程以 1–3 ms 间隔随机改参，主线程连续处理 3000 块（30 s 音频）。
- 复现：`python tools/probe/bench_full_chain.py`（原始数据 `.tmp/bench_full_chain.json`）。

### 3.2 单效果器（p50，µs/10 ms 块）

基线（全效果关闭）= **15.2 µs**（0.15% 单核）。

| 效果器 | 开启耗时 | CPU 占比 | 最坏参数点 | 最坏耗时 |
|---|---:|---:|---|---:|
| comp | 305.3 | 3.05% | `comp.channels=0`（全声道对） | 330.2 |
| reverb | 124.6 | 1.25% | `reverb.outgain=6` | 126.2 |
| stereo | 122.1 | 1.22% | `stereo.mix=0.5` | 122.1 |
| tube | 92.9 | 0.93% | `tube.channels=0` | 100.2 |
| eq | 61.6 | 0.62% | `eq.channels=255` | 61.6 |
| convolver（2048 tap） | 48.7 | 0.49% | — | 48.7 |
| bass | 45.6 | 0.46% | `bass.cutoff=30` | 85.5 |
| spatial | 44.0 | 0.44% | `spatial.headazim=180` | 47.3 |
| exciter | 34.0 | 0.34% | `exciter.channels=0` | 35.0 |
| limiter | 29.7 | 0.30% | `limiter.threshold=-24` | 37.4 |
| shelf / filter / crossfeed / haas / gate / bassmono / dyneq / arbmag / loudness / deesser / liveprog | 15.5–17.4 | ≤0.18% | 单参数波动 ≤1 µs | ≤18.3 |
| ddc | SKIP（需 `.vdc` 资源） | — | — | — |

结论：**comp 是唯一单节点 CPU 大头**（默认 tfres=1 的 CWT 重路径），其次 reverb/stereo/tube；
其余节点几乎与基线噪声同量级。参数极值对耗时影响均在 1 dB 级以内（bass.cutoff=30 除外）。

### 3.3 全链条启动 + 实时调参

| 指标 | 结果 |
|---|---|
| 冷启动 create | **53.995 ms** |
| 全链参数下发（含 IR 加载） | **8.502 ms** |
| 首块处理 | **0.503 ms** |
| 稳态（3000 块 = 30 s 音频） | p50 **644.5 µs** / p95 **827.1** / p99 **928.2** / max **1429.6 µs** |
| 单核占用 | **6.7%** |
| xrun 代理（块耗时 >10 ms） | **0** |
| 实时调参 | 764 次，**0 失败**；set p50 **11.2 µs** / p95 **1368 µs** / p99 **2160 µs** / max **12789 µs** |
| 输出健康 | 全有限，峰值 0.728 |

结论：48 kHz 立体声下，20 节点全链有 **~15 倍实时余量**（6.7% CPU），且与 UI 高频调参并发时
音频侧无一次 xrun。控制侧 p95 偏高来自 crossfeed IIR 重建（1.8–3.0 ms/次）；
**注意**：ddc、无脚本 liveprog、无曲线 arbmag 在全链中近似直通，因此 6.7% 是“含 comp/卷积/
混响”的实测值，若生产预设叠加 DDC + 复杂 EEL + 非平坦 arbmag，需按上述单节点成本追加预算
（ddc/liveprog 属毫秒级以下到数毫秒级，仍有充足余量）。

## 4. 安全边界检查

| 边界 | 检查内容 | 结果 |
|---|---|---|
| FFI/ABI | `AURADSP_ABI=2`、VizFrame 1600 B 双重编译期哨兵、3 桥 140 导出 1:1、Dart 定长镜像 | **PASS**（`smoke_abi_consistency`、`smoke_g7_5_bridge_exports`、`smoke_g7_1_viz_mirror` 38 项断言） |
| 参数越界 | 浮点 NaN/Inf 拒绝、min/max 钳制、`bytes<4` 拒绝、bool 归一化、越界后原值保持 | **PASS**（`smoke_effects_allparams`、`smoke_config_and_matrix`） |
| 字符串/自定义参数 | `eq.curve` ≤4096 B、≤64 点、排序 + Nyquist + ±64 dB；`liveprog.code` ≤256 KiB；IR 路径 ≤4096 B | **PASS**（代码审计） |
| 文件门卫 | IR：magic/声道/帧数/NaN/Inf/时长上限/重采样；DDC 加载竞态 | **PASS**（`smoke_config_and_matrix`、`smoke_ddc_race`） |
| RT-Safe | 音频线程零锁/零分配/零 IO；30 s 音频 + 764 次并发调参；comp/ddc/liveprog 影子重建 | **PASS**（0 xrun，max 1.43 ms；3 项 race 门禁全绿；`smoke_rt_vendor_flags` 60/60） |
| Viz 无锁环 | 写端按容量自限、读端按 `available` 截断，无跨线程分配 | **PASS**（`engine_internal.h` 审计） |
| 插件隔离 | 宿主隔离/平台隔离/Dart 侧隔离 | **PASS**（`smoke_platform_isolation`、`smoke_dart_platform_quarantine`） |
| 生命周期 | create 参数域、`nothrow`、destroy 顺序、关闭异常路径 | **PASS**（除 F-01 的边缘泄漏） |
| 已知形式风险 | `process` 空指针未校验（E-02）、延迟读取非原子（E-03）、comp 频带乱序（E-01） | **需修复/观察** |

（T-04 的时序 flaky，非产品缺陷）。
