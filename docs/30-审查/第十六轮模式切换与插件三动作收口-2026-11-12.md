## 事项一：从 APO 切到任何其它模式时自动卸载全部 APO（`17450a9c`）

- **拦截点**：全部模式路径的共同漏斗 `AppModel.setAudioMode`
  （范式分段、附加分段、管线进/出分段均经此；启动/会话恢复不
  经此函数，不会开机弹 UAC）。当前为 sysapo 且目标非 sysapo
  时：仍有端点附加（`apoAnyAttached || apoInstalledEndpoints`
  非空）才拦截；从未附加/已卸净则直切、不等待。
- **等待期**：置 `apoDetachBlocking`——设置页模式卡的范式/
  附加快切换管线三组选项**全部禁选**，模式卡下方出大等待区
  （56px 动画 + 说明文案，三语 l10n 已备）；等待期间一切切换
  请求被吞掉，**首个目标为准**（业主口径：无论如何来回点都
  要等动画落定）。
- **续行与失败**：卸载走既有 `detachSystemApo()` 全端点语义，
  成功 → 以原目标自动重入切换；失败 → 留在 sysapo、回滚各
  setter 预写的范式/附加字段、错误通知带工具的具体原因
  （`lastApoError`）。面板自己的一键卸载在途时先等它落定
  （最长 30s）再动手，避免两个 apo_config 卸载进程并发。
- **回归测试**：`test/apo_mode_switch_gate_test.dart` 四案
  （拦截→成功续行 / 等待中反复切换被吞 / 失败回滚 / 无附加
  直切且不调卸载），经 `apoDetachRunnerOverride` 测试缝注入
  假卸载（真实路径依赖提权与注册表，单测不可达，与
  `ConfigManager.baseDirOverride` 同例）。

## 事项二：插件编辑器三动作引擎 + 原生浮条立项（`f80712cc`、`a99bdde1`）

业主裁定：浮条本体落在**插件编辑器窗口内原生实现**，立项为
后续大项（立项文档 `docs/10-架构/插件编辑器窗口原生浮条立项
-2026-11-12.md`：编辑器是插件原生窗口、Flutter 画不进去；交
互规格原文、三动作协议、承载面难点与排期口径俱备）。本轮交
付三动作引擎与插件页临时入口：

- **立即应用**：编辑器开着时把影子当前状态立刻收获并强制发
  布到 APO（复用关窗收获同导管 `apoHarvestState` 手动形态）。
- **自动应用**：管理器 300ms 轮询（任一槽「编辑器开 + 开关开
  + 影子模式」才运行，无满足者停表；关编辑器自动复位）。关
  键配套：发布器新增**字节去重** `publishSlotStateIfChanged`
  ——与最近发布字节全等则不落块、不推进 stateGen。没有这层，
  轮询会让 audiodg 每 300ms 重载一次同一状态。
- **恢复**：编辑器一打开（show 回执 + 影子模式）即经
  `apoSnapshotBaseline` 快照基线（savePreset 字节存发布器内
  存）；恢复 `apoRestoreBaseline` 把基线经 loadPreset 灌回
  影子（编辑器参数复原）并强制发布（听感复原）；无基线（快
  照失败/插件被更换）明确回失败并提示，不静默。基线与去重
  记忆随槽位插件身份变化自动作废。
- **临时入口**：插件页槽卡内、编辑器打开且影子模式时显示一
  行三动作（立即应用按钮 / 自动应用开关 / 恢复到打开时按
  钮，基线未就绪时禁用），三语 l10n 已备。原生浮条交付后本
  行去留由后续计划书裁定。
- **回归测试**：`test/plugin_editor_actions_test.dart` 六案
  （打开即快照 / 立即应用手动收获 / 自动轮询节奏与关后停发
  复位 / 恢复就绪门 / 基线丢失清旗 / 非影子模式全空转）。

轻量 595），但 setup 链因此受阻。处置**未扰动用户机器音频**：

staging 副本（复制现树 → 新目录打包），`--verify` 全过。遗留
待业主知悉：开发机 COM 注册现指向 dist staging 树的 APO，
建议找个方便时点跑一次装机版 `apo_config doctor --fix` 指回
`C:\Program Files\AuraDSP`（不影响当前使用，端点附加状态不
变）；本轮未擅自动它。

## 验收清单（业主侧）

1. **模式切换**：APO 已附加时在设置页切到任何其它模式——出
   现大等待动画、模式卡全禁选、点什么都不响应切换；卸载完
   成后自动落到目标模式。再试：附加状态下先手动一键卸载干
   净，再切换——应无等待直接切。
2. **失败路径**：切模式时在 UAC 弹窗点「否」——应留在 System
   APO 模式并弹失败原因通知，模式卡恢复可选。
3. **三动作**：APO 模式打开某插件编辑器，插件页槽卡出现三
   动作行：在编辑器里拧参数 → 点「立即应用」，不关编辑器即
   应听到变化；开「自动应用」后拧参数应在约 0.3s 内跟随；
   点「恢复到打开时」应回到打开编辑器那一刻的调音（含编辑
   器界面参数复原）。关编辑器仍按老规矩自动记录 A/B。
4. **顺带留意**：开发机 COM 注册指向 dist staging 一事（见
   上「打包事故」），方便时告知我处理或自行跑装机 doctor
   --fix。
