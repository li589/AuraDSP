# 引擎尖端改进实施计划 — 基于对标评估 §7

> 日期：2026-10-17 · 依据：`引擎尖端对标评估-2026-10-17.md`（6.7/10，三块硬短板）
> 原则：零参数/零链序/零 ABI 变更起步，全部改动限定 DSP 内部；
> 每项以 `test/smoke/` 现有断言为回归闸门。

## Phase 1（本次实施）— 低成本高收益三件

### P1-A 块率增益每样本平滑（评估 #12，★★★★）
现状：freeverb 的 outgain×autogain、gate/spatial 的 autogain 补偿在块边界
一次性乘上，2048 帧块（42.7ms@48k）下拖滑块产生台阶/颗粒感。
方案：
- 三个模块统一改为**每样本一阶平滑**（2ms 时间常数，`exp(-1/(0.002·fs))`），
  平滑器状态入 handle（`fv_g_sm` / `gate_ag_g_sm` / `spat_g_sm`）。
- freeverb/spatial 把 outgain×ag_comp 折进主循环（消除块末第二遍遍历）；
  gate 把 ag_comp 折进主循环乘法。
- ag 补偿语义：comp 仍按原式每块更新（rin 块首 / rout 块末 / 0.1 平滑），
  应用侧延迟一块（≈10.7ms@512 帧）——leveler 慢跟随无感，
  收敛速度与原实现一致。
- 依据：spatial outgain +6dB 断言容差 ±5%，2ms 平滑在 512 帧块内残差 ~0.4%，
  不触发回归；haas/reverb 冒烟无数值断言受此影响。

### P1-B haas 分数延迟线性插值（评估 #16，★★★）
现状：`d = (int)(dms*0.001*fs+0.5)` 整数取整，44.1k 下 25ms 档分辨率误差
可闻于 mono 兼容检查；同族 spatial ITD 已有插值先例。
方案：延迟转 float、双抽头线性插值；clamp 到 ringLen-2 保证后一抽头可读。
整数 ms 档（576/240 样本）frac=0 与原实现逐位一致，smoke_haas 断言不受影响。

### P1-C gate 块级系数 double 精度（评估 #5，★★）
现状：attCoef/relCoef/bpa/dsCoef 用 expf 单精度，短 attack（1ms）系数敏感。
方案：块级系数改 double `exp` 计算后 cast float；循环内检波维持 float
（高频路径不动）。状态精度提升（freeverb/gate 全量 double 状态）列入 Phase 2。

## Phase 2（下周期，中成本）

1. **非线性模块 2x 过采样**（评估 #6，★★★★★）：exciter/tube/psycho 的
   tanh/waveshaper 前置半带上采样 + 后置抗混叠。最大听感差距。
2. **Lookahead limiter 替换 legacy JLimiter**（评估 #7，★★★★★）：
   1.5ms 前瞻 + 平滑包络 + 4x ISP 真峰检波；替换链尾限幅，保留 ±10 钳位兜底。
3. **GR 计量上报**（评估 #17，★★★）：动态模块写 atomic GR 样本，
   经 viz 环/参数接口暴露，UI 消费画 GR 表。
4. **dyneq 每段独立 attack/release**（评估 #9，★★★）。
5. **gate hysteresis/range/hold 参数面**（评估 #10，★★）——需动参数表，单独评审。
6. **混响/gate 状态全量 double**（评估 #3，★★★）——需评估 freeverb 缓冲翻倍内存。
