## 1. 审查锁定事实（便于后续复核）

- **线程契约**（`auradsp_engine.h` L8-13）：`auradsp_process` = RT 音频线程，无 malloc/lock/IO/日志；`set/get_param` 控制线程（`ctrl_mutex` 保护）；`viz_read` UI 线程。
- **常量已核实一致**：`kSpatSpk=8`（B1 binaural 不丢声道）、`kSpatItdLen=256`、`kSpatHistLen=32768`、`kFdnMax=16384`、`kLimLookaheadMax=576`、`kMxMaxChannels=8`、VizRing 容量 64。
- **param table 默认值唯一来源**：`PARAM_FLOAT/PARAM_INT` 宏只含 id/type/offset/min/max/hook，**无默认字段** → 引擎默认完全由 `engine_internal.h` 的 Params 结构体初始化器决定（P-4 修复只需改 struct 一处）。
- **la_len 运行期不变**：`mc_limiter_la_len` 仅 create 时按 sample_rate 计算；`limiter.lookahead` 为 bool 模式开关，不影响 la_len（PF-2 deque 失效重建策略的依据）。

## 4. 性能评估

### 4.1 RT-Safe 结论

- `auradsp_process` 及全部自研子链零分配/零锁/零 IO；`process_plugin_slots_stage` 用预分配 `plugin_buf_l/r`；插件宿主两段式握手正确（RT 零取 host mutex，卸载侧 release+acquire 栅栏+有界自旋）。
- `ScopedFtzDazGuard` 每块置 FTZ/DAZ：压制 denormal 拖尾但不清 NaN（S-6 已在入口拒绝，双保险）。
- vendor `processFloatMultiplexd` 块超限内部重分配的 latent，已被 `auradsp_process:255` `frames>max_block` 钳位保护（若该钳位被移除则构成 RT 分配风险）。

### 4.2 每样本运算量（立体声路径，flops/样本）

| 阶段 | 运算量 |
|---|---|
| 输入/末级 NaN 卫士 | ~10 / ~6 |
| gate（deesser 关） | ~30（PF-3 后门限每块一次 powf，去每样本 log10f） |
| filter / shelf | ~20（各 2 biquad） |
| bassmono / basspsycho(2×OS) | ~12 / ~150 |
| dyneq 3 段 | ~80/段（2 biquad + 3 envelope） |
| haas / exciter(2×OS) / freeverb / loudness | ~10 / ~110 / ~90 / ~20 |
| **spatial（FDN 关）** | ~300（10-24 biquad + 8-tap ER + norm） |
| **spatial（FDN 开）** | ~400（fdn_tick + 106） |
| **spatial_binaural（≥1 源）** | ~500（6 biquad + ER + FDN + LFE LP） |
| limiter 0ms / 1.5ms LA 模式 | ~40 / 摊销 O(1) 窗口维护 + env 递推（PF-2 前为每样本 576 iters 全窗扫描） |
| emit_viz 摊销（≈每 480 样本 1 次 4096 实数 FFT） | 270k flops / ~480 样本 ≈ 560/样本 |
| FDN `fdn_tick` 精确计数 | 8 读 + 24 LP + 16 扩散 + 32 Hadamard + 8 fb + 8 写 + 18 输出 = **106** flops/输出帧 × 1（mono send 共享，虚拟扬声器共用一条 FDN） |

### 4.3 延迟 / CPU 预算（8ch@48kHz/512）

- 块周期 = 512/48000 = **10.67ms**；最坏运算 ~2.3~3.4M flops/块，3GHz 标量 ~0.17~0.26ms，SSE ~0.04~0.13ms → **最坏 ~0.3~0.5ms/块**。
- **余量 ~20~35× vs 8.5ms（3 块）DSP 目标**；PF-2/3/4 修复后 LA 与 spatial 路径进一步下降，计算量不是瓶颈。
