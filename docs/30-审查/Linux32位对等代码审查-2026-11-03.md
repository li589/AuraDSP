# Linux 32 位对等代码审查（2026-11-03）

范围：本轮增量（`9842e56` bundle 解析 + isSupported、`5e2b0ca` 门禁 bundle 节、`6755765` UI widget 测试）与用户同期提交中与 Linux/共享面相交的部分（`b886f9a` 32 位 UI 口径、`ac4f1e9` Win32 声道钳制、`ffa151b` 单实例唤醒 + 旧名清理、`ad560d0` runner 标志、`6e27bc9` 自启 notifier 与 --tray）。审查方式：逐文件通读 + 实测复现。

## 确认问题与修复

### R1（已修复）socket 目录死路径使远程模式静默归零

- **现象**：`XDG_RUNTIME_DIR` 指向已不存在的目录时（陈旧会话变量、临时目录被清理），`AURA_PLUGIN_HOST_MODE=process` 下扫描返回 0、加载全灭，且无任何回落或报错。本轮摸底时实测踩到（先误判为代码回归，定位后确认是环境 + 健壮性缺口叠加）。
- **根因**：客户端 `socketBaseDir()` 只校验 env 是绝对路径，不验存在性；宿主 bind 必然失败，而远程模式的扫描/加载只经客户端请求、无本地回落（`PluginHostClient::scanPlugins` 请求失败即返回 0）。
- **修复**（`plugin_host_client_posix.cpp`）：`socketBaseDir()` 增加 `stat` 目录 + `access(W_OK)` 校验，不合格回退 `/tmp`。实测：死目录下远程扫描恢复正常（经 /tmp socket），正常目录与进程内模式不受影响。门禁新增源级不变量锁定。
- 附带教训：定位期间一度因构建命令输出被 `grep -c` 吞掉而误以为已重编（实际 ninja 缺失、构建根本没跑）——与方案 §10「不要用管道尾巴掩盖判定命令退出码」同类，已在提交说明中记录；本轮引擎验证改用 Unix Makefiles 临时构建目录完成（产物落同一 out/Release）。

## 复核通过（无动作）

- **plugin_bundle.cpp Linux 分支**： stem 优先 + 排序定序保证多文件目录下解析确定；`is_regular_file` 守卫排除同名目录；Windows 分支逐字未动。边界：arch 目录含多个 .so 时按「与 bundle 同名优先」选——Steinberg 规范下该目录恒只有一个插件二进制，此为防御性确定化。
- **onPluginSlotLoaded 的 isCompatible 用法**（plugin_manager_events.dart）：加载失败时用扫描已知的 D2 精确文案兜底——在进程内模式下 32 位插件被引擎拒绝时正是期望呈现，**不应**随 UI 改用 isSupported，此处口径正确。
- **ac4f1e9 Win32 声道钳制**与本轮 POSIX 侧 S2 修复形态完全一致（min 到 kChannels），双平台对齐达成。
- **单实例唤醒**（my_application.cc）：GApplication 唯一实例 + activate 时窗口前置为规范写法；无会话总线时 GApplication 退化为独立进程行为，不阻断启动（CI J8 无头启动将实际覆盖此路径，结果待跟进）。
- **自启 notifier + --tray**（6e27bc9）：与 `desktopExecArg` 转义正确组合（`Exec="<path>" --tray`）；notifier 仅在 setEnabled 时同步，外部手动删 .desktop 不会刷新 UI 状态——Windows 侧同模式，属对等行为而非 Linux 缺陷。
- **b886f9a 的 l10n**：plug32BitBadge/plug32BitHint 三语齐全；plugins_list 的角标/灰显分支只依赖 isSupported/is64Bit，与本轮 Dart 放开自动衔接。

## 观察项（记录，不修）

- **O1**：bundle 条目的 vendor 路径启发式会给出 "Contents"（二进制位于 bundle 内部时，extractVendorFromPath 取到 Contents 层）——Windows 快扫同启发式、UI 厂商表可覆盖，改动有双平台漂移风险，维持现状。
- **O2**：CLAP 驱动同样经 resolvePluginBundleBinary 解析——名为 *.clap 的目录若含 Contents 布局，本轮起在 Linux 会被解析（此前直接丢弃）；CLAP 无 bundle 规范，此为无害泛化。
- **O3**：VST3 活体断言仍缺：本轮 bundle 节验的是发现/解析/位数/偏好序（内层以 CLAP 探针充任），真实 VST3 二进制的工厂探测与音频链仍待真实插件或自建 VST3 探针补齐（与此前记录一致）。
