# vm-win10 第十二轮修复计划（2026-11-11）

## 缘起

第十一轮包 @`0ab6f3c7` 真机验收：**托盘退出正常**（第十轮项 1 就此关闭）。用户同批报两问题 + 三项 APO/界面改进诉求，开第十二轮。

## A 托盘两件

### A1 「最小化到托盘」开关无法手动开关 —— 定罪（代码）

设置页系统卡的开关是写死的假开关：`AuraSwitch(value: true, onChanged: null)`，注释「常驻行为」——没有对应设置项、不可切换。

**修复**：做成真设置。config 新增 `ui.closeToTray`（默认 true，与旧常驻行为一致）；`WindowPort` 新增 `setCloseToTray`（AppModel 构造下发初值、设置变更即时下发）；托盘服务 `handleWindowClose` 裁定：偏好开且托盘就绪 → 隐藏；否则（偏好关或托盘未就绪）走退出路（摘图标 + 销毁窗口），不留无图标可恢复的隐形进程。设置页开关接 `model.setCloseToTray`，说明文案随开关值切换（新增 `sysTrayHintOff` 三语）。

### A2 关闭按钮不走托盘直退 —— 定罪（guest 三层插桩实证），第十轮 v2 自埋雷

证据链（vm-win10 guest，插桩构建逐层排除）：
1. 最小复现（stock 模板 + window_manager 0.5.2 + setPreventClose）WM_CLOSE → 存活隐藏，机制本身无恙；
2. 本 App：Dart 回查 `isPreventClose() == true`（标志已落），但 `onWindowClose` 永不触发、进程死；
3. 原生插桩：WM_CLOSE 到达 WndProc 且 `that` 有效，但 `FlutterWindow::MessageHandler` 入口日志恒空——消息在进门前被短路；
4. WndProc 级插桩补齐最后一环：WM_CLOSE/WM_DESTROY 均到达，随后 Destroy 链执行。

**元凶**：第十轮 v2 在 `FlutterWindow::OnDestroy` 无条件置位 `destroying_`。而 `Win32Window::Create()` 开头先调 `Destroy()` 空转——**每次启动 OnDestroy 都空跑一遍，旗标被永久闩住**；此后 `MessageHandler` 对一切消息绕开控制器 proc，window_manager 的关窗拦截委托永不运行，WM_CLOSE 落 `DefWindowProc` 直接销毁。托盘菜单退出走 Dart 直调 destroy 不经消息分发，故不受影响；其余顶层委托（焦点/激活事件）同被闩死但无可见症状。

**修复**：旗标与 GWLP_USERDATA 撤销只在控制器在场（真销毁）时执行；OnCreate 显式复位 `destroying_ = false` 兜底。v2 的崩溃防护（闩锁后移空销毁 + 撤销分发关联）在真销毁路径上完整保留。

**guest 复验（修复构建）**：WM_CLOSE → 进程存活、窗口隐藏 ✓。

## B APO 加固

现状盘点：audiodg 侧已有 SEH 故障闩锁、座位过期回收；工具侧 install 自愈 COM 注册现行性与 ACL；App 侧故障/加载失败边沿通知已有（复审 S1 APO-4）。缺口有二：

- **B1 开机自启自动附加（新）**：附加此前只有面板按钮一个入口。新增 `maybeAutoAttachApo()`：启动会话恢复后自门控（模式 == sysapo、记忆目标非空、status 枚举中目标仍存在、目标未附加）→ 自动附加一次（提权 UAC 由用户确认）。checkApoStatus 同步留存 `endpoints[]` 全量枚举作存在性真值。结果走通知，失败原因在面板 lastApoError。
- **B2 遥测缺席监督（新）**：「附加全绿但 audiodg 内 APO 永不运行」是五~九轮反复出现的静默失效类，此前状态层无信号（读者只写一行日志）。读者侧块缺席满 300 tick（30s）上报 `absent` 事件（每缺席周期一次）；状态层在 sysapo 且有附加时通知一次（措辞带「若正在播放」条件，未播放时块本不创建，避免误报）；任一正常遥测事件复位闩。
- 不做：无弹窗自动重附加（UAC 无法也不应绕过）；崩溃面由既有机制覆盖（附加状态注册表持久化，重启不丢）。

## C 复合插槽状态机 —— 与用户判断一致

复合与否只在附加那一刻被工具消费（`attachSystemApo` 读 `apoCompositeMode` 传 `--composite`），此前任何时候可点、附加后点纯属假交互。改为：附加前可选；附加中（isApoOperating）或已附加（apoAttached）时禁用（onTap: null，与附加/卸载同口径），整钮挂 `apoCompositeTip` 气泡说明（新增三语）。

## D APO 面板文案修剪

常显说明文字三坨收气泡：① 模式语义说明（apoModeHint）→ 范式行尾「?」图标 Tooltip；② 注册表安全长句（setApoSafetyNote）→ 按钮行末盾形图标 Tooltip；③ 引擎实测明细（复审 S2 的 rate/声道/已应用参数）→ 并入引擎状态行悬停 Tooltip（rate > 0 时）。状态行、心跳芯片、错误条等功能性呈现保留不动。

## 验收要点（详见收口）

托盘：开关可切换且落盘；开时点 X 进托盘、关时点 X 直退；托盘退出反复多次无新 dump（v2 防护回归）。APO：关机前保持附加、开机自启后自动附加回来（目标在场时）；拔除目标设备后启动不误附加、不弹 UAC；复合钮状态机；面板版面清爽度目验。
