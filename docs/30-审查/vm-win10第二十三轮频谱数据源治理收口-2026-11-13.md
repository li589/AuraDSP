# 第二十三轮收口：切换后频谱残留——按「频谱数据来源」全通路治理

日期：2026-11-13。代码头 `f2b6c8d1`（`b785f87f` 治理主体 + `bcfa6019` 判据优先序修正 + `f2b6c8d1` 测试隔离修正）；其后 CI 复核补修测试平台门，最终代码头 `e8f066fc`（`9ff0d007` 等，见 §四）。打包制品取自 `f2b6c8d1` 构建（其后提交仅动测试文件，不影响制品）。触发：user 2026-11-13 11:06 实测报告——ASIO 卸载修复实证关闭（第二十二轮项 1）；新报「切换到别的没声音的驱动选项时有时候频谱会有残留」，并指示按「频谱数据来源」考虑处理。

## 一、审计结论（数据源通路全表，代码核实）

各 viz 生产者的关停行为在第二十二轮前已大部分自带清零纪律：

| 生产者 | backend 标签 | 停流/冻结时行为（本轮前） |
|---|---|---|
| 本地引擎 isolate 泵 | （无标签）→ 视作 `local` | idle 发一帧清零 + 卡死补清零帧 |
| 三桥（vaio/vb/asio） | `vaio`/`vb`/`asio`（isolate 泵打标） | 共用 isolate 侧旧帧看门狗 >1.5s 发一帧后端名清零 |
| APO 遥测读者 | `sysapo` | 第二十二轮冻结 500ms 补发一帧清零（`c794a8c3`） |

**缺口在切换边界与状态层**，与 user 的「数据来源」直觉一致：

1. **状态层对 viz 帧来者不拒**：任何 backend 的迟到帧都能在切换后把已清的显示重新点亮（残影回潮）。
2. **上升沿清零只挂在三桥的 status 事件上**（vb/asio/vaio 布尔翻转时）；切入 sysapo 冷启（APO 读者本会话从未见过帧，`_lastSeq=-1`，补零永不触发）、切入 VAIO 但断路器压制起桥（无上升沿、无帧）、管线源变更不动桥激活标志等场景**无人清零**，旧源最后一帧永冻。
3. 清零动作三处各写一份、覆盖面不一致（VAIO 版缺 GR 与声道/输入计清零）。

## 二、修复（状态层治理，`b785f87f`）

1. **`expectedVizBackend` 判据**（`state_audio_modes.dart`）：按当前模式配置算出「唯一合法 viz 来源」——附着型模式优先（sysapo→`sysapo`、vbcallback→`vb`），其次管线链（asio→`asio`、vaio→`vaio`、capture→`local`），再次直连模式（asio/vaio），缺省 `local`。
2. **viz 事件来源过滤**（`state_events.dart`）：非期望来源的帧一律丢弃（dbgLog `viz: dropped <backend> frame (expected <expected>)` 同源去重打印）；接受时记录 `vizSource`。
3. **切换点统一清零**：`applyPipelineChain` 起始处 `_syncVizSourceOnSwitch()`——期望来源变化即更新基线并 `_clearVizState()`。全部切换路径（setAudioMode 尾调、ready 后对账）都经此漏斗，幂等。
4. **`_clearVizState()` 统一实现**：频谱/eqIn 32 段、L/R −90、五路 GR 归零、级电平 −90、输入计 −120、声道数 0、声道电平与逐声道级电平 −120。三处上升沿清零改为复用它（VAIO 由此补齐 GR 与声道清零）。

**判据优先序的一次定罪修正（`bcfa6019`）**：首版判据为管线链优先，但新测试的鲜活模型断言暴露——默认配置下 `modeCategory` 由**原始** `audioMode='auto'` 派生为 pipeline（链 = capture → local），而归一化后的 `audioMode` 是 sysapo；链优先会把 APO 帧误判为异源全丢。附着型模式由 audioMode 直接派发，故必须优先于链。此为真实判据 bug，由新测试逮住，产品语义随之澄清存档。

## 三、测试（`test/viz_source_governance_test.dart`，4 例）

1. 期望来源随模式与管线链正确变化（sysapo→vbcallback→asio→vaio 链→capture/local）；
2. 异源帧被丢弃、同源帧被应用；
3. 切换模式瞬间清零显示（含声道数 8→0），切换后旧源帧被丢、新源帧被应用；
4. capture 链只接受无标签（local）帧。

**测试文件内状态污染教训（`f2b6c8d1`）**：同文件多例共享落盘 config，前一例存下的管线路由会漏进后一例的鲜模型构造（期望来源被污染为 vaio）。定规：每个状态类用例必须显式设置起始模式，不得断言与机器默认有关的中间状态。

## 六、验收请 user

1. **切换清零**：在有声模式间与切到无声选项间来回切换，频谱与电平应「切换当刻」即落零，不再等待、不再残留；含切入 APO（冷启）与 VAIO 被断路器暂停的场景。
