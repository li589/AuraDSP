## S1 低频单声道编辑器 UI 口径（`510b330c`）

先行澄清（git 可证）：r48→r49 零 bassmono 文件变
更，低频单声道的接线与效果逻辑两轮均未动。投诉根
源是编辑器旧判定——声道对可用性按实时流宽
（vizChannelCount）算，流为立体声时 7.1 设置下声
道对被误灰、合并行整段消失。按 user 口径改（纯
UI，DSP/掩码语义不动）：可用性改按设置声道数
（模型单一真相 `effectiveChannelCount` +
`isStereoPath`）；设置外声道对不渲染（7.1 四对全
显全可选、5.1 三对、4.0 两对、2.0 只 FL/FR），未
选对在效果器内直通如故；合并方式始终显示（不足
两对仅禁用），两按钮紧凑定宽 196 右对齐；「声道
选择」标签去粗体；声道对按钮内边距/间隔收紧。
bass_shaping 测试改按设置声道数驱动并按新口径断
言（4ch 不渲染 C/LFE、SL/SR；合并方式常显）。

入 ASIO（断言合成模式仍 vaio 这一旧落空点）/ 输
出 ASIO 两路 + 停源 + 恢复 + stop 放行。
