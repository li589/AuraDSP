## 二、 关键工程与设计规范审查

### 2.1 跨平台代码规范与隔离契约（P0 级）
- **审查项**：禁止在业务代码中散落 `Platform.is*` 或 `defaultTargetPlatform`。
- **核查结果**：**通过**。
  - 业务层零直接平台判断，所有平台上下文均统一通过 [`PlatformProfile`](file:///d:/temp_desktop/Proj/JamesDSP/app/auradsp_app/lib/platform/platform_profile.dart) 代理查询；
  - 自动化脚本 `python test/smoke/smoke_dart_platform_quarantine.py` 执行通过（ALL PASS）。
- **网络与 I/O 契约**：
  - 在线歌词检索采用 Dart 标准库 `HttpClient`，设置了 4 秒连接超时与 5 秒数据传输保护，不引入外部冗余 HTTP 依赖，在 Windows / Android / Linux / macOS 全端通用。

### 2.2 UI 设计系统与视觉交互规范（`.ai/rules/ui_design_spec.md`）
- **统一问号徽标 (`InfoBadge`)**：
  - `visualizer_drawer.dart` 中的所有提示气泡统一使用 `InfoBadge(message: ...)`，无任何手动违规手写 `Tooltip(child: Icon(...))` 的情况。
- **数值滑块与单位规范 (`ValueSlider`)**：
  - 灵敏度（`unit: 'x'`）、阻尼（`unit: '%'`）、重力（`unit: 'G'`）、辉光（`unit: '%'`）均显式指定单位与格式化函数；
  - 严格避免了 `100% %` 或 `1.0x x` 的单位重复拼接缺陷；
  - 所有滑块均完整配置了 `defaultValue` 与 `onResetToDefault` 出厂复位能力。
- **中文硬编码与国际化棘轮**：
  - 执行 `python tools/l10n_cjk_scan.py`，全量扫描 `lib/features` 与 `lib/ui` 统计为 **0 strings / 0 files**；
  - 执行 `flutter test test/l10n_cjk_guard_test.dart` 结果为 100% PASS。

### 2.3 音频实时安全性（RT-Safe）
- **审查项**：UI 视效不得对引擎 RT 线程施加锁竞争或阻塞。
- **核查结果**：**通过**。
  - 可视化完全运行于 UI Isolate，仅作为只读订阅者消费 `model.spectrum` 与 `model.levelL/R`；
  - 示波器波形与利萨如图形由前端 `WaveformSynthesizer` 依据频谱与电平差纯本地平滑合成，零额外 IPC 开销，绝对保障引擎 RT 音频线程的无锁、无分配。

### 2.4 性能优化与内存释放（Memory & Resource Hygiene）
- **重绘边界 (`RepaintBoundary`)**：
  - 所有 5 种视效的 `CustomPaint` 画布及高频更新组件均显式包裹 `RepaintBoundary`，阻断局部重绘对整体页面的污染；
- **离屏节流 (Offscreen Culling)**：
  - 严格遵守 R2 页面可见性门控契约：在用户切换至非可视化页时，`VisualizerStage` 的动画控制器停止 `.repeat()`，高频物理计算停止，保持 **0 额外 CPU/GPU 开销**；
- **资源释放完善性**：
  - `VisualizerPage`：在 `dispose()` 中完整释放 `_focusNode` 与 `_mediaSync`；
  - `VisualizerStage`：在 `dispose()` 中取消 `_hudHideTimer`，销毁 `_animController`；
  - `MediaSyncService`：在 `dispose()` 中注销定时器并释放 `currentTrack`、`currentLyrics`、`activeLineIndex` 等 `ValueNotifier`；
  - `LyricView`：在 `dispose()` 中销毁 `_scrollController`。无任何句柄或定时器泄漏隐患。
