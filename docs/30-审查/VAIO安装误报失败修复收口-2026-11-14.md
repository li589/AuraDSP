# VAIO 安装误报「安装失败」修复收口（2026-11-14）

## 现象（user 报告，开发机）

开发机上卸载 AuraDSP 后重装，向导/面板提示「VAIO 驱动安装失败」。

## 取证与定罪（开发机一手证据）

时间线（2026-11-14，开发机 setupapi.dev.log + 随包脚本日志
`%TEMP%\auradsp-vaio-install.log`）：

- 12:22:02 卸载：devcon remove 成功，`pnputil /delete-driver oem174.inf
/uninstall /force` 成功（旧包 = user 上午自建包，DriverVer 10.5.38.37，
FileRepository `auravaiodriver.inf_amd64_102bc557a74c16e9` 整目录删除、
服务删除、System32.sys 删除）。
- 12:22:31 重装（新包，DriverVer 11.19.53.562）：证书导入、pnputil 暂存
成功（新 FileRepository `auravaiodriver.inf_amd64_c4f742297fd1b982`，
oem174.inf）；devcon 创建设备节点 ROOT\MEDIA\0005 并输出
**「Drivers installed successfully」却以退出码 1 结束**。
- setupapi 同段明文：`Reactivating service 'AuraVaioDriver' pended for
deletion`、`Driver 'AuraVaioDriver' required reboot: Driver did not
unload`、Configure 段 exit(0x00000bc3) = ERROR_SUCCESS_REBOOT_REQUIRED。
- 装后实态：设备 ROOT\MEDIA\0005 present、Status OK、CM_PROB_NONE；
DriverStore 与 System32\drivers 的.sys 均为修复版 `339AD371…`；
服务 Running（内存中仍是旧镜像，重启才换新）。

**定罪**：卸载时旧驱动的内核镜像未能卸载（服务挂起删除，镜像留驻内存
至重启），重装遂落入「已安装、需重启激活」状态；devcon 在此状态按其
固有行为以 1 退出。随包脚本 `install_vaio.ps1` 只看 devcon 退出码便报
退出码 6，App 与安装向导随之显示「安装失败」——**误报：安装实际已完成，
只差重启**。该状态并非开发机独有：宾机干净环境三轮卸载→安装循环中，
devcon remove 明示「Removed on reboot」、随后安装同样命中 devcon 退出 1，
即同会话内卸载后重装必然落入此状态。

附带定罪：脚本 `-Action status` 按 `InstanceId -match 'AuraVAIO'` 数设备，
而 root 枚举设备的 InstanceId 是 `ROOT\MEDIA\<n>`、不含硬件 ID，故
**status 的设备数恒为 0**（开发机、宾机实测均如此，与真实在场设备矛盾）。

## 修复（提交 `82636ad0`）

- `installer/windows/custom_installer/driver/install_vaio.ps1`：
- 新增 `Get-VaioDevices`：按友好名/硬件 ID（DEVPKEY_Device_HardwareIds）
匹配设备；`status` 改用之，设备数恢复真实。
- 安装判读改按装后状态（与 dev 脚本 `install_driver.ps1` 按节点数判读
同口径）：devcon 非零时，若其输出含「Drivers installed successfully」
且设备在场 → 记「已安装、需重启」并以**新退出码 8** 返回；否则维持
退出码 6 真失败。文件头退出码表补 8。
- 卸载侧提示（最佳努力）：服务残留 / 设备残留 / devcon remove 明示
「Removed on reboot」任一成立时，日志提示镜像留驻内存、重启才卸载
干净、先于重启重装将得到退出码 8。注：镜像留驻在用户态并无恒定可见
信号（包删除后服务项与设备均可从枚举消失），故以安装侧按状态判读
为权威层，卸载提示仅覆盖可见情形。
- App（`state_audio_modes.dart`）：退出码 8 视为脚本成功，不写
`lastVaioError`，改发 warning 通知「AuraVAIO 驱动已安装；旧驱动尚在
内存中，请重启电脑使新驱动完全生效」。
- 向导（`install_engine.dart` + `driver_notice.dart`）：退出码 8
（`kDriverRebootRequired`）记为「VAIO 驱动已安装；旧驱动尚在内存中，
重启电脑后新驱动完全生效」，不再记「VAIO 驱动安装失败」。
