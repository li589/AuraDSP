# 安装向导可靠性三件套与整包缺陷收口（2026-11-14）

## 立项（user 指令 + 修订裁定）

user 三项要求：① 安装程序单实例（多次打开安装程序的处理）；
② 更新安装的文件占用、目录不可写、非管理员权限处理；
③ 覆盖安装的文件备份口径、非安装文件不动、卸载干净（注册表 /
程序目录 / 开机启动项 / 驱动全清，用户配置目录仅勾选时清）。

审计结论：备份快照本就存在（会话临时目录，不涨安装目录体积）、
同名文件本就直接覆写（占用走改名让位）、卸载本就彻底且默认保留
用户数据。真实缺口为：向导无任何单实例机制、无安装目录可写性
预检、本次运行产生的让位文件只在下次安装/卸载时顺带扫除、
解包写入无逐文件失败恢复。

修订裁定（user，2026-11-14）：**备份 + 回滚全保留**；新增
Windows Installer 式失败对话框——失败步骤可反复重试直至用户
点取消、关键文件禁用「跳过」、错误原样输出。提交链：三件套
`72b9fc7b`，本轮验证另定罪两缺陷并修复：pnputil 259 误报
`231dd9c3`、整包缺 devcon.exe `82b7b4f3`。

## 实现（`72b9fc7b`）

### S1 单实例

- 向导（`wizard/windows/runner/main.cpp`）进程全生命周期持有
  会话级命名互斥 `AuraDSP-Setup-Instance`（不用 Global\——
  标准用户无 SeCreateGlobalPrivilege）；`--resume-options`
  （提权交接）以 60×250 ms 重试获取等待前任退出；静默令牌
  （`--silent`/`/silent`/`/S`）撞互斥直接退出码 1、不弹窗；
  交互模式弹双语提示框。
- 引导器（`bootstrapper.cpp`）在 200 MB 载荷 SHA 校验前做
  OpenMutex 顾问性预检（权威判定在向导本体），撞车时不解包、
  不产生新会话目录。

### S2 可写预检 + 让位文件收尾

- `InstallEngine.install()` 步骤 0：在任何变更之前对最终安装
  目录做探针（递归创建 + 写删 `.auradsp-write-probe`）；失败
  给出可行动文案（纯函数 `writabilityFailureMessage`：
  errno 5 且未提权 → 提权或改选用户目录；已提权 → 权限/安全
  软件拦截；其它 → 通用 + 错误原文）。
- 解包经 `asideSink` 收集本次运行产生的让位文件：成功路径
  即时删除重试（`_retireAsides`），残余经 `leftoverPaths`
  交既有退出后清理脚本；失败路径同样携带。

### S3' 失败对话框（重试 / 跳过 / 取消）

- 类型（`models.dart`）：`FileErrorDecision {retry, skip,
  cancel}`、`FileErrorPrompt {step, relPath, errorText,
  critical}`、`FileErrorHandler`、`InstallCancelled`。
- `extractPayload`（`payload.dart`）逐文件决策回路：静默模式
  无 handler → 抛出（等价自动取消）；重试 → 重写该文件；
  跳过 → 记入 `skippedSink`，若目标已消失则尽力把让位文件
  改名还原（「跳过 = 保留旧版」成立）；取消 → 抛
  `InstallCancelled`，走既有回滚，错误文案为「安装已被取消，
  已回滚到安装前的状态。/已清除本次写入的文件。」。
- 关键文件判定（纯函数 `isCriticalPayloadPath`）：
  `resources/` 前缀（大小写/斜杠归一）可跳过；其余（根目录
  二进制、`driver/`、`data/`、默认层）一律关键、禁用跳过。
- 跳过文件：不进清单、完成页警示列出（「已跳过 N 个写入失败
  的文件（可能缺失或仍为旧版）：…」）、经 `staleUpgradePaths
  (..., alsoPresent:)` 排除出过期文件删除集。
- 对话框（app.dart `_promptFileError`）：错误原文以
  SelectableText 等宽呈现；关键文件时「跳过」按钮
  `onPressed: null` 置灰并附关键文件说明。l10n 新增
  `fileError*` 六键（zh/en/ja）。
- 备份拷贝失败维持告警续行（安全网降级，非安装失败）。

测试：向导套件 35 → 45/45（VM 内运行：分类器、文案分支、
alsoPresent、决策回路四态）；`flutter analyze` 0 问题。

## 验证中定罪的两起整包缺陷

### pnputil 259 误报（`231dd9c3`）

宾机交互修复时完成页报「VAIO 驱动安装失败（退出码 5）」。
`%TEMP%\auradsp-vaio-install.log`：pnputil 已发布 oem10.inf
并更新 ROOT\MEDIA\0001 后以 **259**（ERROR_NO_MORE_ITEMS，
驱动已为当前、无事可做）退出，脚本只看退出码判失败——与
上一轮 devcon 误报同病。修复（`install_vaio.ps1`）：退出码
259 且 `Get-VaioDevices` 在场 > 0 → 记「already installed.
Continuing.」续行；其它非零维持退出码 5。宾机实证：修复版
脚本安装动作越过 pnputil 续行（后因下条 devcon 缺失以 7
退出，新包已除此因）。

### 整包缺 devcon.exe（`82b7b4f3`）

`install_vaio.ps1` 在 staging 后退出 7：**全部发行包的
`driver/` 自始至终没有 devcon.exe**。devcon.exe 是 WDK 工具、
非构建产物，历史上靠人工放置在驱动构建目录的一份副本随包；
2026-11-14 上午为治 C1301 删除 `modern\x64` 构建树时被一并
抹除，pack 从不校验 → r31、r32 两轮包的向导 VAIO 步骤在真机
上不可能走通（脚本/App 直跑路径不依赖它，故未早暴露）。
修复（`installer/windows/pack.py` 的 `stage_driver_files`，
build_windows Step 5 与三种 pack 模式共用的唯一组装点）：目标
缺 devcon.exe 时自最高版本 WDK Tools 补齐并记日志；仍缺失
则 `die`——绝不再发装不了 VAIO 的包。重打包日志三模式均
确认「devcon.exe 自 WDK 补齐（10.0.28000.0\x64）」。

## 验证（宾机 vm-win10，全程转储恒 5、无新增）

- 单实例（开发机会话 0 冒烟）：互斥被占时第二个 `--silent`
  实例退出 1；`--resume-options` 实例等待、前任被杀后获取
  并驻留；向导运行时引导器 `/silent` 约 1 s 退出 1 且不产生
  新会话目录。
- 可写预检（开发机负向）：`Setup /silent --install-dir
  C:\Windows\System32\AuraDSP-probe` → 目标目录从未创建、
  注册表 InstallLocation 未被污染、14 s 内退出。
- 非关键文件跳过（宾机交互，占用最大的 .irs）：对话框错误
  原文为改名让位失败的 PathAccessException（errno 32）、
  「跳过」可用；跳过后完成页双警示（备份告警 + 跳过清单）；
  清单 2564 条 sha256（= 2565 − 1），被跳文件不在清单内、
  磁盘上仍为旧版内容。
- 关键文件取消 + 回滚（宾机交互，占用 `auradsp_app.exe`，
  新版 Setup）：对话框注「这是关键文件，不能跳过」，
  **「跳过」置灰禁用**；点「取消安装」→ 错误页红字
  「安装已被取消，已回滚到安装前的状态。」；回滚后清单仍
  2564 条、 exe 未被改动、让位残留 0。
- 无占用交互全流程（新版 Setup）：完成页仅测试签名提示，
  无 VAIO 失败警示——pnputil 259 与 devcon 两修复在真实向导
  流内闭环。
- 静默修复（新版 Setup）：退出 0，`driver\devcon.exe` 落盘，
  清单 2566 条，脚本日志 devcon「Drivers installed
  successfully」收尾。
- 干净卸载（`uninstall.exe --silent --no-keep-data`）：
  程序目录、HKCU/HKLM 卸载项、`Software\AuraDSP`、Run
  启动项、VAIO 设备（0 台）、用户数据目录全部消失；其后
  静默鲜装复原（devcon 在场、清单 2566、VAIO 3 端点）。

## 宾机 GUI 验证备忘（供后续轮次复用）

脚本存 `~/workspace/tmp_bundles/r32_*.ps1`（VM 本地）：
计划任务必须经 PowerShell `Register-ScheduledTask`
（Interactive + Highest）注册、且动作以隐藏 PowerShell 宿主
间接拉起目标程序——`schtasks /create` 与任务直指 exe 两种
写法都出现过「报告成功但从未运行」；点击器须先
`SetProcessDpiAwarenessContext(-4)` 并按 GetWindowRect
比例在单脚本内原子计算坐标；**禁止 SetWindowPos 改向导
窗口尺寸**（Flutter 表面会高于可见窗口、裁掉底部控件）；
向导自然几何下关键坐标已实测标定（许可勾选 (0.349, 0.854)、
快速安装 (0.400, 0.938)；失败对话框 取消/跳过/重试 在
y≈797–820 一行）。
