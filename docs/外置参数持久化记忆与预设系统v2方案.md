# AuraDSP 外置参数配置、持久化记忆与预设系统 v2 方案

> **版本**：v2.0 (2026-10-10)  
> **定位**：解决“硬编码参数散落”、“关闭应用后调音参数丢失”、“预设不含新特性与外置资产”三大核心痛点。  
> **上游文档**：《产品架构总览.md》、《APP-插件与信号图扩展规划.md》、《UI与音频效果深度重构与体验优化方案.md》。

---

## 一、 核心痛点与解决目标

### 1. 硬编码参数外置化 (Externalized Configuration)
- **痛点**：采样率 (48000)、声场展宽安全系数 (0.75)、缓冲区大小 (1024)、FFT 采样长度 (4096)、刷新率 (30fps)、文件大小安全限制 (64MB) 等关键参数散落在 Dart 变量与 C++ 源码中，用户无法按需调节或按系统适配。
- **方案**：
  - 构建统一外置配置文件 `%APPDATA%/AuraDSP/config.json`；
  - 运行时自动加载；如文件不存在自动生成规范模板；
  - 暴露关键调优项，支持用户在设置页或通过配置文件进行微调。

### 2. 持久化记忆系统 (Session State Memory)
- **痛点**：用户花费心血调好的 8 大效果卡片参数、多段 EQ 绘制曲线、低音增强模式、电子管风格、加载的 IR 脉冲文件，在关闭应用后全部归零，下次打开变回空白默认值。
- **方案**：
  - 建立会话记忆引擎 `%APPDATA%/AuraDSP/session_state.json`；
  - 参数调节时自动防抖（500ms）异步静默存储；应用退出时同步写入；
  - 应用启动时：先从记忆恢复 UI 镜像，待 C++ 引擎与音频 isolate 就绪后，自动重放下发全量参数（包含 `eq.curve`、低音谐波、电子管饱和度、IR 与 VDC 路径自校验重载）。

### 3. 预设系统 v2 (Preset System v2)
- **痛点**：
  - 原预设仅存平铺 key-value，缺失 Phase 3/4 新增的 EQ 交互曲线、低音模式/谐波、电子管饱和度/风格、混响空间尺寸等全套参数；
  - 新安装应用时预设库为空，缺乏即开即用的专业调音模板；
  - 无法导入导出预设文件。
- **方案**：
  - 升级为 **Schema v2**，支持版本兼容；
  - **内置 6 大出厂经典调音预设**：
    1. `Pop Vocal Clarity`（流行清澈人声）：凸显人声泛音与微管味染色；
    2. `Rock Bass Impact`（摇滚重低音）：心理声学谐波注入与动态冲击；
    3. `Symphonic Concert Hall`（宏伟交响大厅）：1.8x 空间混响与立体声拓宽；
    4. `Vintage Vinyl Tube`（经典黑胶暖管）：饱和驱动度 +4.5dB 与五极管温润染色；
    5. `V-Shape Smile Hi-Fi`（流行微笑曲线）：动感明亮的高低音增强；
    6. `Studio Flat Monitor`（录音棚监听）：全线性直通，纯净还原。
  - 支持“出厂预设 (只读)”与“用户预设”清晰分区；
  - 支持当前状态一键保存为预设、覆盖、重命名、删除、外部导出与外部导入。

## 三、 实施阶段划分

- **Phase 1**：外置配置中心（`AppConfig` & `ConfigManager`）落地，接管硬编码；
- **Phase 2**：持久化记忆系统（`SessionMemory`）落地，自动防抖落盘与启动重放；
- **Phase 3**：预设系统 v2 升级，包含出厂预设资产打包、用户自定义预设导入/导出/管理；
- **Phase 4**：UI 全面适配，设置页新增外置配置与重置入口，效果页升级预设中心卡片；
- **Phase 5**：自动化测试、回归验证与静态分析门禁。
