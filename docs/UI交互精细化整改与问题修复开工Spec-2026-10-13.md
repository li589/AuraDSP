# UI交互精细化整改与问题修复开工 Spec (2026-10-13)

## 一、背景与目标

在完成串扰消除（Crossfeed）独立卡片与混响热修复后，用户针对全软件交互体验、排版细节、视觉层级以及隐藏的逻辑缺陷提出了 15 项深度优化要求。

本 Spec 遵循**“极简、纯粹、专业、层次清晰”**的 AuraDSP 设计哲学，通过系统性重构与微交互打磨，消除冗余占行文本、统一字体规格与图标符号、强化参数分组边框，并彻底修复 ArbMag 任意响应 EQ 的状态回写关闭 Bug。

---

## 二、15项优化任务全景与技术方案

### 1. 效果-输入门控 (`_InputCard` / `_InputBalanceAdvanced`)
- **现状**：高级卡展开后，单独占一行显示 `channelBalanceHint`（“每个声道单独控制...”），破坏了紧凑度。
- **整改**：
  - 在 `AdvancedSection` 标题“高级”旁集成小问号图标与 hover 气泡，将“每个声道单独控制，默认100%...”文本移入气泡；
  - 移除展开面板内部单开的提示文本行，保留右侧“重置 100%”按钮与滑块条形控制。

### 2. 效果-动态压限器 (`_CompressorCard` / `_CompressorAdvanced`)
- **多余单位修复**：`ValueSlider` 中 `unit: 's'` 且 `format: (v) => '${(v * 1000).toStringAsFixed(0)} ms'`，导致文本拼为 `1000ms s`。修复方案：将 `unit` 置空或将单位统一定义为 `ms`。
- **视觉分组边框**：将“自动增益补偿 (AGC)”与“输出增益门”包裹在统一的 `_OutputGainFrame` 外框容器中，与上方核心物理参数（时间常数、分析颗粒度、时频分辨率）形成清晰的物理阶段区分。
- **字体规格统一**：“分析颗粒度”与“时频分辨率”标题由单薄的 `captionOf(p)` 统一升级为标准滑块标题风格 `labelOf(p, color: p.text)`。

### 3. 效果-低音增强 (`_BassCard` / `_BassAdvanced`)
- **多语言术语精简**：
  - 中文：“动态增强 (DBB)” $\rightarrow$ **“动态增强”**；“纯净低架 (Shelf)” $\rightarrow$ **“纯净低架”**；
  - 英文与日文同步剔除 DBB/Shelf 冗余缩写。
- **问号气泡释义**：“低音增强模式”标题升级为 `labelOf(p, color: p.text)`，右侧加小问号 Tooltip，详细阐述三个选项的声学机制（自适应能量增强 vs 模拟平直低架 vs 心理声学高次谐波）。

### 4. 效果-低频单声道 (`_BassMonoCard`)
- **文案与布局精简**：
  - 去除极客感过重且占行的“链头处理...”文本，将其声学价值（消除低频相位抵消与浑浊感、聚拢超低音能量）与分频点说明去重合并；
  - 布局重构：主卡展示“分频点”常用预设（80 Hz, 120 Hz, 200 Hz），“分频点”标题统一为标准滑块字体风格并在右侧附问号气泡；
  - 高级卡 (`AdvancedSection`) 内部放置 20~300 Hz 精细调节滑块 `ValueSlider`。

### 5. 效果-空间混响 (`_SpatialReverbCard` / `_SpatialReverbAdvanced`)
- **分组外框**：高级卡底部的自动增益补偿与输出增益门套入统一的 `_OutputGainFrame` 外框中，明确其作为“输出级”的职能。

### 6. 效果-多段图形均衡器 (`_EqualizerCard` / `_EqualizerAdvanced`)
- **模式切换优化**：频段切换前增加“模式”标题（统一滑块字体），左侧加问号 Tooltip；
- **交互提示融合**：将底部多余占行的“上下拖动增益，双击复位...”融合进“模式”问号气泡中，精简主卡高度；
- **高级卡输出外框**：架构与插值算法标签字体统一为标准 label，输出增益与 AGC 套入 `_OutputGainFrame`。

### 7. 效果-任意响应 EQ (`_ArbmagCard` / `_ArbmagAdvanced`)
- **Bug 根因修复 1（点击预设自动关闭）**：
  - 根因：新冷启动时引擎端 `arbmag_enable` 尚为 0，点击预设芯片下发 `setArbmagString` 触发了 `getParams`，引擎回传的暂态 0 通过 `_mirror` 把用户的 `arbmagOn` 强行重置为 `false`。
  - 修复：对齐 convolver/ddc 的 auto-bypass 防御机制，保护 `arbmagOn` 用户开启意图，并在解析就绪且 `arbmagOn` 为 true 时自动下发生效。
- **Bug 根因修复 2（清除曲线自动关闭）**：
  - `clearArbmag()` 中移除非必要的 `arbmagOn = false`，仅清空字符串与重置节点计数，保持用户卡片使能开关意图。
- **高级面板布局重构**：
  - 主卡仅保留频响曲线微缩预览与经典目标预设芯片；
  - 导入文件、剪贴板粘贴按钮移至高级面板代码编辑器下方；
  - 提取“应用代码”按钮并置于按钮栏最前位：`[应用代码] [导入文件] [从剪贴板粘贴] [清空]`；
  - 校验代码合法性，非法代码时禁用“应用代码”按钮；
  - 自动增益与输出增益门套外框放于面板最底部。

### 8. 效果-立体声扩展 (`_StereoCard` / `_StereoAdvanced`)
- **说明文字整合**：将最下方占行的“分带微调...”说明文字移至“高级”文字旁的小问号气泡内，彻底消除面板底部的多余留白。

### 9. 效果-差分环绕 (`_HaasCard` / `_HaasAdvanced`)
- **术语修正与整合**：“延迟测”统一为“延迟侧”，文字风格升级为标准滑块字体；
- 标题右侧增加问号，将“延迟侧制造声场...”相关原理文字整合入问号气泡，删除占行文本。

### 10. 效果-激励器 (`_ExciterCard`)
- **模式选择器预留**：顶部新增“模式”配置行，展示当前算法 `tanh (双曲正切)` 胶囊；
- “模式”右侧附带问号 Tooltip 解释高频谐波生成原理；
- “谐波量”气泡文案优化，删除原先单开的占行提示。

### 11. 效果-电子管模拟器 (`_TubeCard` / `_TubeAdvanced`)
- **排版字体统一**：主卡“音色风格”与高级卡“过采样”标签升级为标准滑块字体；
- **信号流顺序校正**：将“干湿混合比 (Mix)”移至过采样之后；自动增益补偿与输出增益门套外框置于高级面板最下方（符合“效果生成 $\rightarrow$ 湿声混合 $\rightarrow$ 输出增益门”的物理流向）。

### 12. 脚本-EEL2 编辑器 (`liveprog_page.dart`)
- **问号说明与手册入口**：
  - 卡片标题“EEL2 编辑器”右侧加问号 Tooltip，提供简短功能说明；
  - 工具栏按钮右侧增加“手册”按钮（`Icons.menu_book_rounded`），点击弹出指令与寄存器快速参考对话框；
  - 将原卡片标题下方冗长的“寄存器 spl0/spl1...”占行提示移除，归入参考手册中。

### 13. 插件-第三方效果库 (`plugins_page.dart`)
- **图标与间距微调**：“深度遍历”勾选框与右侧图标之间增加 6px 间距，将感叹号图标统一更换为 `Icons.help_outline_rounded` 问号图标。

### 14. 处理链-全局信号流顺序示意 (`chain_page.dart`)
- **文案与序号精简**：
  - 标题精简为“全局信号流顺序示意：”，去除多余的“(自左至右)”；
  - 节点芯片移除 `1.`、`2.` 序号前缀，直接显示模块名称（如“电子管”）；
  - 对齐 `stageLabelOf` 的映射名称，使其与效果器卡片标题完全统一（例如 `stXfeed` 映射为“串扰消除”）。

### 15. 输出增益门滑块重置按钮
- 全量 6 个效果器（动态压限器、低音增强、空间混响、多段 EQ、任意响应 EQ、电子管模拟器）高级面板中的“输出增益门”滑块，全部接入 `onResetToDefault: () => model.set...OutputGain(0.0)`，滑块右侧恢复一键归零重置按钮。
