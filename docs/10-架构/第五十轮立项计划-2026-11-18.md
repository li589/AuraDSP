## S1 低频单声道编辑器 UI 口径（user 裁定）

验收投诉：合并方式要点声道选择才出现；7.1 下部分声
道对选不了；按钮太长留空多。先澄清：**r48→r49 零
bassmono 文件变更**，低频单声道的接线与效果逻辑本
轮与上轮均未动（user 明令不碰）。投诉根源是编辑器
的旧判定：声道对可用性按**实时流宽**
（vizChannelCount）算——流为立体声时只剩 FL/FR 可
用、合并行整段隐藏，与设置声道数脱钩。

改法（纯 UI，DSP/掩码语义不动）：
- 可用性改按**设置声道数**：模型单一真相
  `effectiveChannelCount`（手动=设置值、自动=引擎回
  读值）+ `isStereoPath`。
- 设置外声道对**不渲染**（不再灰置占位）：7.1 四对
  全显全可选、5.1 三对、4.0 两对（FL/FR+BL/BR）、
  2.0 只 FL/FR。未选中的对在效果器内直通（现有掩
  码语义）。
- 合并方式**始终显示**（不足两对仅禁用，canMerge
  门不变），两按钮紧凑定宽、右对齐。
- 「声道选择」标签去粗体；声道对按钮内边距/间隔
  收紧。

## S2 ASIO 谓词修复（r49 S3 回归）

验收实测：输入切 ASIO 时无徽标、测试仍可点、点了
无效。定罪：r49 的拦截/徽标/禁用全键在
`audioMode == 'asio'`，而 `composeMode` 只看输出
端——输入 ASIO 驱动时合成模式仍为 vaio，合成链却
已是 ASIO 桥链（`composeChain`：输入 ASIO 驱动或
输出 ASIO 客户端任一 → asio 链），谓词全数落空。

改法：新增单一谓词 `asioInChain`
（`pipelineChain == PipelineChain.asio`），四处改
键：setSource 总闸、测试页徽标显隐、波形/文件两处
禁用；切入停源补到 `applyPipelineChain` 汇合点
（管线改选不经模式切换，与 S4 清屏同汇合点口径）。
状态单测改真实拓扑驱动（输入 ASIO / 输出 ASIO 两
路 + 停源 + 恢复 + stop 放行）。
