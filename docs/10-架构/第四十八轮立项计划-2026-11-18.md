## S1 电平表群（A5/C3/D1）——先审计定罪、后修

现象：
- A5（APO，7.1+矩阵+填充）：输入门控输出电平只有
  FL/FR 跟随，SL/SR/BL/BR 行不亮（user 描述 SL 亮时应
  FL/BL/C 同亮而只 FL 亮）；实测输出正常。
- C3（VAIO，矩阵+填充）：主页显示与输出正常，但输入
  门控只显示 FL/FR，「即显示的是关闭声道填充时的状态」。
- D1（多声道，模式未指明）：输入卡依然只显前两声道，
  且**全部**处理链效果器电平表皆然。

已知事实（代码核实 2026-11-18）：
- 本地引擎路径已被冒烟证明正确：矩阵模式下 stage
  12/13 逐声道 == 输入幅值（smoke_mc_channel_levels
  [8]，r47 S5 口径）；emit_viz 对 12/13 按 blkCh 门控。
- APO 宿主侧 ApoEngineHost 遥测写者整表拷贝
  stage_ch_levels（ApoEngineHost.cpp:711-719），Dart 读
  者按 u32[186] 的 channelCount（须 ∈{4,6,8} 且遥测版
  本 u32[1]>=5）展开 stageCh，否则回落 chCount=2 +
  stageCh 恒 -90——**回落一旦触发，全部逐级表只剩
  FL/FR，与 D1/APO 症状同形**。宿主遥测结构布局与
  u32[186] 偏移是否真对齐、宿主帧 channel_count 在矩
  阵模式下的取值，未实证。
- 桥路径（VB/VAIO）经 bridge_manager 的
  stageChLevelsTelemetry()，按桥引擎 FFI 帧的
  channelCount 裁剪列数——帧 channelCount 的真实取
  值未实证（若恒 2 则全表裁成两列）。
- 输入门控采样点在引擎入口（原始输入、填充/上混之
  前）：填充在泵/上混侧把流加宽时，门控 in/out 天然
  看不到被填充声道——C3 的「填充关时状态」与此同形，
  属采样点口径问题、与裁剪问题需分开定罪。
- 矩阵模式下链内级（gate 之外）处理立体声下混，逐级
  表只 FL/FR 是架构事实、不修；**离散模式**下逐级表
  应全宽，D1 是否含离散情形需分开复核（审计项）。

审计动作（定罪前不改代码）：
1. APO：宾机/开发机真机读遥测块原文，核 u32[1] 版本、
   u32[186] 值、f32[195..] stageCh 区与宿主结构布局的
   对齐；核宿主帧 channel_count（矩阵/离散各一）。
2. 桥：给桥 viz 事件加一次性判读（日志/探针），核
   VB 与 VAIO 两桥帧 channelCount 与 stageCh 列宽。
3. 离散复核：本地引擎离散 7.1 下逐级表全宽已被冒烟
   [3] 覆盖（gate 逐声道）；宾机侧离散 D1 情形按 1/2
   的路径结论归因。
4. 填充采样点：确认 VAIO/VB 填充的加宽点（泵 remap /
   引擎 mx_upmix）与门控采样点的相对位置，决定门控
   in/out 的口径（维持入口口径并在 UI 明示，或补一路
   填充后计量）——口径选择在审计结论后请 user 裁定，
   不先斩。

修复随定罪结论落点（引擎 emit / 遥测布局 / 桥帧 /
状态层规范化 / 输入卡回退逻辑），每落点配冒烟或单测。

## S2 A1 一键卸载只卸带叉（user 裁定 2026-11-18）

- 口径定版：亮勾=待附加、暗勾=已附加保持、亮叉=待卸
  载。一键附加仍附全部排队者；**一键卸载改只卸带叉
  （锁定集 ∩ 已附加）者**，未标叉的已附加端点保持。
- 锁定集为空时点一键卸载：不执行卸载，给通知明示先
  标记要卸载的端点（或按钮禁用+提示，二选一在实现时
  按现有交互惯例定）。
- **模式切离的自动卸载（r16）保持全卸口径**：切离
  sysapo 必须全部卸净才能离开，与设置页按钮口径分
  开，注释写明分工。
- sections.dart「回空只经一键卸载」注释与三态说明同
  步改版；chcap 单测扩：一键卸载只卸带叉、未标叉保
  留、空集不卸；r46/r47 相关冒烟断言同步。

## S3 E-a ASIO 模式测试页无声——先查接线

- 查测试源（波形/文件）注入点与 ASIO 模式信号路的关
  系：注入在 isolate 软件管线，ASIO 若绕开注入点则
  测试源永远进不了 ASIO 链。
- 能接通（注入点可前移/旁路可达）则修；属固有（ASIO
  输入/输出为外部硬件直通、软件源无合法注入点）则按
  user 预批方案：ASIO 模式下测试页加 ? 气泡提示（说
  明测试源不适用于 ASIO、需外部信号），不硬接。
