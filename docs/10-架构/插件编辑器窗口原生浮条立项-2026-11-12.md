# 插件编辑器窗口原生浮条立项（2026-11-12）

> 业主 2026-11-12 裁定：浮条落在**插件编辑器窗口内**做原生实现，
> 立项为后续大项；本轮先交付三动作引擎与插件页临时入口（已完成，
> 见 `f80712cc` 与第十六轮收口文档）。本文为该大项的立项记录，
> 供后续排期时直接展开为计划书。

## 1. 背景与问题

sysapo 模式下插件编辑器操作的是 App 进程内的**影子实例**，调音
默认要等编辑器**关闭**才经状态收获同步到 audiodg 内的真实处理
（关窗收获 + A/B 自动记录）。业主希望编辑器不关窗也能即时生效，
并在编辑器窗口角落提供一组随手可及的动作控件（浮条）。

## 2. 为什么必须是原生实现

插件编辑器窗口不是 Flutter 表面：它是插件自己的原生 GUI，由引
擎进程内托管或隔离宿主进程（plugin_host_x64/x86）托管（Windows
为 Win32 窗口、Linux 为 XEmbed/顶层窗口），Flutter 的 Widget 树
画不进该窗口。要把控件悬在编辑器窗口的角落，只能在宿主原生层
创建自有子窗口/覆盖窗并自行处理命中、绘制与手势。

## 3. 交互规格（业主原文口径，后续实现不得走样）

- 编辑器界面左下或右下角附加区域：一个**靠边小箭头**（收纳态）。
- 鼠标 hover 到小箭头 → **Q 弹动画**弹出一条浮条（透明背景，
  圆形按钮），含三键：「立即应用」「自动应用」（开关；开启后
  异步每 300ms 检查插件参数变化并应用）「恢复」（回到本次编辑
  器打开时的状态）。
- 浮条可**长按任意按钮拖动**换边（右→左、左→右）；须处理好点
  击 / 开关切换 / 长按拖动三者的状态冲突。
- 停靠左侧时从左侧展开、停靠右侧时从右侧展开；**无 hover 至
  少 3s 后自动收回**并贴回对应边缘。
- 参考形态：业主提供的 Vector（Android）右下角浮动坞截图
  （主页/模块/仓库/日志的圆形展开菜单）。

## 4. 动作协议（已就绪，浮条直接复用）

三动作引擎已于本轮落地（管理器 + isolate + 发布器）：

| 动作 | 命令 | 语义 |
| --- | --- | --- |
| 立即应用 | `apoHarvestState`（手动） | 影子 savePreset → 强制发布到 APO 插件块 |
| 自动应用 | `apoHarvestState {auto: true}` 轮询 | 发布器字节去重：无变化不落块、不推进 stateGen |
| 基线快照 | `apoSnapshotBaseline`（编辑器打开时自动） | savePreset 字节存发布器内存 |
| 恢复 | `apoRestoreBaseline` | 基线经 loadPreset 灌回影子 + 强制发布；无基线明确失败 |

浮条点击事件的回传路径（待计划书定案）：编辑器宿主（引擎/隔离
宿主）→ 引擎命令通道 → 音频 isolate → 等价于上表命令。隔离宿
主已有 socket+shm 通道，进程内托管可直达。

## 5. 范围草案与难点（计划书阶段展开）

- **承载面**：Windows 先行——进程内托管的编辑器父窗口、隔离宿
  主 x64/x86 各自的编辑器窗口，共三种父窗形态；Linux（X11）
  后行或同批评估。
- **窗口关系**：浮条窗须跟随编辑器窗口移动/缩放/最小化/关闭，
  并处理插件自带模态对话框、编辑器重开（reparent）等情形。
- **绘制与手势**：原生层实现圆形按钮、透明背景、弹簧动画曲线、
  长按判定与拖动手势、3s 无 hover 收回计时——无 UI 框架可用，
  全部手写（Win32 GDI+/Direct2D、X11/cairo 二选一待定）。
- **DPI/多屏**：Per-Monitor DPI 下的尺寸与贴边坐标换算。
- **插件差异**：部分插件编辑器为独立顶层窗、部分为子窗嵌入，
  浮条锚点策略须按形态分支并逐一实测（VST3/CLAP/VST2）。

## 6. 排期口径

- 启动时另行出计划书（承载面选型、回传通道定案、分期与验收清
