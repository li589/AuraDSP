# 空间音效升级方案（2026-10-18）

> 定位：在现有 **L1 参数化 HRTF** 之上，给出可分期落地的升级路线；同时明确 UI 去品牌化策略。
> 现状基线：`engine/dsp/dsp_spatial.cpp`、`engine/chain/engine_chain.cpp`、`engine/engine_param_table.h`、`app/auradsp_app/lib/features/effects/spatial_card.dart`、`test/smoke/smoke_spatial.py`。
> 相关文档：[`空间音效卡与空间核心方案-2026-10-16.md`](../20-执行/空间音效卡与空间核心方案-2026-10-16.md)、[`引擎尖端升级与UI全景适配实施方案-2026-10-18.md`](引擎尖端升级与UI全景适配实施方案-2026-10-18.md)。

---

## 1. 现状基线

- **stage**：`haas → spatial → exciter → freeverb`，spatial 位于 vendor 链之后、音色工序之前。
- **参数**：`spatial.enable/style/room/width/center/outgain/autogain/headazim/headtrack`。
- **算法**：5 个固定虚拟扬声器（-30/0/+30/-110/+110°）；Woodworth ITD + 简化 ILD + 单极点头影低通；5 路求和后做**全局**双 biquad pinna；8 个对称早期反射 tap；outgain/autogain 2ms 平滑。
- **多声道**：Category B 只把前置 FL/FR 送进空间链；C/SL/SR/LFE 直通。Voicemeeter 泵每组也只送 L/R，其余 6 通道透传。
- **头跟踪**：`spatial.headazim/headtrack` 已进参数表、Dart 状态与回读，但 DSP 不消费；`smoke_spatial.py` 明确断言 stub inert。
- **资产**：只有 `.irs/.vdc`，没有 `.sofa/.hrir`；当前为零数据依赖参数模型。
- **UI**：已去品牌化，风格标签为 **影院 / 定位 / 中性**；可视化标题为 `VIRTUAL 5.0 SOUNDSTAGE`。

---

## 2. 目标与原则

1. **源 × 耳处理**：HRTF 必须按“每个虚拟源 × 每只耳”计算，不能在所有源求和后做全局滤波。
2. **一个空间坐标系**：直达声、早期反射、头跟踪、房间必须在同一坐标系内旋转/缩放。
3. **一个空间渲染器**：早期反射与晚期混响归 spatial 总线，freeverb 作为兼容回退，避免“双房间”。
4. **RT-Safe**：所有缓冲/状态在 `auradsp_create` 预分配；音频线程零分配、零锁、零 syscall。
5. **向后兼容**：新增参数默认关闭或保持旧行为；L1 保留为 A/B 回退。
6. **品牌中立**：UI 不出现 Dolby/DTS 等第三方商标；技术文档可保留概念对照，但产品文案一律用“影院 / 定位 / 中性”。

## 3. 分期策略

### Phase A：快赢（低风险、高感知）

| 项 | 方案 | 验收 |
|---|---|---|
| 头跟踪生效 | DSP 按 `-headazim` 旋转虚拟源方位（先 yaw）；平滑、回中、死区；手动拖拽 + OpenTrack UDP | 旋转声源 = 旋转听者（容差内）；无台阶/爆音 |
| 方向 pinna + 仰角 | 每源/每耳 2~4 个方向相关 biquad；前/后/侧不同系数；6–12 kHz 仰角 notch；`spatial.elevation` 或高度层预设 | 前后频谱差异可测；仰角 notch 随高度移动 |
| 中置 HRTF | 中置不再 `oL+=m, oR+=m`，走完整 ITD/ILD/pinna 分支 | 中置外化、无头中化 |
| `spatial.mix` | 0–100% 干湿比；开关切换清空 ring/history/pinna 状态 | 扫参无样本级跳变 |
| UI | 头跟踪开关/角度/回中；水平+高度双环；A/B 旁路 | 控件与引擎回读双向一致 |

### Phase B：核心差异化（下一阶段主线）

**5.1/7.1 耳机虚拟环绕（binaural downmix）**

- 新增“耳机/扬声器”输出模式：输入 6/8ch，按 FL/FR/C/LFE/SL/SR/BL/BR 映射到虚拟源，全部经 HRTF 混成 2ch。
- LFE 低通约 120 Hz、双耳轻微去相关；中置单独 HRTF；环绕用全通/短延迟去相关，不做简单复制。
- 同步改造：`channels.count` / 新增输出声道数、VAIO/VM 传输层、UI 路由卡、`smoke_spatial.py`。
- 对象音频（Atmos/DTS:X）元数据在 APO/VB 的 PCM 路径拿不到；近期只做“声道床虚拟化”，对象/height 另立项评估 `ISpatialAudioClient` 或 7.1.4 声道床。

**上混与去相关**

- 中置用自适应矩阵/相位判决提取，替代 `(L+R)/2`。
- 环绕用全通/短延迟去相关，降低前后拷贝的梳状滤波；保证 mono 兼容与能量守恒。
- 增加距离衰减、空气吸收、早期/晚期比例，让 `width/room` 不只是角度和 tap 缩放。

**统一房间渲染**

- 早期反射用矩形房间镜像源（2–3 阶）；晚期用 8×8/16×16 FDN，带频带阻尼、扩散、调制；RT60/room size 映射到参数。
- freeverb 作为 spatial 内部 late send 或兼容回退，避免双房间和“环绕无混响”。

### Phase C：质量上限

- **实测 HRTF / 个性化**：先支持用户导入 WAV HRIR 对（L/R × 方位/仰角），再评估 SOFA；默认数据必须过授权审查。
- 混合架构：短 HRIR（128–256 tap）做耳廓细节 + 参数化 ITD/ILD 做稳定定位；分区 FFT 卷积，首分区 64/128 样本控制延迟。
- HRTF profile 选择、耳廓尺寸/听音测试；与 DDC/VDC 耳机校准串联。

### Phase D：平台与对象

- 7.1.4 声道床、height 虚拟源、Ambisonic 房间 bed（头部旋转在球谐域做）。
- Windows Spatial Sound / `ISpatialAudioClient` 单独验证；APO 路径不假设能拿到对象元数据。
- 扬声器场景可另做 crosstalk cancellation（CTC），与耳机 BS2B/crossfeed 分开。

## 4. 目标渲染器架构

```text
输入 2/6/8ch
  → 声道映射/上混（中心提取、环绕去相关、LFE 管理）
  → 每源 HRTF（ITD/ILD/方向 pinna/仰角/距离；可选 HRIR 卷积）
  → 早期反射（镜像源）+ 晚期 FDN
  → 双耳总线（头跟踪旋转、平滑）
  → 耳机校准/等响/限幅
```

状态布局建议：固定最大源数（8 或 12）、每源每耳固定 HRIR 长度与 ITD 线、房间固定 FDN 尺寸；所有新参数走 `engine_param_table.h` 的原子表，不破坏 ABI。

## 5. 参数面建议

| 参数 | 说明 | 默认 |
|---|---|---|
| `spatial.mode` | 0=耳机，1=扬声器，2=旁路 | 0 |
| `spatial.elevation` | 高度层/仰角，度 | 0 |
| `spatial.mix` | 空间化干湿比 0..1 | 1 |
| `spatial.distance` | 虚拟源距离/空气吸收 | 1.0 |
| `spatial.headtrack` | 0/1 | 0 |
| `spatial.headazim` | 度，-180..180 | 0 |
| `spatial.hrtf` | 0=参数化，1=HRIR（用户导入） | 0 |
| `spatial.room` / `width` / `center` | 保留现有语义 | 现有默认 |

新增参数默认不改变旧预设听感；老预设缺键按 defaults 基线处理（与预设 v2 语义一致）。

## 6. 验收指标

- ITD/ILD 随方位单调；前后频谱差异可测；仰角 notch 随高度移动。
- 头旋转等变性：旋转声源与旋转听者输出一致（容差内）。
- 5.1 虚拟化：每个输入声道在双耳有正确方位能量；LFE 低通；声道间隔离度达标。
- 能量：`width/room/center` 扫参时积分响度波动 ≤ ±0.5 dB；无削波。
- 无爆音：参数扫频/开关切换无样本级跳变；IR 切换交叉淡化。
- 性能：8 声道 48 kHz、512 帧块，空间链 CPU < 1 ms；RT 线程零分配。
- 主观：ABX / 定位模糊度 / 外化感 / 长时间疲劳度；L1 可 A/B 回退。

---

## 7. 主要风险

| 风险 | 应对 |
|---|---|
| HRTF 授权 | 实测数据不随意打包；优先 clean-room + 用户自带 HRIR |
| 个体差异 | profile/导入/调节；提供中性预设 |
| CPU/延迟 | 分区 FFT、SIMD、首分区低延迟；保留参数化降级 |
| 传输/ABI | 多声道虚拟化需 VAIO/VM/ASIO 端到端改造，不能只改 DSP |
| 预设兼容 | 新参数默认关闭/旧行为；预设 v2 缺键回 defaults |
| 商标/命名 | UI 已改为影院/定位/中性；第三方 IR/VDC 文件名保留原始元数据，不在产品文案中使用 |
