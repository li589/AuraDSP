# 蝰蛇系三效果器开工 Spec（2026-10-13）

> 范围：Haas 差分环绕 / Bass Mono 低频单声道 / XHiFi 式激励器。
> 目标：补齐 Viper 招牌味，全部原生进引擎（EEL 只做味道验证，不做最终形态）。
> 非目标：Dynamic EQ、AGC、Multiband Comp、HRTF（另立项）；Cure Tech+、VSE（不跟）。

## 0. 总体约定

- 新 stage id：`bassmono`、`haas`、`exciter`，全部 `exposed: true`（stage 矩阵 + `kStageMeta` + `kDefaultCoreOrder`）。
- 链位置（默认顺序，`graphOrder` 可调）：
  `input → bassmono → tube → comp → bass → eq → exciter → arbmag → convolver → ddc → liveprog → crossfeed → stereo → haas → reverb → output`
  - BassMono 必须在一切之前（单声道化后再做后续处理，否则低频相位差被后级放大）。
  - Haas 必须在 stereo 之后、reverb 之前（先展宽再做延迟差分，最后进房间）。
  - Exciter 紧跟 eq 之后（先修频响，再加谐波；谐波不进 tube，避免暖声糊）。
- 每效果器标配：`set/get param` 对称、`_mirror` 对称、preset 快照/恢复对称、`toggleStage`/`isStageEnabled`、延迟探针、l10n 三语、state 单测 + smoke（如动引擎则重编 DLL）。
- RT 铁律：process 路径零分配零锁；延迟线/滤波器状态在 `auradsp_create` 分配。

## 1. Haas 差分环绕（Viper Differential Surround）

**原理**：右声道延迟 D ms（只延迟一边，制造 Haas 定位差），干湿混合。单声道兼容：干声保留，塌房成 mono 时只损失宽度不损失内容。

**参数**：

| id | 范围 | 默认 | 说明 |
|---|---|---|---|
| `haas.enable` | 0/1 | 0 | 开关 |
| `haas.delay` | 0~25 ms | 12 | 右声道延迟（Viper 习惯值 10~15） |
| `haas.mix` | 0~1 | 1.0 | 湿声比例（1.0=纯差分，0=直通） |

**引擎实现**：
- `auradsp_create` 按 `max_block_frames` + 25ms×rate 预分配 stereo 延迟环（只右声道用，左声道直通；内存约 48k×2×4B×2ch，可忽略）。
- process：`dry + mix × delayed_R`，bypass 时 memmove 直通（延迟环不清零，切回无抽吸感）。
- **延迟上报**：`compute_latency` 加 `kLatHaas{dynamic}`——按当前 delay 值上报（0~25ms），Dart 侧 `fillEqQ` 式探针同理取实测/标称。

**Dart/UI**：效果页空间区新卡（开关 + 延迟滑块 0~25ms + 混合滑块）；滑块到 0 只关混合不关开关（stereo 解耦教训：`haasOn` 独立位）。

**EEL 味道验证**（先听后写，10 分钟）：
```
@init
pos = 0;
bufsize = srate * 0.025;  // 25ms 上限
@sample
buf[pos] = spl1;          // 右声道进环（需 mem 段，略）
d = buf[(pos - spl_d + bufsize) % bufsize];
spl1 = spl0 * 0 + d * slider1 + spl1 * (1 - slider1);
pos = (pos + 1) % bufsize;
```

**验收**：
- [ ] 右声道脉冲实测延迟 = 设定值 ±1 采样。
- [ ] mix=0 与 bypass 比特一致（null test）。
- [ ] 底栏总延迟随 delay 滑块实时变化。
- [ ] 主观：耳机声场明显出头中，人声不空洞（和 stereo 展宽叠加不打架）。

## 2. Bass Mono（低频单声道化）

**原理**：分频点 F 以下 L/R 取平均（mono），以上直通。防小音箱/耳塞低频左右打架破音，黑胶/母带常规操作。

**参数**：

| id | 范围 | 默认 | 说明 |
|---|---|---|---|
| `bassmono.enable` | 0/1 | 0 | 开关 |
| `bassmono.freq` | 20~300 Hz | 120 | 分频点 |

**引擎实现**：
- 复用 cookbook LPF（与 shelf 同源），左右各一路，状态放 handle（create 时初始化，rate 变化重算系数——跟 convolver 的 `deviceRate` 权威走）。
- process：`lo = (lp(L)+lp(R))/2`，`out_L = (L-lp(L)) + lo`（等价于高频直通 + 低频 mono，省一次 HPF）。
- 零延迟（IIR），`compute_latency` 加 0 项（显式登记不断链）。

**Dart/UI**：低音区并排小卡或 bass 卡内一行（开关 + 频率滑块，80/120/200 快捷 chip 可选）。

**EEL 味道验证**：EEL 无现成 LPF（需手写 one-pole，可做但糙），建议直接原生写，验证靠测量。

**验收**：
- [ ] 100Hz 正弦反相输入（L=-R）：开启后输出 ≈0（mono 抵消），关闭恢复。
- [ ] 1kHz 反相输入：输出不变（高频不受影响）。
- [ ] 分频点扫频，-3dB 点 = 设定值 ±10%。

## 3. 激励器（XHiFi 式高频修复）

**原理**：HPF 取高频成分 → 轻 waveshape（tanh）生成偶次为主的谐波 → 按 amount 混回。压缩音频（MP3/AAC 高频滚降）的主观“空气感”来源；与 tube 暖声的区别：tube 作用全频偏暖，exciter 只动高频偏亮。

**参数**：

| id | 范围 | 默认 | 说明 |
|---|---|---|---|
| `exciter.enable` | 0/1 | 0 | 开关 |
| `exciter.amount` | 0~1 | 0.3 | 谐波混回量 |
| `exciter.hifreq` | 3~10 kHz | 5.0 | HPF 分频点 |

**引擎实现**：
- 复用 cookbook HPF + `tanhf` 整形（tube 链路已有 `tanh`，抽共用函数，拒绝 duplicate code）。
- process：`hi = hp(x)`，`harm = tanh(hi × drive)`（drive 固定 2.0，不暴露，防用户调出刺耳），`out = x + amount × harm`。
- 零延迟（IIR + 无记忆非线性），`compute_latency` 登记 0。
- 防刺耳上限：amount 封顶 1.0，且 harm 限幅在 ±0.5 以内（tanh 天然保证）。

**Dart/UI**：音色区新卡（开关 + 量滑块 + 分频滑块）；文案禁用“杜比/母带级”等词（合规）。

**EEL 味道验证**：
```
slider1:0.3<0,1,0.01>谐波量
@init
x1 = 0; y1 = 0;  // one-pole HP 状态
a = exp(-2 * $pi * 5000 / srate);
@sample
// 左声道示范
hp0 = spl0 - x1; x1 = spl0 * (1 - a) + x1 * a;  // 糙 HP，仅验证味道
spl0 += tanh(hp0 * 2) * slider1 * 0.5;
```

**验收**：
- [ ] 10kHz -20dBFS 正弦进：谐波（20k 混叠注意，用 6kHz 测 12k 二次谐波）随 amount 单调增，THD 可测。
- [ ] amount=0 与 bypass 比特一致。
- [ ] 主观：128k MP3 齿音不增加、镲片有空气感；amount=1 不刺耳（3 人盲听）。
