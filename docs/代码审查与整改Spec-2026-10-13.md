## 一、审查背景与目标

近期系统陆续落地了“输出增益门 + 自动增益补偿（P-010）”、“无损组件延迟测量（ADR-006）”、“哈斯环绕 / 谐波激励器 / 低频单声道化”、“任意响应 EQ（ArbMag）”等多项核心能力。为确保整个项目：
1. **各效果器功能完整、闭环有效**，无“UI 有开关滑块但底层无执行”的断层；
2. **组件关联链路严密**（FFI -> Isolate -> State -> Presets -> SessionMemory -> Engine）；
3. **UI 设计规范整齐统一**，无重复选框、错乱卡片编号、硬编码非多语言字符串或窄屏溢出隐患；
4. **延迟测量安全精准**，100% 隔离不干扰实时播放音频流；
特发起本次全链路深度代码审查与系统性整改。

---

## 二、全面审查发现问题清单 (Findings)

经过对 C++ 引擎、FFI 桥接、Dart 状态管理、本地化多语言和 Flutter UI 层的地毯式代码审查，定位出以下 4 大类共 7 项关键问题：

### 【类别 1：底层引擎与增益闭环缺陷】
| 编号 | 严重度 | 涉及模块 | 缺陷现象与成因 | 预期修复行为 |
| :--- | :--- | :--- | :--- | :--- |
| **F-01** | **Critical** | `libjamesdsp` & `auradsp_engine.cpp` | **ArbMag 输出增益门与自动增益在底层缺失**<br>Dart UI 提供了自动增益补偿开关和输出增益门调节，但 C++ `auradsp_set_param`、`auradsp_get_param` 未定义 `arbmag.outgain` / `arbmag.autogain`，`jdspController.c` 中 `JamesDSPSetFxOutGain` 仅支持 4 个槽位，`stage_arbmag` 未调用增益处理，导致功能完全未生效。 | 1. `jdspController.c` 扩展第 5 个槽位（fx=4 为 arbmag），在 `stage_arbmag` 中接入 RMS 能量检测与 `stage_apply_fx_gain`；<br>2. C++ `auradsp_engine.cpp` 增加参数下发/回读与同步。 |
| **F-02** | **High** | `auradsp_engine.cpp` | **延迟探针 `probe_is_supported` 漏加 `"arbmag"`**<br>`probe_is_supported` 静态白名单遗漏了 `"arbmag"`，导致调用 `auradsp_probe_component("arbmag", ...)` 时被误判为不支持外部资源而直接返回 `-1`。 | 在 `kSupported` 白名单中加入 `"arbmag"`，利用 `probe_isolate` 已注入的测试曲线准确测出 0.00ms 首波延迟。 |
| **F-03** | **High** | `state.dart` | **`replaySessionToEngine` 遗漏重放 `arbmag` 增益参数**<br>重连/启动重放时下发了 `bass`, `eq`, `tube`, `comp`, `reverb` 的 `outgain` / `autogain`，但遗漏了 `arbmag`。 | 在 `replaySessionToEngine` 中增加下发 `ParamId.arbmagOutGain` 与 `ParamId.arbmagAutoGain`。 |

### 【类别 2：UI 视觉与排版设计不一致】
| 编号 | 严重度 | 涉及模块 | 缺陷现象与成因 | 预期修复行为 |
| :--- | :--- | :--- | :--- | :--- |
| **F-04** | **Medium** | `effects_page.dart` | **卡片左上角索引编号（`index`）大面积重复与错乱**<br>因多次迭代追加效果器，导致界面出现多个 `02`, `03`, `06` 徽标（如 BassMono 与 Bass 同为 02，Conv 与 Reverb 同为 03，Stereo / Haas / Exciter 同为 06）。 | 按照当前效果器在处理链上的呈现顺序，从 `00` 到 `13` 严格递增编号（00~13）。 |
| **F-05** | **Medium** | `effects_page.dart` | **`_SpatialReverbAdvanced` 未使用标准 `AdvancedSection`**<br>空间混响高级面板使用了历史遗留的手写 `MouseRegion` + 旋转图标实现，外观边距和收起动画与其他卡片不统一，且污染了卡片 Stateful 状态。 | 重构为通用的 `AdvancedSection`，统一样式，简化代码。 |
| **F-06** | **Low** | `effects_page.dart` | **高级面板摘要字符串中硬编码中文 `"开" : "关"` 与信息缺失**<br>`_EqualizerAdvanced`、`_ArbmagAdvanced`、`_TubeAdvanced` 的摘要写死了中文 `"开" : "关"`，切换英/日文后产生混杂；同时 `Compressor` 和 `Bass` 摘要遗漏了 AGC 状态。 | 统一格式化为语言中立的专业术语 `AGC: ON` / `AGC: OFF`（或绑定 l10n），并在包含自动增益的卡片摘要中完整展示。 |
| **F-07** | **Low** | `effects_page.dart` | **电子管模拟器过采样行窄屏溢出隐患**<br>`_TubeAdvanced` 中“高阶抗混叠过采样”文本未包裹 `Expanded`，窄屏时若文字较长易触发 RenderFlex 溢出。 | 文本包裹 `Expanded(child: Text(..., overflow: TextOverflow.ellipsis))`，确保左对齐文字与右对齐按钮安全排列。 |

## 三、整改技术设计方案

### 1. C++ 引擎与 DSP 底层整改 (`F-01` & `F-02`)

#### 1.1 `jdspController.c` 扩展 ArbMag 增益处理
```c
// 扩展 fxOutGain / fxAutoGain 容量与校验：fx 范围由 0..3 调整为 0..4
// 0: tube, 1: comp, 2: bass, 3: eq, 4: arbmag
void JamesDSPSetFxOutGain(JamesDSPLib *jdsp, int fx, double linGain) {
    if (fx < 0 || fx > 4) return;
    jdsp->fxOutGain[fx] = (float)linGain;
}
void JamesDSPSetFxAutoGain(JamesDSPLib *jdsp, int fx, int on) {
    if (fx < 0 || fx > 4) return;
    jdsp->fxAutoGain[fx] = on ? 1 : 0;
    if (on) {
        jdsp->fxAGIn[fx] = 0.0f;
        jdsp->fxAGOut[fx] = 0.0f;
        jdsp->fxAGComp[fx] = 1.0f;
    }
}
void JamesDSPInitFxGains(JamesDSPLib *jdsp) {
    for (int i = 0; i < 5; ++i) {
        jdsp->fxOutGain[i] = 1.0f;
        jdsp->fxAutoGain[i] = 0;
        jdsp->fxAGIn[i] = 0.0f;
        jdsp->fxAGOut[i] = 0.0f;
        jdsp->fxAGComp[i] = 1.0f;
    }
}

// stage_arbmag 接入 RMS 测量与输出增益应用
static void stage_arbmag(JamesDSPLib *jdsp, size_t n) {
    if (jdsp->arbitraryMagEnabled) {
        double rin = jdsp->fxAutoGain[4] ? stage_rms(jdsp, n) : 0.0;
        ArbitraryResponseEqualizerProcess(jdsp, n);
        stage_apply_fx_gain(jdsp, n, 4, rin);
    }
}
```

#### 1.2 `auradsp_engine.cpp` 参数管理与探针白名单
1. 在 `struct Params` 中添加：
   ```cpp
   std::atomic<float> arbmag_outgain{0.0f};
   std::atomic<int32_t> arbmag_autogain{0};
   ```
2. 在 `apply_fx_gains` 的 `kFx` 映射表中追加第 5 项：
   ```cpp
   { &Params::arbmag_outgain, &Params::arbmag_autogain, 4 }
   ```
3. 在 `auradsp_set_param` 与 `auradsp_get_param` 中增加对 `"arbmag.outgain"` 与 `"arbmag.autogain"` 的读写支持。
4. 在 `probe_is_supported` 的 `kSupported` 中增加 `"arbmag"`。
