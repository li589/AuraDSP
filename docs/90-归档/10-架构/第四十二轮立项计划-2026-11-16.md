# 第四十二轮立项计划（2026-11-16）

来源：r41 包宾机（vm-win10）验收回告（user 2026-11-16 晚）。
两处故障已在回告当晚定因（宾机日志 + 注册表 ACL + 源码三方
实证），其余为体验与架构指令。本计划待 user 开工指令后执行。

## 已定因（实证）

1. **VB 端点附加失败（fx_write_failed）**：Voicemeeter 端点
   `{ad89efb7-…}` **没有 FxProperties 键**，且其父键
   （`MMDevices\Audio\Render\{guid}`）ACL 只给管理员
   SetValue/ReadKey、**无 CreateSubKey**。apo_config 的
   `OpenFxKeyWritable` 直创失败后走 `TakeOwnershipRepair`，
   而该修复以 `RegOpenKeyExW(WRITE_OWNER)` 打开**目标键
   本身**——键不存在时打开即败，修复无从下手。高清音频端
   点 FxProperties 现成，故同轮附加成功。
2. **高清音频在系统设置改声道模式后处理异常**：与 S1 的
   自动回退同根——端点实际格式已变，App 仍按全局声道数
   （7.1）经参数块驱动引擎，两边分歧。宾机 iso 日志
   19:36 可见改格式时图重建、座位 free→claimed。

## S1 故障修复

- **FxProperties 建键**：`OpenFxKeyWritable` 失败路径扩展：
  目标键缺失/创建被拒时，对**父端点键**执行同级接管（启
  SeTakeOwnershipPrivilege → 所有权归 Administrators →
  授 Administrators 完全控制），再重试创建 FxProperties；
  仍失败如实报错。卸载回收沿既有台账（HadFxPropertiesKey
  =0 时删除自建键）。验收：开发机/宾机 VB 端点附加成功、
  分离干净；原生测试补「键缺失」用例（可构造的范围内）。
- **声道能力自动回退（user 指令：不需要用户手动操作）**：
  有效声道数 = min（用户设置，设备实际能力），自动钳制：
  - APO 侧：宿主以 LockForProcess 实际流格式为准钳制引擎
    声道数（参数块值超限时按流格式建引擎），telemetry 生
    效回读扩展声道数，App 显示实际生效值（改系统设置后处
    理不中断不错乱）。
  - 桥模式（WASAPI/ASIO/VB 等）：按输出设备实际声道能力
    钳制 channels.count 的生效值，UI 同步显示生效值。
  - 钳制只改生效值不改用户设置值；设备能力恢复后自动回升。

## S2 声道设置简化（user 裁定）

- **口径（user 2026-11-16）：声道设置默认全局，「跟随全
  局」按钮直接去除**——声道卡只剩全局一份设置（模式/填
  充/数量/采样率），端点覆写 UI 整体移除（覆写编辑态、
  恢复跟随 chip、未附加警告等一并撤下）；选中端点仅影响
  遥测/状态跟随对象，不再有独立声道值。
- 引擎侧参数块 v3 实时覆写表与 FX 初值通道**保留休眠**
  （原生不删，App 不再写入；config `apoEndpointChannels`
  停止读写、既有落盘值忽略），将来恢复有底子。
- **文案简化**：APO 面板与声道卡相关文案三语同步精简
  （去掉解释性长句，只留动作与状态）。

## S3 显示即时性

- 现象：切换声道数量后主页/效果链输入门控的声道数显示不
  变，发声后才更新（显示由遥测/流数据驱动）。
- 改：显示值由「配置 + 选中设备/端点已知格式 + S1 生效钳
  制」即时合成，流数据到达后与实测对齐校正；切换当刻即
  反映，不等首帧。

## S5 统一系统监听模块（user 指令）

- **每平台一个单文件**专责系统音频行为监听，向上层发统
  一事件：硬件插拔、音频服务重启、设备重载/默认设备变
  更/格式变更、其它 APO 附加/分离、端点属性变化。
  - Windows：`lib/platform/windows/` 下单文件（原生侧依托
    既有 apo_inspect/MMDevice 能力，事件面收敛于此）。
  - Linux：`lib/platform/linux/` 下单文件（PipeWire/Pulse
    监听面同口径事件）。
- 现有 checkApoStatus 轮询调和与各处零散监听逐步迁入；
  S1 的 App 侧生效值对齐、S3 的即时显示以其事件为触发源。
