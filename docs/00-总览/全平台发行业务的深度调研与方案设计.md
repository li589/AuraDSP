### 一、调研与方案核心结论总结

针对各个平台的分发生态与 AuraDSP（专业音频处理系统）的独特性，调研得出的核心技术路线如下：

#### 1. Windows 发行体系（双轨制分发）
* **绿色便携版 (`.zip`)**：解压即用。内置 `portable.dat` 标记，配置与声学校准资源就地读写，零注册表污染。
* **自主研发可安装向导 (`AuraDSP-Setup-x64-v<ver>.exe`)**：
  * **子项目定位**：子项目置于 [`installer/windows/custom_installer/`](file:///d:/temp_desktop/Proj/JamesDSP/installer/windows/custom_installer) 目录内。
  * **视觉与体验**：不同于老旧的 NSIS/Inno Setup 风格，自研向导与 AuraDSP 主程序采用一致的现代暗黑/极光美学，支持平滑安装动画与多语言。
  * **深度音频集成**：支持进程锁定智能检测（关闭正在运行的 `auradsp_app.exe`）、自动注册 **AuraASIO COM 接口**（向系统 DAW 暴露虚拟声卡）、配置 **AuraVAIO** 驱动桥、创建快捷方式，并在安装结束时提供打开 Windows 声音设置控制面板（`mmsys.cpl`）的引导。
  * **安全卸载 (`uninstall.exe`)**：自复制到 `%TEMP%` 执行，彻底删除文件与快捷方式，反注册 COM，写入 Windows 标准“已安装应用”注册表，并支持保护用户个性化预设。

#### 2. Linux 发行体系（APT 原生 + 通用免安装 + 应用商店预留）
* **音频打包核心铁律（调研重点）**：AuraDSP 与 Linux 的 PulseAudio 及 PipeWire 强绑定。**严禁在安装包/沙盒中捆绑宿主机级的 `libpulse.so` 或 `libasound.so`**。必须动态链接宿主套接字，否则会导致与宿主音频守护进程握手失败或声卡丢失。
* **Debian / Ubuntu (`.deb`)**：遵循 Linux FHS 规范，`DEBIAN/control` 正确声明 `libpulse0 | libpipewire-0.3-0` 依赖，提供 `/usr/share/applications/auradsp.desktop` 与高清图标。
* **通用免安装 (`.AppImage`)**：采用静态链接的 Type 2 Runtime（使用最新 `appimagetool`），彻底解决 Ubuntu 24.04+ 因移除 `libfuse2` 导致旧式 AppImage 无法运行的问题。
* **应用商店预留（Flatpak & Snap）**：在 [`installer/linux/flatpak/`](file:///d:/temp_desktop/Proj/JamesDSP/installer/linux/flatpak) 与 [`installer/linux/snap/`](file:///d:/temp_desktop/Proj/JamesDSP/installer/linux/snap) 中预留了清单与沙盒插槽配置（授予 `--socket=pulseaudio` 与 `audio-playback` 权限）。

#### 3. 移动端与 macOS 体系
* **Android**：统一归集 Universal APK、Split-ABI 64位 APK 以及 Google Play 官方分发用的 `.aab`。
* **macOS**：规范 `.app` 递归代码签名（Hardened Runtime）、苹果官方 `notarytool` 公证以及带有 `/Applications` 软链接的标准 DMG 镜像制作。

#### 4. 产物统一汇聚策略
* 所有平台的打包脚本均由 `installer/` 对应平台目录驱动，**所有最终成品统一输出至根目录的 [`dist/`](file:///d:/temp_desktop/Proj/JamesDSP/dist) 目录**。

### 四、下一步工作建议

当完成正在进行的代码重构后，可按以下节奏逐步实施：
1. **实现 Windows 便携包归集与压缩脚本**：在 `installer/windows/portable/` 下实现从 `dist/AuraDSP-Windows-x64` 到 `.zip` 的标准化自动化封装。
2. **启动自研安装向导工程**：在 `installer/windows/custom_installer/` 中搭建向导骨架，确定具体的 UI 实现方式（推荐使用与主工程统一技术栈的独立轻量 Flutter 桌面向导工程，以保持 100% 视觉风格继承）。
3. **实现 Linux DEB 与 AppImage 自动化打包脚本**：编写 `installer/linux/deb/` 和 `installer/linux/appimage/` 的构建脚本并在 Linux CI 环境中跑通验证。
