## 3. 命名规范

- **过时命名退役**：`jdsp` 只指 vendor 内 JamesDSPPort 遗留；新自研一律 `aura*`/`Aura*`
 （如 `auradsp_engine` 已是）。`core/` 顶层名废除（按 engine/app/vendor 重分）。
- **文件**：Dart snake_case、类 PascalCase；C++ 与现有 `*_process/_recalc/apply_*`
  动词前缀一致；测试 `smoke_<效果>.py` / `<模块>_test.dart`。
- **参数 id**：`domain.name`（如 `bass.harmonics`）沿用；stage id 与 chain_page
  `kStageMeta` 同名单一来源。
- **红线**：单文件超 800 行即警告（进拆分 backlog）；`gen/`、`aidl-gen/` 手不动；
  `probe_*`、`mem_trace*`、`clicks/` 永不进 `tools/bin` 与 git。

## 4. 分层铁律（驱动层 / UI 层分明）

```text
features/effects → core → engine → vendor
     ┕━━━━━━ 禁止 core→features ━━━━━━┙
```

- 修倒挂：`EelSliderParser` 下沉到 `app/lib/src/parser/`（纯 Dart，无 flutter 依赖），
  `state.dart` 改引 parser（行为零变化，单测照跑）。
- C ABI（`auradsp_engine.h` + `.def`）是驱动/UI 唯一契约；Dart 禁直连 vendor 符号。
- RT 铁律不变：audio 线程零分配零锁零系统调用（新 dsp/ 文件头必须复述）。

## 6. DLL 政策（3 个正式位置 + 旧版归档）

- **真相源**：`build/windows/x64/Release/auradsp_engine.dll`（+ pdb）。
- **运行副本**（2 处，由脚本发，禁止手拷）：`app/windows/runner/`（随 flutter 打包）、
  `test/`（smoke 用）。其余 5 处散落副本（根/`app/`/`windows/`/`engine_api/`/
  `build/...`）**删除**，`verify_dll_copies.py` 改为"构建→分发→校验"单向工具。
- **旧版对照**：每次发布归档 `build/releases/<git-sha>/`（dll + pdb + 当次 smoke 报告），
  回退/对比只认该目录；`*.dll` 保持 gitignored。
- 跨平台预留：`build/android/<abi>/` 同结构，Dart loader 已支持 env 覆盖
 （`AURADSP_ENGINE_DLL`），加 `engine/` 子目录候选位不动。

## 7. 文档政策

- `docs/` 子目录：`00-总览/`（真相源+README索引）/`10-架构/`（APP-*/ADR/产品总览）/
  `20-执行/`（开工Spec-日期）/`30-审查/`（*报告/审计-日期）/`40-回顾/`（阶段性回顾/
  用户反馈）/`90-归档/`（过期方案）。`forensics/`、`ui-redesign/`、`adr/` 不动。
- 命名税：新文档必须带 `-YYYY-MM-DD` 后缀进 20/30/40；README 索引**同提交更新**；
  本方案落 `docs/` 根（跨 00/10/20 的纲领性文档例外）。
- 报告与执行分离：`runner.py` 输出进 `build/` 不进 `docs/`；诊断截图进 `tools/archive/`。

## 8. 跨平台

- 现状：Windows（CMake/MSVC/WASAPI，全功能）+ Android（`aidl-gen` 3018 文件在仓、
  `registrar/spike/stubs` 脚手架）。
- 方案：`engine/platform/<os>/` 收拢音频后端（`AudioOut` 接口：WASAPI 实现先行，
  AAudio/Oboe 后上）；`aidl-gen/` 移出 git（构建时生成；过渡期打 tar 包挂 Release）；
  `core/android|desktop/vendor-src` 合并到 `vendor/`（desktop：libjamesdsp+plugin-api；
  android：沿用其 vendor-src）。
- Dart 侧已跨平台：`platform/` 差异用 `Platform.isX` 收敛一处，禁散落 `if windows`。

## 10. 迁移分期（只动结构不改行为，每步独立提交+全绿）

- **P0 清理**（今天可做）：`tools/` 过程产物 → `archive/` + gitignore；
  测试 PNG → `test/golden/`；删 5 处散落 DLL；`docs/` 建子目录搬文件（git mv 保留历史）；

  vendor 合并；CMake/Dart import/smoke 路径/FFI loader 同步改。
- 每步验收：`flutter analyze` + `flutter test --concurrency=1` +
  `test/runner.py --smoke` + DLL 三处同哈希。

## 11. 风险与必改清单（执行前对照）

- import 风暴：Dart `package:` 路径、`../` 相对链、CMake `add_library` 源表、
  `auradsp_ffi.dart` loader、`verify_dll_copies.py`、`test/runner.py` DLL 路径、

- 并行协作：P0/P1/P2/P3 期间冻结目录级重构，并行 Agent 只改文件内容不改位置。
