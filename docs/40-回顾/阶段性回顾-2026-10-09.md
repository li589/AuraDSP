## 2. 架构现状（与规划的一致性）

```
Flutter UI ── Control API(engine_api v1.1 C ABI) ── 引擎核心
   │                    │                             ├─ vendor libjamesdsp（11 效果 + P-001/P-002 补丁）
   │                    │                             ├─ wrapper 自研：shelf biquad / Freeverb / viz 4096-FFT
   │                    │                             └─ FileGate（IR 六道门卫）
   ├─ 音频 isolate（handle 独占，WASAPI pump）
   ├─ viz ValueNotifier 30fps ← SPSC ring
   └─ 预设/脚本库（%APPDATA%/AuraDSP/）
```

- **一致性 ✓**：UI 不触 RT；所有新效果走既有 set_param 通道（字符串参数复用 setParamStr）；wrapper 自研效果（shelf/freeverb/viz）不碰 vendor（仅 2 个登记补丁 P-001/P-002）。
- **参数总量**：engine_api v1.1 现有 ~40 个参数 ID、10 个可操作效果节点，全部经 graph.effects 注册表可发现。
- **验证资产**：tools/ 烟囱测试 5 件套 + UI 像素断言 3 件套——每次改引擎全量回归的成本已降到分钟级。

## 3. 技术债与风险（诚实清单）

| 项 | 等级 | 说明 |
|---|---|---|
| vendor 输出限幅恒开（threshold=1.0） | 中 | 强正增益（shelf/EQ）会被钳到 1.0；UI 已注明，长期可暴露 threshold 参数 |
| eq.curve 无 get 回读 | 低 | 状态在 vendor 内部；UI 持镜像，重启后曲线不恢复（预设可存） |
| 预设不含 convolver IR path / liveprog code | 低 | 已登记 backlog；IR path 建议预设 v2 加"相对路径 + FileGate 重验" |
| setParamStr 在引擎 fatal 时的文案 | 低 | isolate 有 catch 不崩，文案可改进 |
| 真重排序（M3.5） | ADR | vendor JamesDSPProcess 硬编码链；改表驱动是 ADR 级决策 |
