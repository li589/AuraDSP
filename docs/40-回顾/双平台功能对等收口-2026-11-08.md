# 双平台功能对等收口（2026-11-08）

> 结论：**Linux 与 Windows 核心功能已对等。** 剩余差异分两类——平台生态
> 决定的结构性差异（各自独有机制、语义已对齐），与已实现待真机验收的
> 清单项（非功能缺失）。本文为对等状态的销账矩阵，验收状态以
> `Linux真机验证清单.md` 为准，本文不代签验收。

## 1. 功能矩阵（代码层）

| 功能面 | Windows | Linux | 说明 |
|---|---|---|---|
| 引擎与效果链 | 同一源码 | 同一源码 | 同一 C ABI（56 符号）；参数表单一真源双端对账 |
| 音频模式 | sysapo / vaio / vbcallback / asio | system / virtual / driver + ALSA 专家 | 语义对等、机制不同（见 §2） |
| 本地设备泵 | WASAPI | PulseAudio simple / ALSA 直连（period 256） | `supportsLocalDevice` 双平台为真 |
| 插件扫描 | 快扫本地 + 深扫按位数进宿主 | 同左 | 快扫纯文件头、深扫回工厂真值，双平台同构 |
| 插件托管 | VST3 / CLAP / VST2；x64 进程内 + x86 位桥隔离 | 同左 | 双宿主 `plugin_host_x64` / `plugin_host_x86`，IPC v5 |
| 插件编辑器 GUI | Win32 原生窗口嵌入 | X11 运行时 dlopen + XEmbed | 三格式双平台均可开编辑器 |
| 插件预置 | .fxp / VST3 state / CLAP stream | 同左 | 2026-11-08 审计轮双平台同修（原子写 + 身份校验 + 256MiB 上限） |
| 托盘 / 自启 | 托盘 + 注册表自启 | 托盘 + XDG autostart | — |
| 媒体键集成 | SMTC | MPRIS | 设计对等（轮询粒度差异已裁定可接受） |
| 配置与数据目录 | %APPDATA%\AuraDSP | XDG config/data 拆分 + 存量迁移 | — |
| 调试体系 | DBG 日志（ON/OFF 双口味 CI 门禁） | 同左 | d4b/debug-policy 门禁 2026-11-08 移入 PLATFORM_ANY 双跑 |
| 安装器 | 单文件向导（驱动/便携/安装三模式） | deb + 驱动配置 deb + AppImage + tar.gz | 双平台一键打包链均已落地并实测 |
| EEL2 脚本 IDE | 手册 / 编辑器 / 模板 | 同左（同一 Dart 代码） | 2026-11-08 手册与 VM 函数表全量对齐（含声道语义） |

## 2. 结构性差异（平台本质，不作对等项）

| Windows 独有 | Linux 对应物 | 裁定 |
|---|---|---|
| ASIO 桥 / AuraVAIO 内核驱动 / Voicemeeter 桥（`supportsBridges` 仅 Windows） | PA null-sink（virtual）+ snd-aloop（driver）+ ALSA 专家直连 | 机制不同、模式语义对齐，ADR-012 已裁定 |
| SysAPO 附加模式 | 无对应概念（Linux 无 APO 架构） | 生态缺位，非功能缺失 |
| WASAPI 独占/事件驱动 | PA/ALSA 协商 + XRUN 自恢复 | 各用平台原生路径 |

共同缺席（双平台一致，不算不对等）：LV2 宿主（独立立项，已裁定不在本线）。
