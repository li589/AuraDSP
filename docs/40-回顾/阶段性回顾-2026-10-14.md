## 6. ASIO 宿主 Phase 1（`fcd0f3f`，当日追加，Spec 出口全核销）

Spec 批准后当日落地。核心结论：

- **宿主而非驱动**：`asio` = 加载第三方驱动的 COM `IASIO`，`bufferSwitch`
  回调内调 `auradsp_process`；写驱动属 `01_vaio_driver`（WDK）范畴。
- **GPLv3 路线**：SDK 2.3.4 双许可中选定 GPLv3；不 vendor 不进 release，
  v1 不用 ASIO 商标；专有路线未签约不启用。
- **SDK 最小源集 3 个**：`common/asio.cpp` + `host/asiodrivers.cpp` +
  `host/pc/asiolist.cpp`（`asiodrvr.cpp` WINDOWS 下 `#error`；combase/register/
  dllentry 驱动侧不需要）——Spec 初版列 6 源，落地时实测收敛。
- **命名语义坑**：SDK 驱动名 = 注册表 `Description`（DSD 转码器子键
  `DSDTranscoder` → 显示名 `DSD 转码器 (DoP/Native)`，GBK 字节）；smoke
  初版误用子键名对账 mismatch，已修为 Description 基准（`newDrvStruct` 语义）。
- **实测**：probe 枚举 7 驱动 6 ok（Potato Insert 真实加载失败如实记录）；
  tone FL Studio ASIO 259 帧 × 512/44100 = 3.007s、VM Virtual
  69 帧 × 2048/48000 = 2.944s，peak 均 0.25；全量 smoke **53 项 100% PASS**。
