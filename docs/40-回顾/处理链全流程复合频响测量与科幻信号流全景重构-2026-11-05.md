# 处理链全流程复合频响测量与科幻信号流全景重构

**日期**：2026-11-05  
**分支**：`feature/linux`  
**涉及模块**：`features/chain/chain_spectrum_analyzer.dart`、`features/chain/chain_scifi_flow_panel.dart`、`features/chain_page.dart`、`core/state.dart`、单元测试套件

---

## 1. 核心改进背景与目标

为进一步提升 AuraDSP 专业音频处理链的可视化洞察力与交互质感，针对处理链页面实施两项核心演进：
1. **全流程复合频响测量（EqualizerAPO 风格）**：体现从首个前置效果器至末级插件槽位的端到端综合传递函数频响状态，支持各声道/Voicemeeter 总线切换，兼具静音仿真与端到端延迟测定反哺。
2. **全局信号流全景科幻面板重构**：解决原流图简陋粗糙且缺失插件实时物理位置的问题，提供左侧大标题、右侧科幻发光展开按钮、PCB 电路动态流光粒子走线、实时 Stage 0~4 插件芯片级节点映射、科技感能量流光箭头，以及自由平移缩放触控交互。

## 2. 关键架构设计与落地细节

### 2.1 全流程复合频响测量仪 (`ChainSpectrumAnalyzer`)
- **纯内存静音仿真解析**：
  - 严禁向物理扬声器或声卡驱动写入音频样本，全程采用离散解析传递函数数学模型（`FullChainTransferCalculator`）。
  - 在 20 Hz ~ 20 kHz 对数空间划分 256 点等比频网：
    $$f_i = 20 \times 10^{\frac{i}{255} \cdot 3} \quad (i = 0, \dots, 255)$$
  - 级联各活跃模块传递函数增益（dB）：
    - **Filter**：二阶 Biquad 数字滤波（HPF 高通截频、LPF 低通截频、BPF 带通截频）。
    - **Shelf (Bass Shaping)**：RBJ Low-Shelf 滤波器传递函数。
    - **Bass Boost**：心理声学低音增强钟形滤波（围绕 `bassCutoff` 的峰值增益）。
    - **EQ**：15 频段参量/图形均衡器 RBJ Peaking EQ 增益级联。
    - **Dynamic EQ**：低、中、高三频段静态基底增益叠加。
    - **Loudness**：ISO 226 等响轮廓反向补偿模型（低频最高抬升 +4.5dB，高频微升 +2dB）。
    - **Crossfeed**：双耳互馈模型（单声道高频耳廓阴影衰减，立体声低频交叠平滑）。
    - **Tube / Exciter**：高频泛音微量提升。
    - **Limiter & Output Gain**：全局增益平移。
    - **Plugin Slots**：读取槽位激活态与延迟，透明直通/保持增益。
- **声道切换与 Voicemeeter (VB) 专属适配**：
  - 支持“立体声 (L/R)”、“左声道 (L)”、“右声道 (R)”切换。
  - **Voicemeeter 专属总线下拉**：
    - 仅在 Voicemeeter API 模式下显现。
    - 基于当前版型（Standard, Banana, Potato）与设置中启用的总线掩码 `vbBusMask`，动态列出 `(A1 [Master])` 到设置中勾选的总线。
    - 当用户选定未启用总线时，精确识别并提示“总线未启用处理，信号直通 (0 dB)”。
- **端到端延迟测定与反哺**：
  - 全链路总延迟测定公式：
    $$T_{\text{total}} = T_{\text{core\_dsp}} + T_{\text{plugins}}$$
    - $T_{\text{core\_dsp}}$：前瞻限幅器 (1.5ms) + 心理声学低音 (4.0ms) + Haas (延迟滑块值) + 空间化 (1.2ms) + 卷积 IR 采样折算。
    - $T_{\text{plugins}}$：遍历 Slot 0~3，累加活跃且未旁路插件报告的 PDC 采样点折算毫秒数。
  - 测定结果立即反哺调用 `model.updateFullChainMeasuredLatency(totalLatencyMs)`，自动广播刷新全系统顶栏徽标、主页指标与处理链徽章。
- **EqualizerAPO 经典绘图界面**：
  - 对数刻度频率网格（20, 50, 100, 200, 500, 1k, 2k, 5k, 10k, 20k）。
  - dB 刻度线（-30, -20, -10, 0, +10, +20 dB），其中 0 dB 采用发光高亮虚线强调。
  - 平滑曲线 (Smooth Spline) 与折线 (Polyline) 一键切换。
  - 鼠标悬浮与触屏滑动十字准星与 Tooltip（精确展示光标处频率与增益）。

### 2.2 科幻全局信号流全景面板 (`ChainScifiFlowPanel`)
- **未来感触发条**：
  - 左侧：大号粗体标题“全局信号流顺序”（15px，`FontWeight.w700`，带青色霓虹状态灯柱），下附“全链路 24 节点拓扑 · 实时 Stage 0~4 插件注入映射 · 支持平移缩放”副标题。
  - 右侧：科幻胶囊发光按钮“显示全景 / 收起面板”（带芯片路由图标、霓虹呼吸发光边框）。
- **HUD 展开特效与毛玻璃覆盖层**：
  - 点击后平滑触发 380ms `CurvedAnimation(Curves.easeOutCubic)` 展开，覆盖于“处理顺序与状态”区域上方。
  - 采用深空深色背景（`p.bg.withValues(alpha: 0.94)`）与顶部发光 Accent 边界。
- **PCB 电路板装饰与流光粒子动画**：
  - `_CircuitBoardPainter`：在全景流图背后绘制精密 PCB 走线（水平/垂直导线、45 度折角线、金属焊盘过孔圆环）。
  - 流光粒子动效：由 `AnimationController` 驱动发光能量粒子沿导线循环滑动流动，呈现信号在电路中通电运算的生机感。
- **实时插件物理位置嵌入**：
  - 真实物理处理顺序精准对齐底层引擎：
    1. **Input Gate (输入门控)** [Pinned First]
    2. **Stage 0: Pre-DSP 插件槽位** [芯片插槽节点]
    3. **前置核心节点** (Gate, Filter, BassMono, Shelf)
    4. **Stage 1: Pre-Vendor 插件槽位** [芯片插槽节点]
    5. **Vendor 主效果器节点** (Tube, Comp, Bass, EQ, ArbMag, Convolver, DDC, LiveProg, Crossfeed, Stereo, Haas, Spatial, Exciter)
    6. **Stage 2: Post-Vendor 插件槽位** [芯片插槽节点]
    7. **Reverb (混响)**
    8. **Stage 3: Post-Reverb 插件槽位** [芯片插槽节点，默认插槽阶段]
    9. **Loudness (后置等响)**
    10. **Output Gate (输出门控)** [Pinned Last]
    11. **Limiter (前瞻限幅器)**
    12. **Stage 4: Post-Limiter 插件槽位** [芯片插槽节点，总输出级]
    13. **Audio Output (最终音频输出)** [Pinned Out]
  - 插件节点外观采用青墨高科技芯片插槽样式，明确标识 `[Slot X: 插件名]`、格式（VST3 / CLAP / VST2）、延迟样本与旁路状态。
- **重绘科技能量流光箭头**：
  - 彻底摒弃原有简陋文本箭头，使用自定义 `_EnergyArrowPainter` 绘制能量光标（导引中轴发光线 + 双折角能量光标 `»`）。
- **交互控制与视角复位**：
  - 基于 `InteractiveViewer` 实现鼠标左键拖拽平移、滚轮缩放（0.5x ~ 2.2x）及触屏手势平移缩放。
  - 顶部右上角配备“100% 复位”按钮（一键平滑归位）与“收起全景”按钮。

### 2.3 效果器延迟计算全域统一与工业级主控监视舱重构（消除 AI 味）

1. **延迟状态机规范统一 (`LatencyMode`)**：
   - 彻底梳理并定义全平台一致的 5 态延迟模型：
     - `measured`（实测）：声卡/驱动实测权威值，按毫秒数阶梯着色（$\le 5$ms 纯声学绿、5~15ms 青色、15~30ms 琥珀黄、$>30$ms 橙红）。
     - `estimated`（实时参数推算）：基于效果器内部物理模型实时推算（如 Haas 滑块 delay、Limiter 1.5ms、Spatial 1.2ms、Bass 4.0ms、卷积 IR 采样帧数），统一显示 `≈ X.X ms` 并采用统一天青色。
     - `probing`（测定中）：统一显示 `↻ 测定中` 动画。
     - `zero`（已启用零延迟直通）：统一显示 `0.0 ms` 次级弱灰。
     - `unmeasured`（未测定）：统一显示 `-- ms`。
   - 提供单一色彩权威映射函数 `latencyColorByMode(mode, ms, palette)`，全 19 个效果器卡片徽标统一样式与色板，消除视觉割裂。

2. **测定路径唯一性**：
   - 卡片内点击测定或主控制舱统一测定，全部收敛至权威异步管道 `refreshComponentLatency(compId)` 与 `refreshAllComponentLatencies()`，拒绝各卡片私自派发或硬编码常数。

3. **右上角主状态总控舱 (`MasterStatusConsole`) 消除 AI 味**：
   - **全面废弃**：彻底移除悬浮彩色大胶囊药丸与 60fps 呼吸光晕动画（`PulseDot`）。
   - **工业级 DAW 监视舱设计**：
     - 外观：深灰工控微切面面板（高度 28px、4px 圆角、微弱 1px 内凹边框）。
     - 固态声学微型 LED 指示灯：5.5×5.5px 纯色微圆角硬件 LED（正常纯绿常亮、旁路琥珀黄、待机暗灰、故障纯红），无夸张光晕与动画。
     - 精密 Monospace PDC 仪表：等宽字体显示毫秒延迟，1px 刻槽微凹分隔线。
     - 专业交互：左侧指示灯轻按可切换全局 DSP 旁路/激活，右侧轻按即刻触发权威延迟重测。
