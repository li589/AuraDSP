| # | 发现 | 修复 |

## 二、安全与边界审查（`fb10200`）

范围：POSIX 插件宿主（IPC/shm/socket/进程）、Dart FFI 层（PA/ALSA/字符串与数值边界）、平台与数据层（MPRIS/调试日志/XDG/自启/配置）。

### 确认并修复（8 项）

| # | 级别 | 问题 | 修复 |
|---|---|---|---|
| S1 | 中 | 插件宿主控制 socket 无对端认证：路径回退 `/tmp` 时，同机其他用户可抢先 connect 向宿主下达「加载任意插件路径」命令（宿主以属主身份 dlopen），或抢先 bind 假宿主向引擎回灌伪造应答。XDG_RUNTIME_DIR 在位时目录私有（0700），此为回退路径的防御纵深 | 宿主 bind 后 `chmod 0600` + accept 后 `SO_PEERCRED` 校验同 uid；客户端 connect 后镜像校验，对端 uid 不符立即失败回落进程内（不重试被污染路径）。门禁新增 3 条 [sec] 不变量，隔离链在校验启用下实测全绿 |
| S2 | 低 | 宿主音频线程声道数未钳制：`reserved` 由对端写入共享内存，越界 channels 会让交错循环写爆栈缓冲（frames 有钳制、声道没有，形态不一致） | 与 frames 同口径钳制到 `kChannels`。**Win32 宿主同形态**（`auradsp_plugin_host_main.cpp` 同一循环），记录待 dev 侧跟进，本分支不动 Windows 宿主 |
| S3 | 低 | `SharedRegion::open` 按全尺寸 mmap 前不校验对象尺寸：同名小对象（残留/异构）会让后续访问 SIGBUS | 映射前 `fstat` 校验 `st_size ≥ sizeof(SharedAudio)`，门禁加不变量 |
| S4 | 中 | PulseAudio 设备名回调无异常防护：设备名来自音频服务器，本机任何进程可注册任意字节的 sink/source 名，非法 UTF-8 使 `toDartString` 抛 FormatException，逸出 NativeCallable 回调即成为音频 isolate 的未捕获错误 | `_collectNames` 回调体加 try/catch + swallow（与同文件 server-info 回调的既有口径一致），坏条目跳过 |
| S5 | 低 | `PulseAudioOut.currentPadding` 无负值守卫：延迟读数是 uint64，异常服务器给出 ≥2⁶³ 时经 FFI 落 Dart 为负，乘采样率亦可溢出回绕；负 padding 让泵超额写入、延迟失控 | 负值收敛到 0（与 ALSA 侧既有守卫对齐） |
| S6 | 低 | `debug_trace` 默认路径硬编码反斜杠分隔符：Linux 上 trace 实际落在根目录怪名文件，功能静默失效（S4 修过 debug_log 的同类问题，此文件当时漏网） | 改走 `Platform.pathSeparator`，与 debug_log 口径统一 |
| S7 | 低 | 调试日志位于共享 `/tmp` 且文件名可预测：同机用户可预置 symlink 指向属主文件，追加打开会把日志写进目标文件 | 目标本身为符号链接时改用带 pid 的文件名，再次命中链接则放弃本次日志（正常环境与 CI 仍走固定名） |
| S8 | 低 | XDG 自启 `.desktop` 的 Exec 参数未转义：可执行路径含 `"`/`$`/反引号时破坏条目或被登录会话解析器展开 | 纯函数 `desktopExecArg` 按 desktop-entry 规范转义 + 单测（2 例） |

### 审查通过、无需动作

- IPC 帧协议双向均先校验 magic/version 并以 `kMaxControlPayload` 封顶 payload 再分配；Reader 越界返回失败。
- shm 创建 `O_EXCL + 0600`、同名残留单次 unlink 重试；open 侧头部 magic/version/maxSlots/transportFrames 全量校验（S3 是其尺寸维度的补强）；唤醒信号量 0600；宿主 PR_SET_PDEATHSIG + getppid 看门狗。
- ELF 位数探测只读 5 字节定长并校验实读数；malformed 文件返回「未知」不进入加载。
- MPRIS 元数据解析全量类型守卫（`_asString/_asInt/_asStringList`），单播放器失败不拖垮整轮枚举；总线侧消息尺寸由 D-Bus 守护进程自带上限约束。
- PA 会话清理与幂等关闭（一期审查 F1 已修）；配置驱动的设备名字符串属用户自有配置面，非外部输入。
