### 混合宿主路由（`0a93bc5`）
- 64 位走**进程内**，32 位走**进程外位桥**（`plugin_host_x86`，shm 环 + socket）；client 侧按位数分派。
- 意义：32 位插件不再要求整条链进沙箱，常用 64 位插件保持零拷贝进程内路径。

### 审查修复 R1（`ea72e75`）
- **现象**：`XDG_RUNTIME_DIR` 指向已不存在的目录（陈旧会话变量/临时目录被清）时，`AURA_PLUGIN_HOST_MODE=process` 下扫描返回 0、加载全灭，且无回落无报错。
- **根因**：`socketBaseDir()` 只校验 env 是绝对路径，不验存在性；宿主 bind 必然失败，而远程模式无本地回落。
- **修法**：`stat` 目录 + `access(W_OK)` 校验，不合格回退 `/tmp`；门禁加源级不变量。
- 部署侧同源教训：构建命令输出被 `grep -c` 吞掉导致误判「已重编」（实际构建没跑）——**判定命令禁用管道尾巴掩盖退出码**。

## 氛围频谱柔化重做（用户反馈「背景频谱模糊做不好 + 有个雷霆大弧形不知道在干啥」）

### 定位
- 「大弧形」= `chrome.dart` `_AmbientPainter` 里唯一的径向渐变椭圆（`drawOval`，中心 `(w/2, 0.98h)`，宽 0.85–1.2w、高 0.42–0.72h）。全仓只有这一处 `Gradient.radial`。
  它的上缘横贯下半屏，与频谱毫无形状关系 → 看起来就是一道来路不明的电弧。
- 另一个隐性事实：原实现**根本没有模糊**，只有一层竖向渐变，所以轮廓是硬边。

### 硬约束（决定了不能用滤镜）
`style_spectrum_bars.dart:65` 有实测结论：**逐帧 `MaskFilter.blur` 会把进程内存推到 GB 级并拖慢光栅线程**（931b62a 修的就是这个）。因此走「几何叠层」而不是滤镜。

### 新实现
1. **删除大椭圆**，光晕改为贴频谱轮廓：同一条闭合带沿竖直方向逐级上移，叠 **9 层**，每层不透明度 0.009 → 等效一次廉价模糊；单层只贡献 ~1%，不会出现「等高线」台阶（第一版只叠 3 层，预览图里出现明显台阶，已推翻）。
2. **横向柔化**：沿轮廓补 3 道宽描边（10/22/40 px，alpha 0.014/0.009/0.005），先画、再被主体填充盖住大半，只在峰侧露出「衣领」——解决峰侧硬斜边。
3. **主体**保留竖向渐变（0.115 × 明暗系数），跨度收窄到 0.85×波峰高度，让峰顶更「发光」而不是「涂色」。
4. **冠部细高光**：1.1 px 描边，alpha 随低频呼吸（0.10 + 0.16×bass），给柔化后的轮廓一条「玻璃边」。
5. 低频 `bass` 改为调制**层间距**（`h*(0.0035+0.0025*bass)`）与冠部亮度，不再吹椭圆。
6. 性能：零滤镜、零离屏层、零逐帧 Shader 重建（主体渐变按尺寸缓存）；14 次 path draw/帧 @20fps。静音早退与不可见早退保持原样。

### 验证方式（新增可复用探针）
- 加 `@visibleForTesting ambientSpectrumPainterForTest()` 钩子，把私有 painter 暴露给离屏渲染。
- 探针 `tools/probe/ambient_spectrum_preview_test.dart`：合成「低频厚 + 2k 人声峰 + 6k 齿音峰 + 高频滚降」的 32 带频谱，输出 1200×800 PNG 四种
  （dark_music / dark_bass / light_music / dark_silent）到 `build/tmp/`，肉眼比对台阶、柔边、明暗强度。
  放在 `tools/probe/` 而非 `test/`：`flutter test` 只扫 `test/`，不会被门禁执行（与 probe 目录定位一致）。
- 迭代记录：v1（3 层渐变）→ 预览出现两条等高线台阶 → v2（9 层微位移）→ 平滑；再补宽描边柔化峰侧 → 定稿。
