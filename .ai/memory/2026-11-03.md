### 混合宿主路由（`0a93bc5`）
- 64 位走**进程内**，32 位走**进程外位桥**（`plugin_host_x86`，shm 环 + socket）；client 侧按位数分派。
- 意义：32 位插件不再要求整条链进沙箱，常用 64 位插件保持零拷贝进程内路径。

### 审查修复 R1（`ea72e75`）
- **现象**：`XDG_RUNTIME_DIR` 指向已不存在的目录（陈旧会话变量/临时目录被清）时，`AURA_PLUGIN_HOST_MODE=process` 下扫描返回 0、加载全灭，且无回落无报错。
- **根因**：`socketBaseDir()` 只校验 env 是绝对路径，不验存在性；宿主 bind 必然失败，而远程模式无本地回落。
- **修法**：`stat` 目录 + `access(W_OK)` 校验，不合格回退 `/tmp`；门禁加源级不变量。
- 部署侧同源教训：构建命令输出被 `grep -c` 吞掉导致误判「已重编」（实际构建没跑）——**判定命令禁用管道尾巴掩盖退出码**。

## 氛围频谱柔化重做（用户反馈「背景频谱模糊做不好 + 有个雷霆大弧形不知道在干啥」）

### 定位
- 「大弧形」= `chrome.dart` `_AmbientPainter` 里唯一的径向渐变椭圆（`drawOval`，中心 `(w/2, 0.98h)`，宽 0.85–1.2w、高 0.42–0.72h）。全仓只有这一处 `Gradient.radial`。
  它的上缘横贯下半屏，与频谱毫无形状关系 → 看起来就是一道来路不明的电弧。
- 另一个隐性事实：原实现**根本没有模糊**，只有一层竖向渐变，所以轮廓是硬边。

### 硬约束（决定了不能用滤镜）
`style_spectrum_bars.dart:65` 有实测结论：**逐帧 `MaskFilter.blur` 会把进程内存推到 GB 级并拖慢光栅线程**（931b62a 修的就是这个）。因此走「几何叠层」而不是滤镜。

### 新实现
1. **删除大椭圆**，光晕改为贴频谱轮廓：同一条闭合带沿竖直方向逐级上移，叠 **9 层**，每层不透明度 0.009 → 等效一次廉价模糊；单层只贡献 ~1%，不会出现「等高线」台阶（第一版只叠 3 层，预览图里出现明显台阶，已推翻）。
2. **横向柔化**：沿轮廓补 3 道宽描边（10/22/40 px，alpha 0.014/0.009/0.005），先画、再被主体填充盖住大半，只在峰侧露出「衣领」——解决峰侧硬斜边。
3. **主体**保留竖向渐变（0.115 × 明暗系数），跨度收窄到 0.85×波峰高度，让峰顶更「发光」而不是「涂色」。
4. **冠部细高光**：1.1 px 描边，alpha 随低频呼吸（0.10 + 0.16×bass），给柔化后的轮廓一条「玻璃边」。
5. 低频 `bass` 改为调制**层间距**（`h*(0.0035+0.0025*bass)`）与冠部亮度，不再吹椭圆。
6. 性能：零滤镜、零离屏层、零逐帧 Shader 重建（主体渐变按尺寸缓存）；14 次 path draw/帧 @20fps。静音早退与不可见早退保持原样。

### 验证方式（新增可复用探针）

## 修复「氛围背景开关没有用」（用户实测反馈）

- **现象**：设置里关掉氛围背景，回到主页背景仍在。
- **根因（两层叠加）**：
  1. 外壳 `AppShell` 用 `IndexedStack` 保活页面，且 `_pages[i]` **缓存页面实例**；
     模型 `notifyListeners()` 不会让保活页重建（父级传入 same widget → Element 短路）。
  2. 设置是**模态覆盖层**（`AppPage` 枚举里根本没有 settings），开关不改变
     `visiblePage` → HomePage 内部的 `ValueListenableBuilder<AppPage>` 也不触发。
  两条件叠加 = 配置写进去了，但首页 build 一次都没跑。
- **修法**：新增页面级订阅源 `AppModel.ambientEnabled`（ValueNotifier<bool>，
  构造时从 config 初始化、`setAmbientOn` 同步推送、`dispose` 释放）；
  HomePage 用 `ValueListenableBuilder<bool>` 只听它，开关一变就地重建。
- **门禁**：`ambient_background_setting_test` 增加外壳级用例（pump `AppShell` →
  `setAmbientOn(false)` → **不切页** → 断言 `AmbientSpectrum` 消失）。
  反向验证：把 HomePage 退回「只听 model.ambientOn」→ 该用例立刻转红；
  恢复后 4 条全绿。
- **教训（可复用）**：凡「设置里改、别的页要立刻响应」的开关，**不能只靠 model
  notifyListeners**——保活页收不到；必须给一个专门的 ValueListenable，
  页面订阅它。此坑对 theme/locale 之外的逐项开关（如 vizFps）同样适用。
- 全量：644 通过、0 断言失败；两处加载失败（`Connection closed before test suite
  loaded`）单跑 26/7 全过 → 既有环境抖动。构建已同步 dist（app.so 15:52，
  `ambientEnabled` 在包内命中 2 次）。

## 龙卷风可视化：站不直 + 没律动（用户反馈两连）

### 「站不直」根因
- `_axisX = cx + sway * pow(1-u, 1.6)`：u=0 是底部 → **摆动加在底座、顶部被钉死**，
  与龙卷风「根钉地、顶摆」的物理直觉相反，整根锥体像斜着晃。
- 底部风眼吸积盘还额外 `center = cx + sway` 跟着平移，且 haze 渐变矩形中心
  用的是 `cx`、drawOval 用的是 `cx+sway` —— 渐变和椭圆错位。
- 修：`_axisX = cx + sway * pow(u, 1.35)`（根锚定、顶摆）；风眼/吸积盘/地面尘
  全部钉死在 cx（地面尘连签名里的 sway 都删了）。

### 「变化很少/缺律动」根因（比想象的严重）
- 所有渐变 Shader 的缓存 key 是**常量字符串**（`'haze____'`/`'cone____'`…），
  但渐变颜色里烘焙了当帧的 `bassLvl` —— **首帧之后 alpha 永远冻结**。
  注释宣称「按尺寸与平滑低音 6 档量化缓存」，实现根本没做。
- 幸存的反应只有几何 ±6% 呼吸 + 粒子 alpha，且全部再叠一层
  `bassLvl = (bass*5).round()` 的 6 档量化 + 0.04~0.06 的微弱系数。
- 修：key 带档位（`'haze_$bl'`，8 档，档位变了才重建 —— 与「绝不逐帧建 Shader」
  的既有纪律不冲突，缓存上限 48 → 128）；系数全部换成连续值并加大。

### 新增律动
- `_pulse` 节拍包络（瞬时攻击 + exp(-5.5dt) 回落）：驱动 `maxR`（0.20+pulse×0.09）、
  `funnelH`（0.62+pulse×0.10）、转速（+pulse×1.6）、泛光叠层椭圆（纯色无 shader）。
- **频段→形状耦合**：`_bandAt(u)` 让锥体/光带半径按对应高度的频段能量鼓包
  （低频在根部、高频在顶部），±16~22% —— 形状直接跟音乐走，不再只是整体缩放。
