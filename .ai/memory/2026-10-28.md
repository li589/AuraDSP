# 2026-10-28（续）— Liveprog 行号栏软换行与垂直对齐修复

## 现象
1. 编辑器长行软换行后，其后的行号仍按“一行一高度”排布，与正文错位；
2. 行号文字比对应正文行始终偏下一点点。

## 根因
- 行号栏用 `md + i * lineHeight - scrollOffset` 假定每条逻辑行恰占一个可视行，未考虑 TextField 的软换行。
- `lineHeight` 取自 `TextPainter.preferredLineHeight`（向上取整），而正文实际行高是 `1.5 × fontSize`（12.5 → 18.75，取整 19），逐行累积漂移；`-1.5` 硬编码补救只是继续掩盖误差。

## 修复
- 新增 `EditorLineMetrics`（`features/liveprog/line_number_gutter.dart`）：与 TextField 同 style/strut/textScaler、同可见文本宽度逐逻辑行 `TextPainter.layout` 实测，产出 `tops[] / heights[] / lineAdvance`。
- 页面在编辑器外层 `LayoutBuilder` 中算文本宽度（内容区 − 大纲栏 201 − 行号栏宽 − 2×contentPadding），并缓存（文本/宽度/字号/缩放任一变化才重算）。
- 行号栏按 `tops` 定位、按 `heights` 撑起点击区；行号只画在逻辑行首行；行号文字 strut 高度强制 `lineAdvance / fontSize`，与正文同一行盒 → 去掉 `-1.5` 硬编码。
- 可见行范围改用二分查找（覆盖“始于视口上方、折行进入视口”的长行）。

## 验证
- `flutter analyze` 两文件无告警；`flutter build windows --release --no-tree-shake-icons` 成功。
- 临时几何断言（已删除）：超长首行折成多行时，行号 1/2/3 与 `RenderEditable.getLocalRectForCaret` 行顶差 0.0px。
- `test/liveprog_ide_integration_test.dart` 11/11 通过（系统 TEMP 被外部清理导致 `flutter_test_listener` 目录丢失时需改 TEMP 路径）。
