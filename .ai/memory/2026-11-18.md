## 一、CI J6 连双红（新发现缺口，此前未登记）

**现象**：r50（run 44302073171）与 r51（run 44315947430）收口 CI 均
`failure`，唯一红 job J6 dart-tests；三次重试**确定性**失败 3 例，
但两份收口文只记「开发机门全过」，未提 CI、未入未决登记。

**根因（平台语义，非回归）**：
1. `display_channel_count_test` 两例：能力入口
   `_capabilityChForMode()` 首行 `if (!PlatformProfile.isWindows) return null;`
   → Linux 上不钳制，断言 2 实得 8。
2. `test_source_state_test` 的 ASIO 用例：基线 `setAudioMode('vaio')`
   在 Linux 被 `AudioModes.normalize` 归一为默认 `'system'`
   （vaio/asio 不在 Linux 三模式集合），`audioMode` 断言落空。

**判定手法（关键）**：本地 Windows 同两文件 16/16 全过 → 排除回归，
锁定平台差异；再读 `run_dart_tests.py` 发现既有 `WINDOWS_ONLY`
整文件跳过清单，说明此类差异是本仓已知范式。

**修法**：用例级 `skip: !PlatformProfile.isWindows ? '理由' : null`
（与本仓 settings_asio/paradigms/vaio 三个测试同款写法），不整文件
跳过——保留同文件跨平台用例的覆盖。

**验证**：`skip` 机制用「体内必失败」临时探针证实：
输出 `~1 All tests skipped`、EXIT 0（探针已删）。
