- owner 裁定发布规范：版本号 `vXX.XX.X`（主/次各最多两位数），
  首个正式版 **v0.1.0**（0.5.0 为开发期内部版本退役，pubspec 与
  README 徽章已对齐）；当前发行仅 Win+Linux；正式发行只从
  `main` 构建且门禁/测试全绿；完整发行 = 每平台驱动包 + 便携包
  + 正式安装包三件；installer 子项目完善为首发前置。落点：
  installer/docs/01 发布总则 + §2.3 构成表 + §5 门禁、03 §6、
  02 尾部定位（提交 e83c031）。根 README 的 Linux 巨型单元格
  按 owner 意见由 956 字精简到 382 字——README 忌注水长文。
- installer 总体设计（docs/05，提交 31fe4e7）：deb 手写
  staging+dpkg-deb；AppImage 用维护线 appimagetool 1.9.1 +
  type2 runtime **双钉版**（runtime 默认现下滚动 continuous 是
  业界已点名的供应链坑，必须 --runtime-file 钉日期版+SHA256）；
  Flatpak runtime 更新 25.08、Snap base 更新 core24；Windows
  驱动正式签名（Attestation/EV）登记为最大外部风险。
- Linux 打包落地：installer/shared/version_resolver.py（pubspec
  → env + 格式校验 + --check-tag）+ installer/linux/pack.sh 总
  入口 + deb/driver/appimage/portable 四构建脚本 + flatpak/
  snap 清单。四类产物本机实物验证（0.1.0）：双 deb 结构与权限
  校验、AppImage 解包完整、deb 载荷 Xvfb+PA 下启动存活 10s、
  ldd 缺失 0。实测教训两条：① bundle 源文件权限是 770，
  打包必须做权限规范化（目录 755/ELF 755/其余 644），否则装出
  只有 root 能读的目录，dpkg-deb 也会直接拒收控制目录；
  ② AppDir 混装 i386 的 plugin_host_x86 时 appimagetool 需要
  显式 `ARCH=x86_64`。
