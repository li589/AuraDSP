# .ai/ — AI 智能体自治知识库

> 本目录由各 AI 编码智能体（Antigravity、Codex、Cursor、Claude 等）自主维护与沉淀，无需人工介入。

## 目录结构

- `memory/`：项目演进历史、每日工作日志、重大事故与关键经验教训（原 `.workbuddy/memory` 已平滑迁移至此）。
  - `MEMORY.md`：长期备忘与架构级避坑总览；
  - `2026-10-xx.md`：按日期记录的详细实施与问题排查过程。
- `rules/`：跨智能体硬规则与设计规范（现有 `ui_design_spec.md`：UI 视觉/交互基线）。
  （历史遗留命名 `guidelines/` 从未落盘，2026-10-28 按实际目录改正。）

## 智能体协作守则
1. 任何重构、Bug 修复、算法调优或测试改进，均应在完成阶段性交付后在此留下详细记录；
2. 记录关键经验教训时，务必注明根因、复现方法、解决方案与验证手法；
3. 保持与根目录 `AGENT.md` / `CLAUDE.md` 及 `docs/` 官方文档的同步。
