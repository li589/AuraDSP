# AuraDSP 产品主页 · 设计契约 v5

单文件、零依赖、纯静态：`promo-site/index.html`。深色仪器面板语汇的编辑式版面，
用于商用发布级产品主页。v5 在 v4 基础上做五维度精修：文案、SVG 细节、
文字与控件相对尺寸、字体、持续动效。

## 2. 排印体系

### 2.1 字号阶梯

九个 CSS 变量，替代 v4 中 10.5–13.5px 的模糊聚集：

```css
--fs-display: clamp(37px, 5.15vw, 69px);   /* h1             */
--fs-h2:      clamp(25px, 2.86vw, 38px);   /* 区块标题        */
--fs-h3:      clamp(16.5px, 1.42vw, 20px); /* 小标题 / 步骤   */
--fs-lead:    clamp(15.8px, 1.16vw, 17.4px);/* 首屏导语       */
--fs-body:    16px;                        /* 正文            */
--fs-sm:      14.4px;                      /* 密集正文        */
--fs-ui:      13.6px;                      /* 导航、按钮      */
--fs-label:   11px;                        /* 全大写小标签    */
--fs-micro:   10.4px;                      /* 图版说明、元数据 */
```

display : body ≈ **4.3 : 1**，label 与 body 之间留出 1.45× 间隔，避免中间层拥挤。

### 2.2 字体栈

```css
--serif: "Source Han Serif SC","Source Han Serif CN","Noto Serif SC",
         "Noto Serif CJK SC","Songti SC",STSong,
         "Iowan Old Style","Palatino Linotype","Book Antiqua",Georgia,serif;
--sans:  "Inter","Inter Variable","Segoe UI Variable Text","Segoe UI",
         "Helvetica Neue","PingFang SC","Hiragino Sans GB","Noto Sans SC",
         "Microsoft YaHei UI","Microsoft YaHei",system-ui,sans-serif;
```

- 思源宋体（CN + CJK 双名）优先，避免直接落到 SimSun 的僵硬字形
- 拉丁侧引入 Inter / Inter Variable，中文侧到苹方 / 思源黑体
- **衬线只用于标题、名词、数字、引文**；正文一律无衬线，避免长文疲劳

### 2.3 排印参数

```css
font-optical-sizing: auto;                       /* 光学尺寸随字号变化 */
font-feature-settings: "palt" 1,"kern" 1,"lnum" 1;
font-kerning: normal;
hanging-punctuation: allow-end;                  /* 中文标点悬挂 */
text-spacing-trim: space-first;                  /* 标点挤压 */
text-rendering: optimizeLegibility;
```

字距按尺寸反向分配：display `-0.018em` → h2 `-0.012em` → 正文 `+0.005em`，
微标签 `+0.13em ~ +0.32em`。大字号收紧、小字号放开，是这套阶梯的隐含规则。

数字一律 `font-variant-numeric: tabular-nums lining-nums`（编号、计数、元数据），
避免滚动计数时抖动。

## 3. 版面结构

```
固定顶栏 78px（滚动后玻璃 + 下边框）  +  2px 滚动进度条
├─ 首屏  双栏 1.04 : .96
│   左：eyebrow → h1(逐行遮罩上浮) → lede → 双动作 → 4 specs
│   右：SVG 图版 600×402（23 节点 / 4 包络 / 扫描线 / 网格）
│   下：波形 canvas（13 线，边缘渐隐）+ 字幕 + 「往下」滴落提示
├─ 名录跑马灯（23 单元名 ×2，76s 循环，hover 暂停）
├─ 01 定位   标签列 142px + 三段论述 + 引文 + 刻度尺
├─ 02 结构   4 tab 分段浏览器 + 单元列表 + sticky 详情面板
├─ 03 形态   4 行矩阵（Desktop / Linux / Root / Rootless）+ 状态胶囊
├─ 04 工程   3 条纪律 + 4 个滚动计数
├─ 05 开始   3 步 + 3 入口
└─ 页脚     品牌 + 元数据 + 描边字标（textLength 自适应）
```

**左栏标签列固定 142px（窄屏归零）**：让 01–05 的编号在同一垂直轴上对齐，
这是让页面"像出版物"而非"像落地页"的关键结构。

## 5. SVG 图版（v6 重排）

**两次返工的原因**：初版四段共用一条公式，曲线彼此几乎同形；标签与曲线共用同一水平带，
文字压在图上；基线左端用虚线段表示「信号进入」，渲染后是一串点，被读成省略号「…」。

### 5.1 三栏分治（消除重叠的根因）

画布 `600 × 436`，划成三个互不越界的竖带：

| 区域 | x 范围 | 内容 |
|---|---|---|
| 左标签栏 | 24 – 96 | 序号（衬线 10.2px）/ 段名（10.4px）/ 英文（7.4px，letter-spacing .09em）三行固定行距 |
| 绘图区 | 104 – 538 | 曲线、面积、基线、刻度、节点、两端三角 |
| 右计数栏 | 538 – 588 | 单元数右对齐，与基线同高 |

硬约束：
- 任何 `<text>` 的 x 起点不得 ≥ 104（脚本可校验）
- 任何曲线点不得越过 `plotR = W - 62`
- 段间分隔线贯穿全幅，同时充当三个竖带的基线

### 5.2 四段曲线：四种形态族，不再同形

| 段 | 形态 | 对应的事实 |
|---|---|---|
| 01 前级 | 三条正弦叠加的细密抖动 | 滤波与门限在不停地小幅修正 |
| 02 算法链 | 8 级上行 → 平顶 → 4 级回落 | 12 级串联，可重排 |
| 03 后级 | `|sin(2πu)|` 双隆起 | 空间与展宽的两处作用 |
| 04 输出 | 升到 0.54 处削顶 | 限幅器压住的峰值天花板 |

每段归一化后再乘相对高度 `PSCALE = [.78, 1, .66, .46]`，
因此四段既有形状差异，也有明确的主次（算法链最高，输出最矮）。

### 5.3 端点处理

首尾各 **16%** 用 smoothstep 窗口：

```
e   = min(1, min(u/0.16, (1-u)/0.16))
win = e² (3 − 2e)
```

smoothstep 在两端导数为 0，曲线离开与回到基线时都是**相切**的。

三次返工记录：
1. `sin^0.52` 窗 —— 两端斜率接近垂直，截图里像被切断的断崖
2. 线性 `min()` —— 不留断崖但留下折角
3. 9% 宽的 smoothstep —— 折角没了，但四段高度差要在一小段里走完，视觉上仍陡
4. 当前 16% —— 坡度明显放缓，起落与基线相切

### 5.4 其余细节

- 进出标记：两端各一枚**实心小三角**（`.pin` 淡 / `.px` 亮），替掉原先的虚线段
- 节点：`r = 1.65` 的空心点（`#0A0B0D` 填充 + 酸绿描边 .42），悬停时填满
  —— 早期是 `r = 2.2` 的实心点，一排看过去像串珠
- 面积：`#areaG` 由上到下 `.115 → .075 → .048`。底部保留可见浓度，
  曲线才明确"落"在基线上；早期渐变在底部几乎归零，看上去像悬空的飘带
- 纵向网格 `.pgrid` 降到 `.032`，避免整幅像格纸
- **呼吸动画只用 opacity**（`pulse`，`.74 ↔ 1`）。早期用 `scaleY` 做呼吸，
  缩放围绕元素自身中心，会把填充底边向上收走，与固定不动的基线错开一条缝——
  这正是"看起来重叠"的真正来源
- 扫描组整体套 `clipPath="url(#plotClip)"`，拖尾不会扫进标签栏
- 图头 `SIGNAL CHAIN` / `4 STAGES · 23 UNITS`，四角裁切标记 `.pcrop`
- `max-width: 680px` 收起图头与英文子标签，段名/序号/计数反向放大，避免整幅缩放后小字不可读

## 6. 持续动效

页面在**静止观看时也活着**，但全部低于"分心阈值"。

| 动效 | 实现 | 周期 | 意图 |
|---|---|---|---|
| 图版扫描线 | JS rAF，`translate(x,0)` | 12s | 模拟信号穿过链路，经过的节点放大点亮 |
| 包络呼吸 | CSS `breathe`，`scaleY(1→.72)` | 6.6–8.85s 错峰 | 四段独立节奏，像四条正在运行的通道 |
| 波形场 | Canvas 2D，13 线相位差 `k*2.3` | 连续 | 两条酸绿高亮线暗示被处理的通道 |
| 品牌环 | CSS `spin` | 26s | 极慢旋转，几乎察觉不到但有生命感 |
| 光晕漂移 | CSS `drift`，`translate+scale` | 26s alternate | 首屏右上角酸绿雾轻微游移 |
| 状态灯 | CSS `beat` | 2.6–3.2s | 主形态灯呼吸，蓝本形态不闪 |
| 跑马灯 | CSS `slide` `-50%` | 76s | 23 个单元名无缝循环 |
| 回顶滴落 | CSS `drip` | 2.6s | 「往下」竖线一颗光点反复落下 |

**性能约束**：
- 全部 rAF 动画受 `IntersectionObserver` 门控，离开视口即停算
- `document.hidden` 时直接 return
- `prefers-reduced-motion: reduce` 下全部动画关闭，仅保留静态最终态
- canvas 按 `devicePixelRatio`（上限 2×）缩放，避免高分屏模糊与过度绘制

## 8. 文案原则

用户反馈「AI 味道太重」，所以原则从「写得准」收紧到「像人写的」。

1. **不写对偶和排比**。「先把声音拆开，再决定怎么合上」这类前后对称句最像机器——
   标题改成单句陈述，`这不是一套预设。` / `装好只要三步。`
2. **不用行话当卖点**。`真源`、`对账`、`符号门禁`、`精度比讨好更持久`全部撤掉，
   换成「改一处两边都跟着变」「构建脚本会直接拦下来」。
3. **少用破折号做修辞停顿**。破折号只用于真正的补充说明，一篇里不超过三处。
4. **具体到可核对**。写「6 个单元」「四槽 × 五级插入点」「32 位走位桥隔离」，
   不写「强大的处理能力」。
5. **承认边界**。Rootless 标「蓝本阶段」，回调内分配写「0 次」而不是「零延迟」。
6. **不加感叹号、不加 emoji、不用「让…」「赋能」「打造」**。
7. **标题用名词短语**，不用问句、不用口语。定稿：`设计出发点` / `四段结构` /
   `平台与接法` / `实时回调的约束` / `安装与首次运行`。
   曾试过「引擎装在哪」「装完不用重启」这类口语标题，用户判定为另一种 AI 腔，已弃用。
8. **不要「不是 A，是 B」的对仗**。「改动的最小单位是单元，不是整条链」
   被改成「改动可以只发生在某一个单元上」。

## 9. 已知约束

- 单文件、无外链资源；字体依赖系统可得，思源宋体缺失时回退宋体 / Georgia
- 响应式断点：980px（首屏转单栏）、920px（导航收敛）、900px（详情面板转静态）、
  820px（标题双栏转单栏）、760px（tab 转 2×2）、640px（单元列表两层）
- 图版与波形在移动端仍运行，但视差关闭；图版 viewBox 600×436，三栏互不越界
- 主标题 `--fs-display` 65px 上限，配合 7 字短行，避免 `keep-all` 下的横向裁切
- 导出为静态 HTML，无构建步骤
